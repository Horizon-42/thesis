# 各机型 V_ref 速度窗与观测通过率（v9 发布速度门，2026-09-08 重评估）

数据：`aircraft/reference_speeds.json`（172 型，来源索引 `docs/reference_speeds/README.md`）；观测判定取自五机场发布的
`aeroviz-4d/public/data/airports/<ICAO>/comparison/observed/evaluation_report.json`（2026-09-08 重评估：机型解析修复 + 扩表后，
METAR 顶风修正后的空速估计；无可用风报的行用地速代理）。速度单位 kt（CAS），质量 kg。窗口定义见
`THRESHOLD_SPEED_GATE.md` §2：

```text
V_ref,lo(m) = V_min · sqrt(m / MALW)        V_ref,hi(m) = V_max · sqrt(m / MALW)
观测记录（质量未测）：下界 = V_ref,lo(m_min) · sqrt(max(n,1))，上界 = V_max + 20 kt
计算记录（质量已知）：下界 = V_ref,lo(m)     · sqrt(max(n,1))，上界 = V_ref,hi(m) + 20 kt
```

V_min / V_max 是 FAA Aircraft Characteristics Database（2024-10）在 MALW 处的进近速度：单值机型二者相等；
双值机型 V_min 为最佳（最大）着陆襟翼构型值，V_max 为减小襟翼构型值。m_min 为该机型公布的最小运行质量
（MFW = 厂商最小飞行质量，OEW/BOW/BEW/OWE = 厂商或 OpenAP 的空重）。下表的观测窗按 n = 1 计；实测 n 中位
1.002–1.005，只把下界抬高 0.1–0.5 %。

## 4. 怎么读

- 观测窗是机型公布质量区间上的确定窗：下界取最轻公布质量处的最大襟翼 V_ref，上界取 MALW 处（减小襟翼）
  V_ref + 20 kt。它宽（B738 111–164 kt），因为航班质量未测；任何正确落地的航班都应在窗内，越界即真异常或
  数据/风报误差，逐条可解释（`BASELINE_SPEED_GATE_RESULTS.md` §10.3）。
- 通过率低于 95 % 的机型有两类：单值 FAA 行的多襟翼机型（E75L 91.1 %、E170/E190 87–89 %、B737 96.0 %）——
  上界只含最大襟翼速度，减小襟翼落地的航班以 V_ref+additive 过门槛就读作"快"（followups #21）；以及通航
  C172（74.6 %）——62 kt 锚上 10 kt 的风就是窗宽的三分之一。
- 判定值 p50 列可与发布速度对照：中位穿越空速 = V_max + 8–11 kt（B738 152 对 144，B38M 152 对 145，
  B739 155 对 149，CRJ9 142 对 141，A320 141 对 136，B737 139 对 130，E75L 137 对 126），即 V_ref 加
  5–10 kt 的 additive，与 FSF ALAR 的 V_ref…V_ref+20 一致；B737 与 E75L 的 +9/+11 比双值机型高，正是
  它们的 FAA 单值只给最大襟翼速度的痕迹。
- 未判定列只计"有机型但无公布最小质量"的四型（GLF5、C25A、LJ45、C525，followups #22）；机型无法解析的
  行另计。
