标准改变了什么

退役：±7.5 m

来自 close-in LPV `15 m` 一侧显示 FSD 与 ICAO 正常跟踪 `½ FSD` 的组合。它适合描述 guidance tracking，不是 threshold crossing 或 landing outcome 的通用法规界限；也不是 `±7.5 ft`。

当前：±22 m

数值依据 ICAO Doc 9613 Vol. II, Part C, Ch. 5, Section A §5.3.4.4.7 的 RNP APCH Baro-VNAV 最终进近垂直偏差限制。项目将它统一用于 RNAV/LPV terminal geometry；不声称它是法律意义上的 landing certification。

vertical_error = event_altitude − (LTP_elevation + published_TCH) vertical_pass ⇔ −22 m ≤ vertical_error ≤ +22 m LPV_lateral_bound = min(0.5 × published_lateral_FSD, 0.5 × runway_width) lateral_pass ⇔ |signed_cross_track| ≤ LPV_lateral_bound

解释边界

pass 表示

在阈值平面处，轨迹参考点满足当前 RNAV terminal geometry 的横向和垂直接受界限。

pass 不表示

航空器已安全着陆、符合特定公司 SOP、全机在跑道内、满足障碍净空，或实际飞行了所选 LPV procedure。

fail 表示

至少一个可评价的 terminal component 超界；它是诊断信号，需要结合 event method 和 provenance 解释。

indeterminate 表示

可信 event 或适用 context 不足。它不是 fail，也不能当 pass。
