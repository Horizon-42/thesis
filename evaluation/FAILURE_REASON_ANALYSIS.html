适用范围：这个 resolver 只用于 observed ADS-B。它输出与 policy 无关的 LTP 三维事件，不包含 TCH、FSD、runway width、approach type 或 verdict。optimized/predicted 按后述 terminal-state 规则取得同一个数学事件，不经过 observed resolver。

A.1 Direct：bracket 就是正式 event evidence

对相邻 source-timed 样本检查一次 inbound crossing：

before.s < 0 ≤ after.s after.s > before.s after.time > before.time |interpolated cross-track| ≤ 1000 m |interpolated height above threshold| ≤ 100 m

1,000 m/100 m 只排除无关飞越，不是 verdict gate。选定 source-valid bracket 后，interpolation_fraction 同时应用于时间、cross-track 和 HAE 高度；不再调用 fit_final_segment()。

A.2 Direct source-integrity

位置时间使用 lastposupdate，并检查 reported velocity：

0 < Δlastposupdate ≤ 15 s 0 < reported ground speed ≤ 200 m/s |position speed − mean reported speed| ≤ 25 m/s 0.5 ≤ position speed / mean reported speed ≤ 1.5

这些 predicate 只拒绝位置跳跃与冻结，不保证 geo-altitude 与 position 真正同一测量时刻。本次统计显示 bracket gap 与 direct fail 强相关，因此 15 s 是完整性上限，不是“15 s 内垂直值都足够精确”的保证。

A.3 Direct 三维插值

α = −aᵢ / (aᵢ₊₁ − aᵢ) t* = (1−α)tᵢ + αtᵢ₊₁ c* = (1−α)cᵢ + αcᵢ₊₁ u* = (1−α)uᵢ + αuᵢ₊₁ a* = 0

同一个 α 是关键不变量：禁止再组合 c* from bracket 与 u* from fit。Direct event 的 extrapolation_distance_m=0，uncertainty 状态为 uncalibrated。

A.5 Frame 与 policy 分离

Event 保存仅含物理 LTP 的 threshold_frame_fingerprint；evaluation 另存包含 TCH、FSD、runway width 和标准版本的 evaluation_context_fingerprint。换跑道 frame/cycle 必须重建 event；只换 policy 时可以复用 physical event，但必须重算 verdict。

Unavailable 是有效结果，不是异常回退入口。invalid support、pass coverage 不足、ambiguity 或 frame mismatch 都不得通过切换旧 schema、另一窗口或另一段航迹来制造 estimate。

B.2 跑道坐标与垂直参考

s = 相对 LTP 阈值面的有符号 along-track（阈值前为负） x = 相对跑道中心线的有符号 cross-track（右侧为正） desired altitude MSL = LTP elevation MSL + published FAS TCH z = trajectory altitude MSL at s=0 − desired altitude MSL

TCH 是标称路径在阈值处的高度，不是误差容差。Observed 必须同时通过事件内 runway-data fingerprint 与当前 assessment context 的跑道、周期、坐标、航向和 HAE/MSL datum 一致性检查，防止把旧周期拟合结果套到新跑道框架。

B.3 LPV 主标准

横向

B_guidance = 0.5 × LPV lateral FSD B_runway = 0.5 × runway width B_lateral = min(B_guidance, B_runway) pass ⇔ |x| ≤ B_lateral

FAA Order 8260.58D Formula 3-1-1 的阈值 course-width 下限示例为 106.75 m，因此 half-FSD 为 53.375 m；实际判决使用当前 FAS 值。跑道半宽是项目的几何保护项，确保被评价的导航参考点不在跑道边缘之外；它不声称机翼或起落架整体均被包含。

垂直

LPV one-sided minimum FSD = 15 m ICAO normal-operation fraction = 0.5 B_vertical = 0.5 × 15 m = 7.5 m pass ⇔ −7.5 m ≤ z ≤ +7.5 m

15 m 来自 RTCA DO-229D §§2.2.4.4.4、2.2.5.4.4 的 angular/minimum-clamped LPV scale；0.5 来自 ICAO Doc 9613 Fifth Edition, Volume II, Part C, Chapter 5, Section B, §5.3.3.1.1.1(b)。这不是由本数据集调参得到，也不是 WCH、TCH 范围或 SBAS alert limit。

B.4 唯一 fallback：RNP APCH LNAV/VNAV（approved Baro-VNAV）

B_lateral = min(0.15 NM = 277.8 m, 0.5 × runway width) B_vertical = 22 m pass ⇔ |x| ≤ B_lateral AND |z| ≤ 22 m

±22 m 来自 ICAO Doc 9613 §5.3.4.4.7。只有 assessment context 明确确认 approved Baro-VNAV 并提供权威阈值路径高度时才启用垂直 gate；否则 vertical 为 indeterminate，overall 仅在 lateral fail 时为 fail，其余为 indeterminate。Pure LNAV 没有批准的对称垂直路径误差 gate，因此不是三维 verdict fallback。

B.5 三值合成与 point-estimate 原则

component pass ⇔ 有 estimate 和 bounds，且 lower ≤ estimate ≤ upper component fail ⇔ 有 estimate 和 bounds，但 estimate 越界 component indeterminate ⇔ estimate 或适用 bound 不可用 overall fail ⇔ lateral 或 vertical 任一为 fail overall pass ⇔ lateral 和 vertical 都为 pass overall indeterminate ⇔ 没有 fail，但至少一个 component 为 indeterminate

判决使用 inclusive point estimate。v1 observed uncertainty 尚未校准，因此不发布 numeric interval；未来若校准，interval 也只描述 estimator/data quality，不改变 point verdict。所有坐标、时间、宽度、FSD、bounds 与 deviations 必须为有限数；NaN/Infinity 必须拒绝，不能依靠比较结果“自然通过”。

结果边界：本报告回答“轨迹导航参考点在 LTP 阈值面是否符合所选 LPV 或 LNAV/VNAV 几何基准并位于跑道横向范围内”。它不证明整段 FAS conformance、实际机组选择的 approach mode、航电 integrity、障碍面净空、operator stabilized-approach policy、touchdown point 或完整机体/起落架 containment。

5.2 原因优先级与当前证据

P1 高度与位置仍非真正同步

最强候选，direct 为主。track 的时间轴已改为 lastposupdate，并去除了 held positions；但 OpenSky state snapshot 没有独立的 geo-altitude measurement timestamp。当前做法只能把最近高度快照对齐到位置更新时间。

gap/async 与 fail 的强梯度支持继续审计这一层。下一步应按 bracket 两端的高度变化、GVA、gap 和机场做受控分层；在完成前，不能说“整条航迹高度都不可信”，也不能说“所有 direct fail 都是真实偏差”。

P1 Censored 外推模型误差

KRDU 为主。14,602 个 censored event 有 2,585 个 fail（17.70%）。它们没有阈值后观测，只能从 [-5000,-300] m 线性外推。

source-only truncation 实验的 censored vertical abs P95 在最差机场达到约 36–41 m，说明其中一部分“约 20%”可能是 estimator error。numeric uncertainty 尚未校准，所以不能把每个 censored fail 都当作已确认的物理越界。

P2 Benchmark 与实际 flown procedure 不同

Evaluation 明确比较“该跑道 LPV FAS 的 published TCH”。一条 ADS-B 航迹成功着陆，只证明它完成了着陆，不证明机组实际飞的是被选择的 LPV procedure，也不证明全程保持 LPV guidance。

ILS、visual、Baro-VNAV、不同 FAS 或人工操纵都可能产生安全着陆但不满足本项目的理想 LPV 几何。当前 ADS-B/harvest 数据没有 flown-procedure/mode 字段，因此这是合理但尚未直接验证的候选。

P2 机场级 altitude/datum/reference bias

Direct vertical median 在 KMSY 为 +9.72 m、KSTL +8.13 m、KRDU +10.06 m，而 KSJC 为 −1.28 m、KSMF +3.53 m。符号和幅度随机场明显变化。

这要求逐机场复核 geo-altitude/GVA、HAE−MSL offset、FAA LTP elevation、published TCH 和导航参考点定义。frame/cycle fingerprint 已防止静默混周期，但不能证明所有权威输入与 ADS-B 高度在实际测量层面没有 residual bias。

事实 真实轨迹可安全着陆但不通过理想 gate

±7.5 m 是本项目依据 LPV FSD 正常运行比例建立的理想阈值事件 conformance gate，不是“能否安全落地”的充分必要条件。成功着陆样本中存在真实 threshold-crossing dispersion 并不矛盾。

因此本报告的 fail 应读作“没有通过所选理想 LPV LTP 几何基准”，不能写成“飞机没有正常着陆”。

排除 横向 gate 不是剩余主因

11,804 个 fail 中只有 65 个涉及横向，12 个仅横向。新 direct 方法消除了旧 v6 大部分横向长尾；目前没有数据依据修改 min(½FSD,½runway width)。

当前最可靠的结论：剩余 fail 不是一个单一“fitting bug”。Direct 的首要调查对象是 threshold 附近的高度—位置时间一致性；censored 的首要调查对象是外推误差；在两者之外，还必须区分“理想 LPV benchmark conformance”与“实际成功着陆”。只有完成 GVA/gap 分层和 flown-procedure 验证后，才能把剩余比例进一步分配给数据误差、模型误差和真实几何偏差。

7. 判决条件与“原因”的边界

vertical_error = threshold-event altitude − (LTP elevation + published TCH) vertical pass ⇔ −7.5 m ≤ vertical_error ≤ +7.5 m lateral pass ⇔ |signed cross-track| ≤ min(½ LPV lateral FSD, ½ runway width) overall fail ⇔ 任一适用 component fail overall pass ⇔ lateral pass AND vertical pass otherwise ⇔ indeterminate

正式失败原因是上述分量越界；这是本报告可以直接、确定地统计的内容。物理根因可能包括真实飞行偏差、最终段样本选择、拟合模型、外推、ADS-B 高度/位置时间对齐等。仅凭 verdict 不能把这些根因互相替代。

当前 observed uncertainty 明确为 uncalibrated，不提供 numeric interval，也不改变 point-estimate verdict。报告不会用一个未经验证的区间把 pass/fail 改成 indeterminate。
