estimate_trim_attack_rad 可视化说明

这个函数不是飞控律，也不是最终优化结果。它只是在 single shooting 进入 SLSQP 之前，给每个控制段一个“至少能飞起来”的迎角初始猜测，避免初始仿真直接撞地并导致约束雅可比退化。

1. 这个函数解决什么问题

single shooting 只有控制量和最终时间，没有中间状态节点。SLSQP 第一次评估时，会把整条轨迹从真实初始状态一路 replay 到终点。

如果初始控制猜测太弱，例如 A320 用 4 deg alpha、170 kt、重 78 吨，那么升力不够，轨迹会在第一次仿真中快速下沉到地面以下。

一旦仿真失败，当前代码会把 objective 或 constraint 返回成大常数 1e9。如果附近的有限差分点也都是同一个常数，SLSQP 看到的约束梯度就是零，于是报 Singular matrix C in LSQ subproblem。

2. 函数背后的力平衡

函数只看垂直平面里的“法向力够不够”。它并不试图让飞机正好到达跑道，也不优化路径。它只是找一个 alpha，使升力加上 thrust 在法向上的分量，尽量抵消重力在法向上的分量。

qS = 0.5 * rho(h) * V^2 * S CL(alpha) = CL0 + CL_alpha * alpha lift = qS * CL(alpha) required_normal_force = m * g * cos(gamma) vertical_balance_error(alpha) = lift + thrust * sin(alpha) - required_normal_force
当 vertical_balance_error(alpha) = 0 时，说明这个 alpha 在当前速度、高度和重量下大致能配平垂直法向力。函数就在 -18 deg 到 18 deg 之间找这个零点。

4. 函数流程：从输入状态到 alpha 初值

1

读取模型

如果 fake simulator 没有 simulator 或 atmosphere，函数退回旧默认 4 deg，方便单元测试和简单替身对象。

2

建立误差函数

用当前 V, h, m, gamma, thrust 计算 vertical_balance_error(alpha)。

3

检查边界

先看 -18 deg 和 18 deg 是否夹住零点。如果夹不住，就选误差较小的边界。

4

二分查找

如果零点被夹住，就二分 60 次。这个区间很小，60 次足够让数值误差远小于模型误差。

low_error = vertical_balance_error(-18 deg)
high_error = vertical_balance_error(18 deg)

if low_error and high_error have the same sign:
    return the bound with smaller absolute error

for 60 iterations:
    mid = (low + high) / 2
    if error(low) and error(mid) have opposite signs:
        high = mid
    else:
        low = mid

return midpoint(low, high)

6. 这不是最终答案，只是一个更好的起点

函数保证什么

它让初始控制猜测更可能处于可仿真的区域，让 SLSQP 能看到非零约束梯度和搜索方向。

对于你遇到的报错，它消除了“第一步就撞地，约束恒定 1e9”的直接原因。

函数不保证什么

它不保证 single shooting 一定收敛，不保证最终轨迹真实，也不解决模型缺少襟翼、起落架阻力、速度调度等问题。

如果后续仍然难收敛，问题会从“初始点不可微”转为“single shooting 参数化太弱或目标不可达”。
