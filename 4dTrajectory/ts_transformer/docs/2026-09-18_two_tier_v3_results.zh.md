## 5. 解读与条件（每条带配置；不引用 09-18 token 战役的数当基线）

1. **L 轴**：五行 Δ 上 L = 120 的格都是该行最优或并列最优（established 全部：Δ = 20 0.769 / 0.843，Δ = 30 0.827 / 0.762，Δ = 60 0.742 / 0.702，Δ = 90 0.746 / 0.746，Δ = 120 0.690 / 0.613）。L = 30 在 Δ ≤ 30 不可用（第 3 条），在 Δ ≥ 60 能训出但仍是行内最差（0.504 / 0.547、0.380 / 0.488、0.626 / 0.596）。L = 60 与 90 之间没有稳定次序，差在 seed 线内。
2. **Δ 轴**（L = 120）：Δ = 20 与 30 相当（0.769 / 0.843 vs 0.827 / 0.762，差在 seed 线 0.078 内），Δ ≥ 60 变差（0.742 / 0.702、0.746 / 0.746、0.690 / 0.613）；FDE p50 同样 Δ = 20 / 30 最好（256–309 m）。并列时的规则选短 Δ，故选 L120_D20。
3. **选模规则的副作用（L = 30，Δ ≤ 30）**：选模指标是固定 L−1 锚点的 common-grid ADE；这两格该指标在第 1 个 epoch 最好（L30_D20 38.8 / 38.6 m → 第 180 epoch 46.7 / 46.0；L30_D30 75.3 / 74.4 → 95.2 / 95.5），所以保存的 checkpoint 是只更新 14 步的初始网络，闭环读数（established 0.02–0.03，fully flyable 0.13–0.29）测的是初始网络的匀速外推。L = 30 在 Δ ≥ 60 的格选模在 35–80 epoch，之后反弹到比初始更差；L ≥ 60 的格都正常收敛。这是计划规则（选模锚点固定在 L−1，训练锚点全随机、l1_share 0）下的真实结果，不是代码错误。要不要给 L = 30 换选模锚点，由用户决定（改计划参数，重训 L = 30 的格）。
4. **训练预算**：八格的选模最优 epoch 落在 163–180，预算用完时指标还在降：L60_D30 180 / 179、L60_D60 175 / 128、L90_D60 171 / 163、L60_D90 178 / 164、L90_D90 175 / 178、L120_D90 177 / 167、L60_D120 165 / 178、L90_D120 177 / 180。这些格（都在 L ≥ 60、Δ ≥ 30）可能被 180 epoch 限制。胜出格 L120_D20（111 / 139）和同行的 L120_D30（148 / 128）不在其中，判定不受影响；Δ ≥ 60 各行内的比较带此条件。
