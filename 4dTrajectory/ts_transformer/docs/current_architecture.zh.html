动力学与 Loss：control 不是轨迹，rollout 后才是

控制预测必须穿过与 CasADi 模型数值契约一致的 Torch point-mass 模型。 这条路径保持可微，因此位置误差可以反传到 controls 与 duration。

每个 RK4 子步里的 7 状态与 3 控制

state = [lat, lon, altitude, V, ψ, γ, mass]
control = [thrust, bank, load_factor]
  • ISA 密度 + Cd = Cd0 + k·Cl² + stall_drag；
  • RHS 更新位置、速度、航向和航迹角，质量保持常数；
  • 每个 control segment 最多按 0.5 s RK4 子步积分；
  • 每步做 ENU / ECEF / WGS84 geodetic 转换；
  • dense rollout 同时返回 2 秒 query states 和 segment endpoints。
