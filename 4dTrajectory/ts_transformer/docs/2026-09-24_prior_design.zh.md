# 先验设计（阶段 5，2026-09-24）

**一句话**：先验是一个自回归模型，读航班的背景（机场与候选跑道）和到此刻为止的状态与生效的词，写出下一步
六列词（每列"不变"或一个新词）。它从句子产物里学（教师强制）；以后与执行器接起来，一步说词、一步飞。

词的定义见[指令词表](2026-09-23_instruction_vocabulary_design.zh.md)，执行器见[执行器设计](2026-09-23_executor_design.zh.md)，
框架见[两层模型框架](2026-09-23_two_tier_framework.zh.md) §1、§4。

## 1 数据

- **来源**：句子产物 `4dTrajectory/outputs/POOLED/instruction_language/v2_20260924/`（规格 `103a6eae6b90`）。train 50,214 架、
  970 万步；val 10,540 架。只读这一份产物，核对规格 sha 与标注器源码 sha（框架 §1："句子产物是唯一的真值来源"）。
- **划分**：train 训练；val 只用于早停和读数；test 不打开。
- **一步** = 句子的一行（2 s）。一架航班的句子是信号的前 `len(words)` 行（在落地前结束）。

## 2 每一步的输入与输出

第一版在第 t 步看到的如下（**第二版的改动见 §8**：这里的航迹、地速、垂直速率含有之后 7.5 s 的信息）：

- **状态**（信号的第 t 行，机场坐标系，米制，按固定尺度缩放）：E、N、MSL 高度、航迹（sin、cos）、地速、垂直速率、
  从第 0 行起的时间；
- **相对生效跑道的量**：离入口沿航道的距离、偏离中线、入口上方的高度、航迹与跑道航向之差（sin、cos）。第 0 步
  跑道指针还没说，这几个量为 0，另给一个标志位——否则第 0 步就从特征里知道了要说哪条跑道；
- **生效的词**（第 t−1 步为止）：六列各一个嵌入；第 0 步用"还没有词"的嵌入；另给每列"上次换词之后过了几步"
  （对数缩放）；
- **背景**（每架一份，加在每一步上）：机场的嵌入；候选跑道的几何（最多 8 条：入口 E、N、高程，跑道航向 sin、cos，
  有效位）。

输出第 t 步的六列词。每列一个分类头，类别 = "不变" + 这一列的全部取值：

| 列 | 取值数 | 类别数 |
|---|---|---|
| 跑道指针 | 候选数（≤ 8，按机场屏蔽无效的） | 9 |
| 进近 | 3（未许可、许可加入、复飞） | 4 |
| 航向 | 72（5° 一档） | 73 |
| 高度 | 181 档 + 下降至落地 | 183 |
| 下降角 | 平飞、4 个下降档、爬升 | 7 |
| 速度 | 47 档 + 未指定 | 49 |

第 0 步六列都写（初始的词），之后每列在约 1–2 % 的步上换词。

## 3 模型

因果 Transformer（只看自己和之前的步），每步的输入是上面各项投影后相加，六个分类头。第一次的尺寸（§6）：
d = 192、4 层、6 头、前馈 768、dropout 0.1，约 200 万参数。按长度把航班分桶成批，不截断（最长 1,133 步）。

## 4 训练

- 损失：六列交叉熵之和（跑道头只在有效候选上做 softmax）。
- 优化：AdamW，学习率 3e-4，权重衰减 0.01，梯度裁剪 1.0。
- 早停：看 val 的平均每步负对数似然，3 个 epoch 不降就停，最多 30 个 epoch，保留 val 最好的一次。
- 产物：`4dTrajectory/outputs/POOLED/prior/<名字>/` 写一次、不覆盖：`checkpoint.pt`、`config.json`（含产物目录、规格 sha、
  标注器 sha、git 状态）、`history.json`（每个 epoch 的 train / val 损失）、`readout.json`。只在干净的工作树上跑。

## 5 读数（这次只读，不设门）

框架 §4 的先验门有四项：困惑度、前 K 覆盖、自由生成能否以落地结束、赢过"重复上一条"和"只看上一个词"。第一次
训练读前两项和两个基线；自由生成要和执行器接起来，放在下一步。

- **每步负对数似然与困惑度**，分列报；
- **换词的步**（真值换了词）：模型给"换词"的概率；取值的前 1 / 前 5 命中率；
- **不换的步**：模型说要换词（取最大概率的类不是"不变"）的比例；
- **两个基线**（都从 train 数出来，在 val 上算同样的负对数似然）：
  - 重复上一条：每列按 train 的换词频率给"换词"的概率，换成什么按 train 各取值的频率；
  - 只看上一个词：换成什么按"这一列上一个词 → 下一个词"的 train 频率（加一平滑）。

## 6 这次定下的选择（都是第一次的值，不经交叉验证）

| 选择 | 值 | 理由 |
|---|---|---|
| 模型尺寸 | d 192、4 层、6 头 | 数据 970 万步，一个小模型先跑通；显卡 8 GB |
| 批 | 按长度分桶，每批约 16,000 步 | 显存 |
| 学习率、衰减、裁剪 | 3e-4、0.01、1.0 | 常用值 |
| 早停 | val 负对数似然，耐心 3，最多 30 epoch | |
| 状态缩放 | 位置 10 km、高度 1 km、地速 100 m/s、垂直速率 10 m/s、时间 600 s | 让各量在 ±几 之内 |
| 不用的输入 | 机型 | 第一次先不加；先看只靠几何与状态能学到多少 |

## 7 第一次训练的读数（val，2026-09-24）

230 万参数，28 个 epoch（第 25 个最好，每个约 58 s，共 27 分钟），train 970 万步、val 205 万步。

| 列 | 模型 | 重复上一条 | 只看上一个词 | 换词的步数 | 换词的步上 P(换) | 取值前 1 | 取值前 5 | 不换的步上误说要换 |
|---|---|---|---|---|---|---|---|---|
| 跑道指针 | 0.0023 | 0.0082 | 0.0082 | 10,540（都是第 0 步） | 1.000 | 0.808 | 1.000 | 0.0000 |
| 进近 | 0.0120 | 0.0222 | 0.0222 | 16,092 | 0.693 | 0.923 | 1.000 | 0.0001 |
| 航向 | 0.0460 | 0.0925 | 0.0832 | 25,827 | 0.507 | 0.557 | 0.843 | 0.0005 |
| 高度 | 0.0184 | 0.0433 | 0.0429 | 18,374 | 0.815 | 0.645 | 0.886 | 0.0007 |
| 下降角 | 0.0452 | 0.1003 | 0.0959 | 39,536 | 0.549 | 0.772 | 1.000 | 0.0020 |
| 速度 | 0.0539 | 0.0778 | 0.0736 | 26,752 | 0.444 | 0.483 | 0.830 | 0.0001 |
| **合计（每步）** | **0.1778** | 0.3444 | 0.3260 | | | | | |

读法：

- 每一列都比两个基线低，合计约低 45 %，每步困惑度 1.19。流程（产物 → 数据 → 训练 → 早停 → 读数）跑通了。
- "什么时候换词"比"换成什么"难：换词的步上模型给"换"的平均概率只有 0.44–0.82（速度、航向最低）；换成什么，前 5
  覆盖 83–100 %。换词的时刻本身有几秒的读法误差（执行器设计 §9 办法 B：高度、角度词读晚 4–6 s，速度词 8–9 s），
  模型学到的时刻也就带着这个误差。
- 跑道指针在第 0 步说，前 1 命中 80.8 %：只靠机场、候选跑道和第 0 步的状态，平行跑道之间还分不清。

## 8 第二版：输入与结构的改动（计划，2026-09-24）

### 8.1 为什么改

1. **速度类的输入含有未来的信息。** 信号里的航迹、地速、垂直速率来自 `flight_scenarios.state_samples_from_track`：对每个
   ADS-B 点，在它前后各 7.5 s 的窗口里做最小二乘拟合（`DEFAULT_WINDOW_S = 15`，repo `docs/open-items.md`）。所以第 t 步的
   这些量已经含有 t 之后 7.5 s 的信息。合成例子：100 m/s、第 0 s 起每秒右转 2°，这样拟合出的航迹在 −2 s 已偏 0.89°、
   0 s 偏 2.30°；只用过去 15 s 拟合的在 0 s 仍为 0。
   - 航向词正好标在转弯开始的那一行，先验可能学成"看到航迹开始弯了才说转"。闭环时执行器要先听到词才会转，这样学到的
     先验会说晚或不说。影响有多大还没量（§8.3 的变体 0 就是量它的）。
   - 位置（E、N、高度）直接取自报告点，没有拟合，不受影响。标注器照旧用拟合：它读完整条航迹产出标签，看到未来是允许的。
2. **没有相对每条候选跑道的量。** 第一版只算"相对生效跑道"的量，第 0 步跑道还没说时为 0。所以第 0 步选跑道时，模型只能
   用绝对位置和拼成一个向量的候选几何，在网络里自己算出相对关系。词表设计 §4.2 本来规定每一步对每条候选都算相对量，
   §4.1 规定候选跑道编码成与排列顺序无关的 token、§4.3 用"本步隐状态对每条候选打分"选跑道；第一版把这些简化了，
   当时没有写明。
3. **第 0 步的航向、速度词是从拟合的速度里读出来的。** 去掉速度类输入后，只有一个位置点，看不出往哪飞、飞多快。

### 8.2 改动（四项）

1. **不输入拟合的速度类量**：去掉航迹（sin、cos）、地速、垂直速率，以及"航迹 − 跑道航向"（它也用拟合的航迹）。
   保留 E、N、MSL 高度、从第 0 行起的时间。飞多快、往哪飞，模型从之前各步的位置里自己看（每 2 s 一个位置）；要不要
   另外给"只看过去"的速度，由 §8.3 在 train 上比。
2. **第 0 步：交接时已知的列当条件，不预测。** 每步输入里"生效的词"从第 0 步起就含这些列；损失和读数里第 0 步只算要
   预测的列。逐列（**待用户确认**）：

   | 列 | 第 0 步 | 理由 |
   |---|---|---|
   | 航向 | 已知条件 | 描述交接时的状态（当前航迹取最近一格）；一个位置点看不出方向 |
   | 速度 | 已知条件 | 同上（当前速度的档） |
   | 高度、下降角 | 已知条件 | 交接时正在执行的高度指令（平飞在当前高度，或正下降到某个目标）；它是交接之前定下的，一个位置点也看不出下降的目标 |
   | 进近 | 已知条件 | 进入切片时已在五边上就是"许可加入"，否则"未许可"，由状态决定 |
   | 跑道 | **预测** | 先验要做的决定；靠 8.2 第 3、4 项的相对量和候选 token |

   闭环时这些条件来自交接的场景（观测航班第 0 步的词），和给执行器的初始状态是同一份交接。另一种做法是跑道也当条件
   （真实运行里跑道在进入终端区之前多半已经定了）；这里选预测，保留"选跑道"这一项读数。
3. **每一步对每条候选跑道算相对量**（词表设计 §4.2）：离入口多远（沿航道，入口之前为正）、偏离航道多远（右为正）、
   高出入口多少，都只由位置算；方向那一项（运动方向 − 跑道航向）不用拟合的航迹，改用"上一步位置指向这一步位置"的方向，
   第 0 步没有上一步，记 0 并给标志位；这一项留还是去由 §8.3 比。对所有候选都算，不只算真值跑道，所以不泄露答案。
   第一版"相对生效跑道的量"去掉：跑道说出之后，"生效的跑道"就是那条候选的向量（词表设计 §4.3 "说出之后"）。
4. **候选跑道 token**（词表设计 §4.1、§4.3）：每条候选的几何（入口 E、N、高程、航向 sin、cos、长度）和 8.2 第 3 项的相对量
   经同一个小网络变成这一步的候选向量，与排列顺序无关；汇总进这一步的输入（对候选求和或注意力汇总，实现时二选一，
   写进 §6）。跑道列的输出改成对每条候选打分：分数 = 本步隐状态 · W · 候选向量，另加一个"不变"的分数，在本机场的
   候选上做 softmax（补齐的位置为负无穷）。

**不在这次四项里、另外记下的差别**：词表设计 §4.4 规定同一步里各列依次给出、后一列能看到前面刚选的值，并按规则屏蔽；
第一版六个头互相独立。教师强制下影响不大，但自己采样时同一步可能出现不配的组合（例如给了"许可加入"却没给切入航向）。
和执行器接起来自由生成时一起定。

### 8.3 在 train 上比什么

- **选择用的数据**：从 train 按航班留出一份（例如 10 %，按机场分层）做内部选择集；val 只用于早停和最后的读数，不用来挑变体。
- **变体**（其余都按 8.2）：
  - 变体 0：照第一版给拟合的航迹、地速、垂直速率——**只用来量未来信息的影响，不会用于闭环**；
  - 变体 1：只给位置；
  - 变体 2：位置 + 只看过去的速度（上一步到这一步的位移除以 2 s：地速、运动方向、垂直速率）；
  - 8.2 第 3 项的方向那一项：在变体 1、2 上各试留 / 去。
- **读什么**：内部选择集上第 1 步起的每步负对数似然（分列）；换词的步上给"换"的概率和取值前 1；第 0 步跑道的前 1。
  变体 0 与变体 1、2 在"换词的步上给'换'的概率"上的差，就是先验靠未来信息的程度。
- **怎么选**：在变体 1、2（及方向项留 / 去）里取内部选择集上每步负对数似然最低的；差别小于随机种子之间的差时取输入少的。
  选定后在 val 上读一次（与两个基线比），变体 0 不参与选择。
- 读数口径与第一版不同（第 0 步只算跑道），两版的数不直接比；各自与按同一口径重算的两个基线比。

### 8.4 不变的

词表不变；标注器照旧用拟合的量读句子；模型尺寸、训练设置沿用 §6（交叉验证另做）。
