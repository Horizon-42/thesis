# 读数：先验靠不靠"知道自己在哪个机场"——机场向量被换掉以后丢多少（2026-10-03）

**一句话**：每个先验模型（"管制指令语言模型"）给五个训练机场（KMSY、KRDU、KSJC、KSMF、KSTL）各存了一个学出来的向量，每一步都加进输入。
在这五个机场的验证集上把它换掉：换成五个向量的平均（给没见过的机场就是这个），验证集上预测标注指令词的损失每步升 0.015（base）/ 0.018（augmented），

**结论是模型确实在用这个向量**：KSMF、KMSY 丢得最多（augmented 换成其余四个的平均，落地少 15.7 / 12.3 个百分点），KRDU、KSJC 丢得少。
损失的增加约六成落在航向词上。这是在五个训练机场的验证集上测的，**KAUS 还没有跑任何模型**。

## 0 几个词

- **机场向量**：模型里 `self.airport`（`prior/model.py`），一张有 5 行的表（`nn.Embedding`），每行是一个向量（这里只量了长度和夹角，没有逐维看），随训练一起学出来；
  五个机场各一行，每一步都加进这一步的输入。设计文档（[先验设计](../prior_design.zh.md) §4.5）对它只写了"机场：一个机场嵌入"，没有理由；
  同一节对飞机型号恰恰不用编号嵌入（编号会让模型记住个别型号，遇到少见或没见过的就不会用），改用有物理或规章含义的量。
- **候选跑道表不是问题所在**：每条候选跑道用几何量（入口东/北坐标、标高、航向的正弦余弦、长度）经同一个共享网络进模型，对 KAUS 不用训练就能算出来。
  这里只讨论那张"机场编号表"。
- **三种读法**（R46 的 `--substitutes`）：
  - **own**（自己的）：照常，用本机场自己的向量。这是参照。
  - **mean**（平均）：每个机场的向量都换成五个向量的平均。没见过的机场（KAUS）拿到的就是这个。注意这个平均里有五分之一是自己的向量：
    我用各向量的长度和夹角算了，平均向量与每个机场自己的向量的夹角余弦在 0.40（KSMF）到 0.54（KRDU）之间，所以它仍带着一部分"自己"的方向（我的计算，不是 R46 的输出）。
  - **others**（其余的）：每个机场的向量换成**其余四个**的平均。里面没有自己机场的任何成分，是"完全认不出这个机场"的情形。
  每次只换这一张表里的一行，别的输入（句子、位置、候选跑道……）全是这个机场自己的。
- **每步负对数似然（NLL）**：教师强制（teacher forcing，每一步都把标注的真实历史喂给模型，只看它给下一个标注词的概率）下，
  模型给标注指令词的概率取负对数，按"训练损失计入的预测步"取平均；越小越好。+0.0100 的意思是平均每步的"意外程度"多了 0.01（自然对数单位）。
  六列：**跑道**、**进近**、**航向**、**高度**、**下降角**、**速度**（每一步每一列要么"不变"要么换词）。
- **自由生成（自己飞）**：模型自己一步步说指令，执行器（v11）照着飞，判最后的结局；每架航班飞 4 次，温度 1.0。
  **落地**：飞机在入口处被判落在了指向的那条跑道上（横向偏差不超过 106.7 m，高度不超过落地条件）。其余结局按字面：
  **过入口时太高**（`crossed_too_high`）、**过入口时偏出跑道**（`crossed_off_runway`）、**落到了别的跑道**（`crossed_other_runway`）、
  **没截获航道就过入口**（`crossed_without_capture`）、**触地**（`ground_contact`）、**超时**（`timeout`，时限内什么都没发生）、
  **低于下滑道**（`below_glidepath`，飞行中掉到了下滑道下沿以下；只有带程序高度屏蔽的 augmented 才会判出这一类，base 没有这个屏蔽，所以恒为 0）。精确判据见 `autopilot/judge.py`。
- **成对差**：同一架航班、同一个随机数种子（每换一种读法，生成器都按同样的种子重来），换向量后的量减去 own 的量；
  **标准误（±）** 是按航班算的（NLL 用比值估计量：n·var(d)/(总步数)²，每架的步数当作固定）。差的绝对值大过 2 倍标准误才当作有差别。
- **直进（straight-in） / 引导（vectored）**：按**观测到的**那条航迹分的组——路径迂回度（实际走的弧长除以到入口的直线距离）小于 1.05 的是直进，
  其余没有建立在五边上的是引导（`data/approach_difficulty.py`，全项目同一个定义）。
- **百分点**：份额的差。**机场向量的长度** 用欧氏长度。

## 5 怎么读（我的读法，不是量出来的事实）

1. **先验确实靠"知道自己在哪个机场"**。去掉机场自己的向量（others）损失每步 +0.024 / +0.028，落地少 5.8 / 8.0 个百分点；
   这比项目里以前当作有意义的差（M1 +0.0077，场景模型 +0.004）大约 2–7 倍（换成平均 +0.015 / +0.018 对 +0.0077 是 2.0–2.3 倍，对 +0.004 是近 4–5 倍；其余更大）（只是数量级参照，见 §2.4）。
2. **给 KAUS 平均向量，在训练机场上的代价已是落地少约 2–5 个百分点**（base −2.2，augmented −4.9），NLL 约 +0.015–0.018。
   但这是个**偏乐观的下界**：（a）平均里有五分之一是自己，余弦 0.40–0.54，保留了一部分自己机场的方向；真正的 KAUS 不在这五个机场里，平均里没有一点 KAUS；
   最接近的参照其实介于 mean 与 others 之间，更靠 others（我的估计，没有量化）。（b）平均向量长度只有训练见过的一半，模型从来没见过这种输入。
   所以 KAUS 用平均向量读出的数，量的是**"一个靠认机场来表现的模型，在一个它认不出来的机场上"**，是没有机场向量的模型在 KAUS 上能做到的一个**下界**——
   这里"下界"是我的读法：若有一个训练时就没有机场向量的模型，它的表现应不低于这个，但**本读数没有训练过那样的模型，所以这不是量出来的**
   （换掉向量是在训练好的模型上做的，模型是围绕这个向量训练的；从头不带它训练的模型可能把一部分损失补回来，也可能补不回来，不知道）。
3. **损失不均匀**：KSMF、KMSY（两个模型里都是）丢得最多，KSJC、KRDU 最少。可能的原因（我的读法，没验证）：KSJC 的落地本来就近乎饱和；KRDU 的航向列损失最小。
   KSMF、KMSY 可能是引导航班更多、更需要机场特有的转弯习惯（只是猜测：本读数没有按机场拆直进 / 引导，没有量）。
4. **向量里学到的是什么，不清楚**：向量几乎垂直（§4），是一张独立的编号表。它可能学进了这个机场的转弯习惯、进近走法、爬降偏好等，也可能是数据里与机场混在一起的别的东西
   （例如该机场验证集的气候、机型构成、飞行日分布）。**换到 KAUS，它被迫去认的是一个它没见过的混合体**。

## 6 这个读数不能说什么

- 只测了**换掉**，没有测"不带向量训练"：后者是另一个模型（一次训练，且用户 2026-09-26 说过 base 不重训）。
- 逐机场的落地差每格只有 400 架航班，标准误 0.5–1.3 个百分点；机场之间的排序（谁丢得多）在差不到一倍的地方不可信（例如 base mean 下 KRDU −1.06 与 KSJC +0.38 与 KSTL +0.69 都看不出差别）。
  NLL 的差有 190 万步支持，逐机场也很稳。
- 一个模型、一个训练种子、一次抽样种子；没有看不同种子下机场向量的角色是否一样。
- 验证集不是 KAUS：KAUS 的跑道布局、交通组合、气候都与五个训练机场不同，这里量的"代价"不能直接转成 KAUS 上的数。
- 没有量别的"机场标识"途径：五个机场的跑道几何仍进模型（候选跑道表），所以去掉向量后模型仍靠几何认出一部分机场；others 的损失是"去掉向量"的代价，不是"完全不知道机场"的代价。
