## 读数（只陈述事实，不套判据）

1. 在训练见过的机场上，新基础模型能让 90.3% 的航班落地。这里的“落地”用的是评估包的判定，比旧判定严。
2. **在没见过的机场上，落地率大幅下降**：C 只有 62.8%，A 是 50–55%；旧版是 83–86%。而且波动很大：
   - KRDU 三组都只有 24–31%（旧版 75–85%）；
   - 同一个配置 A 换个种子，KSMF 从 61.3% 变成 30.1%，KMSY 从 53.8% 变成 81.6%。

   KAUS 是留出的测试机场，模型在它上面要做的正是这种“没见过的机场”，所以这一点直接关系到最终测试。
3. **失败几乎都是“评估判为未降落”（landing_failed），而且直进航班也一样。**

   | 折 | 直进：落地 / 评估判未降落 / 共 | 引导：落地 / 评估判未降落 / 共 |
   |---|---|---|
   | C，KRDU | 58 / 127 / 198 | 45 / 80 / 164 |
   | A 种子 2024，KRDU | 52 / 136 / 198 | 34 / 96 / 164 |
   | A 种子 2024，KSMF | 56 / 117 / 186 | 56 / 113 / 186 |
   | C，KSMF | 146 / 9 / 186（另有动力学失败 25） | 146 / 18 / 186 |

   - 每句的词数和标注句相近。例如 C 在 KRDU 直进，航向词 37 对 33，下滑角词 19 对 22。也就是说，模型说的词的种类和数量都正常，飞机也飞到了跑道，但最后没有通过评估包的降落判定。
   - 旧版 C 在 KRDU 直进的失败只有超时 6、触地 4 等，落地 201/214。
   - 在见过的机场（基础模型 val）上，“评估判未降落”只占 5.3%（102/1,914）。

   还没查是评估的哪一条没过（横向、垂直、速度，还是稳定进近），要查需要重新判定这些句子。猜测（未验证）：v17 的修正词更细（D197–D199），对着陆末段精度的要求更依赖具体机场；换到没见过的机场，末段偏差超出了评估的容差。
4. 对照的配置选择（C）在两种量法（损失、落地率）下一致，都是 C 最好。
