# B19：v19 标注 + D204 输入上的先验交叉验证（2026-10-14）

## 跑了什么

- **为什么跑**：用户 10-14："检查完毕后，再跑一遍CV，如果确认效果更好了，那么就在新的标注数据上跑base模型的正式训练"；
  "/100 是定了的，一起上"。检验的是 D203 的新标注（五边上垂直修正对准下滑道、修正持续到入口），同时带上已定的 D204（横向
  偏移输入按 100 m 尺度）。
- **活动**：`prior_campaign`，从运行工作树 run-b19（`1bac2c38`，分支 `two-tier2-glidepath`）启动，单元 `prior-b19`。
- **输入**：`v19_20261014` 标注、`v24_20261014` 执行器，每行 4 s。
- **交叉验证**：每次留出一个机场，5 个机场；配置 A 种子 1337、配置 C 种子 1337、配置 A 种子 2024（与 B15/B16 相同）。
- **停点**：选完配置就停（`stop_before_base.sh`）；base 训练和它读 val 的那一次，只在折的结果确认更好之后再跑。
- **数据**：`4dTrajectory/outputs/POOLED/prior/prior_b19_20261014`；每折对比 `prior_b19_20261014.run/fold_summary.py`。
- **结论**：折在留出机场落地 80–85 %（试验 80.2 %，B16 47.0 %），配置 A；B19 的 base 是跑满 30 轮的那个（`prior_b19_base30_20261014`，用户 10-14 选定），val 落地 **93.0 %**（B15 的 base 90.3 %）。13 轮早停的 base 只作记录。

试验（`prior_lateral100_20261013`）= v18 标注 + 同样的 D204 输入，所以这一组的差别只来自标注。只算"标注句本身能落地"的

| KMSY | 85.7 % | 84.8 % | 29.3 % |
| KRDU | 85.0 % | 71.2 % | 35.2 % |

- 评估门不合格：垂直 128 → 60，横向 101 → 45。
- 句子数不同：v19 的标注落地更多，`landed` 选进的句子更多。
- KSMF 变差的地方在引导（vectored）航班：超时 10 → 22（多数停在离跑道 10–90 km 处，没飞回来），触地 16 → 24；五边的门
  不合格反而更少（横向 12 → 8，垂直 23 → 13）。D203 只改五边的标注，引导段的标注与 v18 逐字节相同。
- 停训的轮次不同：试验 KRDU 第 22 轮停，B19 跑满 30 轮；B19 KSJC 第 24 轮停，试验跑满 30 轮。

### 3. 配置选择：A

分数是留出机场 select 日每步预测损失的平均（越低越好）；规则 D40：落在最好分数加两倍种子尺度以内的配置里选参数最少的。

| 组 | 分数 | 参数 |
|---|---|---|
| C 种子 1337 | **1.492** | 381 万 |
| A 种子 1337 | 1.544 | 217 万 |
| A 种子 2024 | 1.571 | 217 万 |

种子尺度 0.028；A 和 C 都在范围内，选 A（B15 选的是 C）。损失比 B15 低很多（C 1.981 → 1.492），因为 v19 的句子里角度
词少了约三分之一（train，Δ = 4 s：每句 25.7 → 16.5），要预测的词变了；不同标注集之间的损失不能比。
