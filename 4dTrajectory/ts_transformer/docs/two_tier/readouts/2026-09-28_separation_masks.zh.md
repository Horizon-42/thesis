**一句话**：多机闭环里的两条间隔屏蔽——速度词、进近许可——放在训练集运行日的记录上，会拿掉 **0.32 %** 的标注速度词和许可词（每个机场都
不超过 1 %，最多 KSJC 0.98 %），过第 0 步第一条通过线（≤ 1 %）。用户 2026-09-28 定：按合计判，两条屏蔽在五个机场都硬用；预判所有速度词都保不住

## 1 两条屏蔽是什么、怎么量

**两条屏蔽**（`inference/separation_masks.py`；按用户定的放法，§9 第 18 项：由场景闭环算好每架这一步允许的词交给说话器，先验包的导入规则不动）。
两条都只看同一条跑道（或当作一条的近距一对）上、进近时钟上紧挨在前面的那架：

- **速度词**：只在本机和前机都已建立在五边上、本机离入口还超过 9,260 m（5 NM 以内不指定速度）时用。两架从此刻起各自以执行器的速度律 0.25 m/s²
  趋向各自生效的速度目标、沿各自的航道飞，预判到前机过入口的那一刻；那时后机离前机不够规章要求的距离（`Separation.distance_nm`：雷达 3 NM 或
  TBL 5-5-2，取大；与边特征里给模型的是同一个量）的速度词屏蔽掉。生效的词已经不够时，"不变"也屏蔽（必须说一个新词）。**所有速度词都不够时
  （兜底），什么都不屏蔽**（用户 2026-09-28，§9 第 20 项）：那时"留下的距离最大"的永远是词表最慢的一档 20 m/s，比任何机型的失速速度都低，
  逼模型说它没有意义；这时让模型照自己的分布说，交给事后检查。
- **进近许可**：本机与最近的、已许可的前机在进近时钟上相隔不足一前一后的最小距离（雷达 3 NM 或 TBL 5-5-1，取大）时，不许说"许可"，继续引导。

**预判是近似**，写明了：不算转弯、下降、风对速度的影响，也不算执行器"未指定速度"下为在入口前减到进近速度而加大的减速（对这样的前机偏乐观）。

**怎么量**（`experiments/traffic_masks.py`，R27）：训练集运行日、每个机场的记录场景放在闭环的步上——每架有句子的航班照它记录的行（`traffic_loop.recorded`，
每架先用标注器重读、与存下的句子逐词核对），背景到达照记录回放。每架从第一个预测步（第 8 行，先验在这一步说每一列）起逐步查，计数口径与程序高度那一次
（`prior_procedure_check`）相同：

- **速度词**：第 8 行生效的词，加上之后说的每一个速度词；
- **许可词**：第 8 行生效的"许可"，加上之后说的每一个"许可"；
- **被迫换词**（单列，不进通过线）：之后没说速度词、但生效的词被屏蔽的步——屏蔽会逼先验说一个新词；
- **兜底**：所有速度词都不够的检查次数。

每架的速度目标取它生效的词：速度词取它的值；"未指定"取它机型公布的进近速度（`autopilot.speed.approach_speed_ias_mps`，最大着陆重量下的值，
当作沿航道的速度）；机型没公布的、背景飞机（没有词），保持当前速度。谁"已许可"：生效的进近词；背景飞机从建立在五边上起算已许可。

## 2 通过线

| 机场 | 标注的速度词：被屏蔽 | 标注的许可词：被屏蔽 | 合计 | 过线（≤ 1 %） |
|---|---|---|---|---|
| KMSY | 5 / 12,833（0.04 %） | 2 / 4,857（0.04 %） | 0.04 % | 过 |
| KRDU | 25 / 45,970（0.05 %） | 22 / 14,296（0.15 %） | 0.08 % | 过 |
| KSJC | 125 / 20,181（0.62 %） | 172 / 10,024（1.72 %） | 0.98 % | 过 |
| KSMF | 4 / 16,250（0.02 %） | 28 / 5,610（0.50 %） | 0.15 % | 过 |
| KSTL | 64 / 28,902（0.22 %） | 92 / 9,576（0.96 %） | 0.41 % | 过 |
| **合计** | **223 / 124,136（0.18 %）** | **316 / 44,363（0.71 %）** | **0.32 %** | **过** |

- 这是兜底不屏蔽以后的数（`masks_v2_20260928`）。兜底照设计原文留最慢一档时（`masks_20260928`，已被取代）合计 0.39 %，KSJC 1.19 % 超线；
  那时用户定按合计判（§9 第 19 项），随后又定兜底不屏蔽（§9 第 20 项）。
- **KSJC 的许可词最多**：172 个里 77 个在近距一对 30L/30R 之间——记录里管制员让两条跑道并排放行，靠的是目视间隔；这一对按一条跑道判（7-4-4 c1 (b)
  要目视间隔，我们的词表说不出），所以许可要等前面那条上的飞机拉开 3 NM。与第 5 步里记录本身就失去间隔同源（设计 §3.2"模型因此比记录严"）。
  KSTL 的 92 个里 28 个在两对平行跑道之间，其余都在同一条跑道上。

## 3 预判准不准

- **拿记录对**：每次速度检查，把"生效的词"预判的距离，与这一对在前机真正过入口时的实际距离比（前机的过入口时刻按它自己最后一行推到入口）。
  五个机场的中位数差 −60 到 +4 m；5–95 % 在约 ±1 km 以内（KSTL −1,120 到 +745 m，KSJC −1,086 到 +1,113 m）。
- **被屏蔽的词，记录后来真的不够吗**：223 个被屏蔽的速度词里 44 个——这一对在前机过入口时确实不足规章距离；其余的，管制员后来又说了别的词（或飞行员
  自己减速），而预判假设"此后不再说词"，所以屏蔽偏严。这正是屏蔽的用意：此刻说这个词、以后不再调整就一定违规的，拿掉。

## 4 被迫换词与兜底

| 机场 | 被迫换词（没说速度词、生效的词被屏蔽的步） | 兜底（所有速度词都不够的检查） |
|---|---|---|
| KMSY | 362 / 44,233（0.82 %） | 123 / 45,282（0.27 %） |
| KRDU | 1,264 / 148,307（0.85 %） | 788 / 151,810（0.52 %） |
| KSJC | 5,198 / 216,011（2.41 %） | 5,826 / 220,909（2.64 %） |
| KSMF | 405 / 26,147（1.55 %） | 468 / 26,664（1.76 %） |
| KSTL | 6,112 / 110,218（5.55 %） | 6,390 / 112,347（5.69 %） |
| 合计 | 13,341 / 544,916（2.45 %） | 13,595 / 557,012（2.44 %） |

- 被迫换词不进通过线（与程序高度那次的第 5 条规则同样单列）。KSTL 最多：记录里同一条五边上的一前一后常常只比 3 NM 多一点（上一步普查：要 3 NM 的，
  最近时仍有 2.5 NM 以上的占多数），生效的速度一保持，预判就不够。
- 兜底时屏蔽让开，交给事后检查（第 1 层）。多机闭环里这些步上模型照自己的分布说；失去间隔由检查结束那一架。

## 5 用户定的事（2026-09-28）

- **第一条通过线按合计判，两条屏蔽处处硬用**（§9 第 19 项，选了建议的做法）：当时合计 0.39 % 过、KSJC 1.19 % 超；KSJC 超出的一半在近距一对上，与第 5 步
  同源。另一个做法（按机场判，KSJC 的屏蔽只作奖励或读数）不用。
- **兜底时不屏蔽**（§9 第 20 项，选了建议的做法）：另两个做法——只留不低于本机进近速度的最慢一档（逼它"减到进近速度"）、照设计原文留最慢的几档——不用。
