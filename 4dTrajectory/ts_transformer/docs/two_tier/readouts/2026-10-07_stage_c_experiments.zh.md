# 阶段 C 的后续实验日志

C10 之后在同一个设计内做的后训练实验：每个实验的意图、设置、结果和结论，以及下一步。
设计上的决定见 `design/post_training.md`，代码和运行细节见 `readouts/2026-10-05_stage_c_implementation_log.md`（§27–§29）。
所有读数都在同样 1,000 个 select 窗口上，用同样的随机数（读数种子 1337），可以逐轮直接比较；
1,000 个窗口的落地比例本身约有 ±1.2 个百分点的随机波动。

## 背景：C10 和上限读数

- **C10**（`post_train_20261006`，分支训练，K = 8，14 轮）：落地 80.2 %（第 0 轮）→ 85.1 %（第 6 轮）→ 85.7 %（第 8 轮，最好）。
  从第 6 轮起不再上升（日志 §26–§27）。
- **上限读数 C15**（`ceiling_20261007`）：每个窗口说 32 次时，99.3–99.4 % 的窗口至少有一次能落地；只说一次时是 79.5–85.7 %。
  也就是说模型说得出落地的话，只是给它们的概率不够（日志 §28）。

## 实验 1：只学落地的句子（C17，`post_landed_20261007`）——已停止

**意图**：分支训练在 85 % 左右停住以后，换一种训练方法，试试能不能把"一次说对"的比例往"试 8 次"的 98 % 推。
每轮每个窗口说 8 次，只留奖励最高的那句落地句子，用它的负对数似然训练（加拉回 base 和单机数据项），没有负信号。
用户 2026-10-07 接受（P49 / D165），从 C10 第 8 轮出发。

**设置**：起点 C10 第 8 轮（D162），种子 2024，读数种子 1337；每轮 4,000 个 train 窗口（真实、A、D、B 各 1,000）；
每个窗口 8 次（`--continuations 8`）；每次更新 16 句落地句子 + 64 句单机数据；学习率 1e-5（先验）/ 1e-4（交通模块），
权重衰减 0.01，拉回 base 0.04，数据项 1；计划 6 轮。CPU 上 16 个说话 worker，主进程单线程训练，每轮约 41–46 分钟。
运行工作树 `run-post-landed`（`61e718ba`）。

**停止**：用户 2026-10-07 定的规则是"这一轮如果还是平的就停"。我定的"平"是：第 3 轮的落地比例不明显高于起点，
即低于 85.7 % + 1.2 = 86.9 %。第 3 轮是 85.1 %，13:21:47 自动停止，第 3 轮完整保留，刚开始的第 4 轮移到一边。
第 2 轮曾在训练中途被终端关闭时的 systemd 作用域杀掉，从第 1 轮的检查点续跑过（日志 §29）。
数据只读，`SHA256SUMS` 78 个文件，`logs/` 里有两次运行的日志和启动脚本。

**结论（我的读法）**：4 轮都在起点的噪声内，没有效果。可能的原因：
- 91 % 的窗口都留下一句，其中大多数是模型本来就常说的话，学它几乎不改变什么；真正有用的难窗口被冲淡了。
- 每轮挪动很小：KL 只从 0.029 升到 0.033；单机数据项的大小和落地句子损失差不多，约一半的梯度在拉回单机说法。
- 落地句子损失一直在 1.06–1.08，没有下降：学的都是当前模型自己说出来的新句子，它们的概率本来就不低。
- 整句平均地学，避开冲突的关键几个词的信号被稀释。

## 实验 2：分支训练加大 K（K = 16）——下一步，优先

**意图**：用户 2026-10-07 定为下一步。C10 的分支训练里约一半的分支组 8 个续句结局全一样，没有信号；
把每个分支点的续句从 8 个加到 16 个，有信号的组更多（例如从某点出发成功率 0.9 时，整组没信号的概率从约 43 % 降到约 19 %），
难的分支点更容易找到那一两个成功的续句，基线也更准。问题：信号更多以后，分支训练能不能越过 C10 的 85 %。

**设置（计划）**：`post_train --method branch --continuations 16`，起点 C10 第 8 轮（D162），种子 2025，读数种子 1337，
其余同 C10（每次更新 4 个分支组 + 64 句单机数据、学习率 1e-5 / 1e-4、权重衰减 0.01）；6 轮。
说话用 CPU 上 16 个 worker，训练在主进程的 GPU 上（`--speak-device cpu --device cuda`，代码在审查中）。

**预计**：说话时间约是 K = 8 的 1.7–1.8 倍；每组 17 句，训练的每一块内存约翻倍。

**状态**：等 `--speak-device` 审查完、合并后，从运行工作树启动。
