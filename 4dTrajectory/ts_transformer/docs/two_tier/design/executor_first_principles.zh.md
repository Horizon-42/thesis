# 执行器设计：从第一性原理出发（草案 5）

状态：草案。日期：2026-10-11。写作规则：简明技术中文（ASD-STE100 风格）。

本文不参考任何旧的执行器代码或旧的执行器设计。依据只有三项：词的定义、动力学方程、已经有明确值的模型值。

**草案 5 的改动：** 速度词也加提前量 L_v（D8，替代 D1）。三列的提前量各自测量后再定（V12）。

**草案 4 的改动：** 纵向律（§7）重写。角度词加提前量 L_γ，这要求改词表（§17）。改出只用物理极限。"平飞"的路径角为 0。删除由管子推出的 γ̇_c。倾斜角上限加入失速。加"已捕获"标志。

## 0. 范围与规则

### 0.1 本文回答的问题

执行器听到一串词。它必须让飞机飞出这些词所说的航迹。本文给出执行器怎样做这件事。

### 0.2 信息规则（唯一）

执行器只能使用下列信息。

| 编号 | 信息 | 说明 |
|---|---|---|
| I1 | 已经听到的词 | 每一列当前生效的词，和听到它的时刻 |
| I2 | 自己的状态 | 高度、空速、航迹角、路径角、质量，和自己对作动器的估计 |
| I3 | 机体数据 | 气动参数、安装推力、型号的进近速度 |
| I4 | 词所指的地图数据 | 生效跑道的航道、机场标高。只用来把词换算成绝对值 |

执行器不得使用下列信息。

| 编号 | 禁止的信息 |
|---|---|
| X1 | 未来的词 |
| X2 | 观测航迹 |
| X3 | 飞机相对跑道中心线的偏离 |
| X4 | 下滑道的位置 |

**注意：** 执行器用 I4 只是把词变成数。它不用 I4 来修正位置。

### 0.3 限制规则

**规则 L1：** 执行器的限制只有两类。

| 类别 | 内容 |
|---|---|
| 物理极限 | 失速（C_L 不超过 C_L,max）、载荷系数范围、推力范围、倾斜角上限 arccos(cos γ / n_上)，n_上 = min(n_max, n_失速)，不超过可飞包络的 45° |
| 已有明确值的模型值 | 直接写入本文。不推导，不改 |

**规则 L2：** 本文不得加入第三类限制。需要时间尺度的地方，时间尺度必须由词的定义推出（§6、§7、§8）。词的公差（管子、包络）是验收标准，不是执行器的时间尺度。

### 0.4 本文不解决的问题

| 问题 | 原因 |
|---|---|
| 比 5° 一档更细的横向精度 | 词没有给出更细的信息。这是标注侧的问题 |
| 垂直偏离与下滑道平行 | 最后下降没有高度目标。这是词的定义 |
| 作动器时间常数的真实值 | 无法从 ADS-B 位置数据辨识（见 §9.2） |

## 1. 术语

| 术语 | 定义 |
|---|---|
| 周期 | 执行器的控制周期，Δt = 1 秒 |
| 指令 | 执行器发给作动器的值 |
| 实际值 | 作动器此刻的真实值 |
| 估计值 | 执行器用观测器推算的实际值，写作 â |
| 作动器 | 推力、倾斜角、载荷系数。各有一个一阶滞后 |
| 目标 | 词换算成的绝对值 |
| 观测器 | 执行器内部对作动器的推算。它只用自己发过的指令 |
| 管子 | 高度词的公差带，半宽 ε。只用于验收，执行器不读 |
| 提前量 | 词说出到它描述的时刻之间的时间。航向词 L，角度词 L_γ，速度词 L_v |
| 改出 | 从下降（或爬升）转为保持高度 T |
| 已捕获 | 执行器正在改出或保持高度目标（§7.6） |

符号：φ 倾斜角（向左为正），n 载荷系数，x 推力分数（占安装推力的比例），V 空速，γ 路径角（爬升为正），χ 航迹角，m 质量，g 重力加速度，h 高度（MSL）。

## 2. 动力学模型

执行器的全部反求来自下面的方程。

### 2.1 点质量方程（无风）

| 方程 | 含义 |
|---|---|
| V̇ = (x·T_max − D) / m − g·sin γ | 沿航迹的加速度 |
| γ̇ = (g / V) · (n·cos φ − cos γ) | 路径角变化率 |
| ω = g · n · sin φ / (V · cos γ) | 转弯率（向左为正） |
| ḣ = V · sin γ | 高度变化率 |

阻力：D = ½·ρ·V²·S·(C_D0 + k·C_L²)。升力系数：C_L = n·m·g / (½·ρ·V²·S)。

失速：C_L 大于 C_L,max 时，飞机失速。

### 2.2 作动器方程

每个作动器 a 服从：**ȧ = (u − a) / τ**。u 是指令，τ 是时间常数。

周期内指令保持不变，则：

**a(t + Δt) = u + (a(t) − u) · e^(−Δt/τ)**

### 2.3 模型的已知缺口

| 缺口 | 影响 |
|---|---|
| C_D0 不随构型变化 | 稳定进近的推力偏低。减速能力由推力下限等效 |
| 没有风 | 空速等于地速 |
| 时间常数是假设值 | 见 §9.2 |

## 3. 总结构

每个周期，执行器按下列顺序做事。

1. 更新观测器（§4）。
2. 把词换算成目标（§5）。
3. 横向律：选倾斜角（§6）。
4. 纵向律：用已选的倾斜角，选载荷系数（§7）。
5. 速度律：用已选的载荷系数，选推力（§8）。
6. 作动器反求：把想要的实际值换成指令（§4.3）。
7. 发出三个指令。

**规则：** 顺序不得改变。载荷系数依赖倾斜角。推力依赖载荷系数。

## 4. 观测器与作动器反求

### 4.1 为什么需要观测器

三个作动器都有滞后。指令发出后，实际值要几秒才到位。执行器读不到实际值。

执行器知道自己发过什么指令。它用 §2.2 的公式推算实际值。时间常数已知时，这个推算是精确的。

### 4.2 观测器的更新

每个周期发出指令 u 之后，三个作动器各做一次：

**â ← u + (â − u) · e^(−Δt/τ)**

初始值：倾斜角 0，载荷系数 1，推力 = 第一周期所需的推力。

### 4.3 作动器反求

执行器想让作动器在周期末到达 a\*。指令按下式算：

**u = (a\* − â · e^(−Δt/τ)) / (1 − e^(−Δt/τ))**

然后把 u 限制在该作动器的范围内（物理范围）。

### 4.4 倾斜角

倾斜角的变化率，上限是 p。

1. 横向律给出想要的倾斜角 φ\*。
2. 滚转率：ρ = clip((φ\* − φ̂) / Δt，±p)。
3. 指令：u_φ = φ̂ + τ_φ · ρ，限制在 ±φ_phys 内（§6.4）。

周期内的平均滚转率：**p_mean = p · τ_φ · (1 − e^(−Δt/τ_φ)) / Δt**。τ_φ = 2 秒时，约 0.79 p。

## 5. 词到目标

| 列 | 词 | 目标 |
|---|---|---|
| 跑道 | 跑道 R，或"复飞" | R 的航道、机场标高 E。复飞状态 G |
| 航向 | 相对 R 航道的一档（5° 一档） | 绝对航迹 χ\* = 航道 + 档值，在听到的时刻锁定 |
| 高度 | 标高 E 以上的高度 T，或"no level-off" | H\* = T + E（MSL），或无目标 |
| 角度 | 下降类别、平飞、爬升 | 名义路径角 γ_k（类别的中心值）。平飞：γ_k = 0 |
| 速度 | 地速档值，或"unspecified" | V\*（见 §8.1），在 t_听到 + L_v 到达（R5.5） |

**规则 R5.1：** 航向词在听到时，用当时生效的跑道航道换算。之后只改跑道，不改 χ\*。

**规则 R5.2：** 航向词的含义是"听到后 L 秒，航迹到达 χ\*"。到达时刻 t_a = t_听到 + L。

**规则 R5.3：** 角度词的含义是"听到后 L_γ 秒，路径角到达 γ_k"。到达时刻 t_γ = t_听到 + L_γ。修正器加的角度词含义相同。这一规则要求改词表（§17）。

**规则 R5.4：** 高度词给出目标 T。方向由 T 和当前高度决定，陡度由角度词决定（词表 §3.4）。高度词没有到达时刻。

## 6. 横向律

### 6.1 目标

在 t_a 时刻，航迹到达 χ\*，倾斜角回到 0。

### 6.2 步骤

设 e 为航迹误差（χ\* − χ，取 ±180° 内），T_left 为到 t_a 的剩余时间。

1. 想要的转弯率：r = e / max(T_left，Δt)。一个周期是执行器能行动的最短时间。
2. 想要的倾斜角：φ_want = atan(V · r / g)，限制在 ±φ_phys 内（§6.4）。
3. 停止边界：φ_stop（§6.3）。
4. 目标倾斜角：φ\* = sign(e) · min(|φ_want|, φ_stop)。
5. 滚转率和指令：按 §4.4。

### 6.3 停止边界（精确公式）

倾斜角 φ 以速率 p_mean 收回至 0。收回期间飞机继续转：

**Δχ_收回 = g · (−ln cos φ) / (V · p_mean)**

要求收回后不过冲，即 Δχ_收回 不超过周期末剩余的误差 e'：

**φ_stop = arccos(exp(−e' · V · p_mean / g))**

e' = max(e − ω·Δt, 0)，当飞机正在向目标转时。背离目标转时，e' = e + |ω|·Δt。

**说明：** 公式用估计的实际倾斜角 φ̂。倾斜角还在增长时，不会被当成已经到位。

### 6.4 限制

| 限制 | 值 | 类别 |
|---|---|---|
| 滚转率 p | **15°/s** | 已有明确值（本项目的决定） |
| 倾斜角上限 φ_phys | min(arccos(cos γ / n_上), φ_包络)，n_上 = min(n_max, n_失速(V)) | 物理极限；φ_包络 = 45° 是已有明确值（可飞包络 `geometry.flyability.Envelope`，评分器用的同一个值） |

n_失速(V) = ½·ρ·V²·S·C_L,max / (m·g)（§7.5）。φ_phys 是飞机还能保持路径角的最大倾斜角。

**为什么加入失速：** 只用 n_max 时，φ_phys = 60°。但 V = 1.3·V_s 时，n_失速 ≈ 1.69，保持平飞的倾斜角只有约 54°（1.23·V_s 时约 49°）。倾斜角在两者之间时，§7 的载荷系数被限住，飞机掉高度。保持高度时修正器不修正（词表 §4.9），这个误差会留下来。加入失速后，倾斜角受限，损失的是转弯率，不是高度。转弯慢了，航向的修正词可以补。

与 45° 的包络一起，失速项只在 n_失速 < 1/cos 45° ≈ 1.41 时起作用，即空速低于约 1.19·V_s(1 g)。进近速度（V_REF 约 1.23·V_s 以上）不触发它；速度词可以低到失速本身（D3），那时它起作用。

**本设计没有 32° 的倾斜角上限。** 32° 是词表规格里的值。它来自真实转弯的统计，是标注器判断一个词是否合格的标准。它不是执行器理解词所必须的值。

本设计没有单独的转弯率上限。转弯率由倾斜角和速度决定：ω_max = g · tan φ_phys / V。

**警告：** 去掉 32° 之后，倾斜角在极少数情况下可以超过 32°。验证项 V7 测量它。

## 7. 纵向律

### 7.1 原则

纵向律与横向律同构。时间只来自词。限制只有物理极限。

| | 横向（§6） | 纵向（本节） |
|---|---|---|
| 词给的目标 | 航迹 χ\* | 路径角 γ_k（角度词），高度 T（高度词） |
| 词给的时间 | 提前量 L：t_a = t_听到 + L | 提前量 L_γ：t_γ = t_听到 + L_γ（R5.3） |
| 想要的变化率 | r = e / max(T_left, Δt) | γ 的坡道：剩余的变化 ÷ max(T_γ, Δt)（§7.2） |
| 不过冲的边界 | φ_stop，由滚转率 p 推出 | γ_stop，由载荷系数的物理极限推出（§7.3） |
| 物理极限 | φ_phys | n_min、n_上 = min(n_max, n_失速) |

本节不使用管子半宽 ε，也不使用由它推出的任何速率。

### 7.2 角度词：坡道

设角度词生效，带符号的名义路径角为 γ_k（下降为负，爬升为正，平飞为 0，复飞时为 +γ_GA）。T_γ = t_γ − t 为到达时刻前的剩余时间。

周期末想要的路径角：

**γ_w = γ + (γ_k − γ) · Δt / max(T_γ, Δt)**

意义：剩余的变化平均分到剩余的时间里。到达时刻之后，T_γ ≤ Δt，执行器在一个周期内到达（受物理极限限制）。

例（L_γ 还没有测量，此处只是示例）：L_γ = 6 秒，平飞→3°，坡道 0.5°/s。在 70 m/s 时需要 Δn ≈ −0.06 g。

**平飞：** γ_k = 0。执行器不追高度 T。实测：官方闭环 40,534 句中，"平飞"角度词出现 6,442 次，全部在第 0 行。那时 T 是当前高度取整到网格的值，取整误差在管子以内（词表 §3.4）。

### 7.3 改出：物理停止边界

有高度目标时（不是"no level-off"），设 e_h = h − H\*（高于目标为正），e' = 周期末预测的 e_h（按当前路径角飞一个周期，与 §6.3 的 e' 相同做法；按 γ_w 预测时，捕获后 γ_w 等于类别角，会把剩余高度预测为 0，飞机停在目标上方）。

**停止下沉 S(γ)：** 从路径角 γ 和当前的估计载荷系数 n̂ 出发，指令取停止方向的极限（停止下降取 n_上，停止爬升取 n_min），用 §2.1 和 §2.2 的方程积分到 γ = 0，所经过的高度变化。S 包含载荷系数作动器的滞后。

**停止边界：** γ_stop = 使 S(γ) ≤ |e'| 成立的最大 |γ|。S 随 |γ| 单调增大，所以 γ_stop 唯一。

实现用闭式近似（审查后定）：把载荷系数的滞后看成纯延迟，再加一个周期 Δt，τ_d = τ_n·(n_c − n̂)/(n_c − n_平) + Δt。加 Δt 的原因：执行器每个周期才决定一次，停止最多晚一个周期开始；不加时，目标附近高度环的时间常数小于周期，离散环有一个根落在 −1 之外，保持高度时持续振荡（实测 ±2 米、±2°）。S(γ) = V·τ_d·sin γ + V·(1 − cos γ)/a，由 S(γ_stop) = |e'| 解出 γ_stop。近似在每个方向上都保守：滞后当作延迟（实际改出更早结束）；a 和 τ_d 取改出过程中最小的值（拉起取 γ = 0 处，推下取当前 γ 处）。单元测试 T7 用积分检查它：保守；除去有意加上的一个周期（V·Δt·sin γ），多留的高度小于 2 米（实测 0.6 到 1.9 米）。

例：V = 70 m/s，n_上 = 2.0，τ_n = 0.8 秒，Δt = 1 秒。3° 下降在 T 以上约 7.3 米开始改出：其中约 0.7 米来自 a，约 6.6 米来自作动器滞后和一个周期。实测（75 m/s，4.5°）在约 16 米处开始，向下过冲不超过 0.2 米，之后稳定在 T。

**说明：** 改出是"最后时刻、用尽物理能力"的停止。它和词说的折线（直线下降，在 T 处转平）相差不到 1 米。每次改出时，载荷系数的限制都会起作用。这是 D6 的结果，不是错误。

### 7.4 路径角目标 γ_tgt

| 词的组合 | γ_tgt |
|---|---|
| 角度词"平飞" | 0 |
| "no level-off" + 下降类别 | γ_w |
| 有高度目标，未捕获 | −sign(e_h) · min(\|γ_w\|, γ_stop) |
| 有高度目标，已捕获（§7.6） | −sign(e_h) · min(\|γ_k\|, γ_stop) |

方向由 T 和当前高度决定，陡度由角度词决定（R5.4）。

### 7.5 内环与载荷系数

1. 想要的路径角变化率：γ̇\* = (γ_tgt − γ) / Δt。不加速率上限。
2. 周期内的平均倾斜角：φ̄ = (φ̂ + φ̂_周期末) / 2。φ̂_周期末 由 §6 已选的倾斜角指令，按 §4.2 的公式预测。
3. 想要的载荷系数：n\* = (γ̇\* · V / g + cos γ) / cos φ̄。
4. 限制在 [n_min, n_上]。
5. 作动器反求（§4.3）。

**物理极限：**

| 极限 | 值 | 类别 |
|---|---|---|
| 载荷系数范围 | n_min = 0.5，n_max = 2.0 | 已有明确值（可飞包络） |
| 失速 | n ≤ n_失速 = ½·ρ·V_末²·S·C_L,max / (m·g) | 物理极限。V_末 = V + V̇·Δt 是周期末的预测空速，V̇ 由观测器的推力和载荷系数算出。载荷系数在周期末才到位，所以要守的是周期末的失速（实现中发现：用周期初的速度时，复飞拉起会在周期末失速） |

**说明：** 第 3 步用预测的实际倾斜角，不用指令的倾斜角。倾斜角升高时，载荷系数同步升高，飞机不会掉高度。§6.4 的 φ_phys 保证这一点总能做到。

### 7.6 已捕获

修正器要读这个标志：保持高度时，修正器不说角度修正词（词表 §4.9 第 1 条）。

| 规则 | 内容 |
|---|---|
| 变为真 | 角度词"平飞"生效；或有高度目标，并且停止边界起作用（γ_stop < \|γ_w\|） |
| 保持 | 直到听到新的高度词或新的角度词（含修正词）。这与词表 §5.5 相同 |
| 变为假 | 听到新的高度词或角度词时。下一个周期按上表重新判断 |

**说明：** 已捕获时，新的角度词使标志变假。如果 T 没有变，飞机仍在 T，停止边界马上又起作用，标志又变真。所以"同一高度上的下降类别"等于保持高度。

### 7.7 复飞的爬升角

γ_GA 由推力决定：

**sin γ_T = (x_max · T_max − D) / (m · g)**

γ_GA = clip(γ_T，1.885°，3°)。1.885° 是公布的最小复飞梯度（每海里 200 英尺）。3° 是已有明确值（词表文档 D28，本项目的决定）。推力给不出时，推力上限起作用。

### 7.8 为什么删除草案 3 的 γ̇_c

草案 3 用 γ̇_c = V·γ_s² / (2ε)（70 m/s 时 0.31°/s）作为所有路径角变化的速率上限。删除它的原因：

1. **它只为改出推导，却限制了全部变化。** 推下（平飞→下降）和修正词也被它限住。平飞→3° 要 9.7 秒，飞机比词说的线高约 18 米，大于 H_final = 7.5 米（词表 D66）。
2. **"由管子推出"不成立。** 管子是允许的范围，不是控制律。任何在 ε 以内开始、单调到达 T 的改出都在管子里。"最陡类别恰好在边缘开始"只是一个选择。ε 还含标注器 10 米的拟合容差，而且随高度层变化（词表 D52：40/70/235 米）。
3. **"平飞"一行的上限 γ_s 永远起不了作用：** |e_h| ≤ ε 时，√ 项不大于 γ_s。

**实测（官方闭环，train，Δ = 2 秒，40,534 句）：**

- 角度修正词共 433,541 个，每句 10.7 个。99.7% 的航班至少有一个。
- 观测的平飞→下降角度词 6,397 次。e_h（飞出 − 观测）的中位数：词前一行 13.7 米，词所在行 20.2 米，词后 6 秒 28.5 米。词后 2 到 6 秒，\|e_h\| > 15 米的占 73% 到 75%。
- 52% 的"变陡"观测词后面跟着一个"更陡"的修正词，中位数间隔 2 秒。

**角度词说得晚（这是 §17 的依据）：** 选执行器在词之前 10 秒一直平飞的 4,703 次平飞→下降。e_h 的增长就是观测飞机自己的下沉：

| 相对词的时间 | −10 秒 | −8 | −6 | −4 | −2 | 0 |
|---|---|---|---|---|---|---|
| 观测飞机已下沉，中位数（米） | 0 | 0.7 | 2.5 | 5.4 | 9.9 | 16.0 |

观测飞机在词之前约 6 到 8 秒开始推下。说出词时，它的下沉率约 3 m/s（约 2.5°）。原因：标注器在新一段的第一行说出角度词，而新一段只在飞机偏离旧的直线之后才开始。没有提前量时，执行器最早也只能在听到词时开始推下，所以会落后约 16 米。

脚本：`plant_comparison/` 下的 `angle_corr_timing.py`、`angle_corr_err.py`、`pre_word.py`，读 `instruction_language/v12_20261005/closed_loop/train_2s.npz`。输出在 `plant_comparison/angle_word_timing/`。

## 8. 速度律与推力

### 8.1 目标速度 V\*

| 词 | V\* |
|---|---|
| 地速档值 V_g | V_g / cos γ（无风，空速等于地速） |
| "unspecified" | max(V_REF · √max(n,1) · √(ρ_0/ρ)，V_stall(n)) |
| "unspecified" 且复飞状态 G | 听到复飞时的空速，保持不变 |

- V_REF：型号公布的进近速度（指示空速），按 √(m / MALW) 缩放。乘 √(ρ_0/ρ) 换成真实空速。
- √n 的依据：失速速度与 √n 成正比。V_REF 是 1 g 的参考速度。这是物理，不是设定值。
- V_stall(n)：失速速度，物理极限。本设计不加裕度。

### 8.2 速度变化率

#### 8.2.1 速度词的时间含义（D8）

**规则 R5.5：** 速度词的含义是"听到后 L_v 秒，空速到达 V\*"。到达时刻 t_v = t_听到 + L_v。"unspecified"也一样：它在 L_v 秒后生效。这要求改词表（§17 C8）。

依据：标注器在观测速度"离下一档更近"的第一行说出速度词。这与改动前的角度词相同：说出时，观测飞机已经在变速。没有提前量时，执行器最早也只能在听到时开始变速，所以总是落后。加提前量后，三列（航向 L、角度 L_γ、速度 L_v）的时间含义一致。

#### 8.2.2 想要的加速度

设 e_V = V\* − V，T_v = t_v − t 为到达时刻前的剩余时间。

**V̇\* = e_V / max(T_v, Δt)**

意义：与横向律（§6.2）和角度词（§7.2）同一条规则。剩余的变化平均分到剩余的时间里；到达时刻之后，执行器在一个周期内到达。

| 情况 | V\* |
|---|---|
| 速度词 | V_g / cos γ |
| "unspecified" | max(V_REF·√max(n,1)·√(ρ_0/ρ)，V_stall(n)) |
| "unspecified" 且复飞状态 G | 听到复飞时的空速 |

**唯一的限制是推力范围**（§8.3）。想要的减速度超过推力范围能给的，推力下限起作用。实际的减速度由动力学（推力、阻力、重力沿航迹的分量）决定。

**说明：** D8 替代 D1。草案 4 的"时间常数取行间隔 Δ_行"删除。速度律不再依赖行间隔。

#### 8.2.3 为什么不需要距离

"unspecified"的目标是一个速度值 V\*。从动力学反求：V̇\* 由 e_V 和到达时刻决定，x\* 由 §8.3 的精确反求给出。距离不出现在任何一步。

飞机从高速度减到 V\* 的快慢，由推力下限和阻力决定。执行器不需要知道"离门槛多远"。

**说明：** 去掉 a_max（1.4 m/s²）和 a_U（0.25 m/s²）。它们是标注器的合格检查值和词表的节奏值，不是执行器理解词所必须的值。

**警告：** 到达时刻之后，执行器在一个周期内消除速度误差，推力经常到限。这是物理极限在起作用，不是错误。验证项 V8 测量推力变化率。

### 8.3 推力

精确反求：

**x\* = (m · (V̇\* + g · sin γ) + D(V, n\*)) / T_max**

1. D 用 §7.5 得到的 n\* 计算。
2. 限制在 [x_min, x_max]。x_min = −0.2，x_max = 1.0，已有明确值（模型）。
3. 作动器反求（§4.3）。

**警告：** x_min = −0.2 是模型对"襟翼、起落架、减速板"的等效。它不是物理的慢车推力。

## 14. 已知局限

1. **横向与垂直的精度，由词的分辨率决定。** 5° 一档和 60 米一档的词，无法让执行器对准中心线 20 米以内。这是标注侧的问题。
2. **最后下降没有高度目标。** 偏差在进入下降时定下，之后与下滑道平行。执行器不得自己修正它（X4）。
3. **作动器时间常数未辨识。** 本设计在整个文献范围里验收，不对一个值做优化。
4. **构型阻力缺失。** 模型的稳定进近推力偏低（约 6%，真实约 15% 到 20%）。
5. **一阶滞后不是自动驾驶的真实形状。** 真实的滚转更接近限速的斜坡。
6. **§7 的纵向律是新推导，没有实验。** 原型实验用的是另一个纵向律。它还依赖词表的改动（§17）和 L_γ 的测量（V12）。V1 是它的验证。
7. **§8.2 的速度律是新推导，没有实验。** 它去掉了两个加速度值和距离，并依赖速度词的提前量（§17 C8）。推力会更频繁地到限，推力变化率会更大。V8 和 V10 是它的验证。
8. **去掉 32° 的倾斜角上限没有实验。** 这个值曾在 39% 到 58% 的航班里至少触发过一次。V7 是验证。
9. **速度词也没有提前量。** 它与改动前的角度词结构相同（按"更接近下一档"说出），很可能也偏晚。本文不改（D1）。
10. **控制周期 1 秒是沿用的值。** 2 秒也满足整除条件，没有比较。V11 是验证。
11. **本设计整体没有被实现，也没有被测过。** §10.1 的数字来自一个与它不同的原型。
12. **§7.5 的平均与末值不一致。** 第 2 步用周期平均的倾斜角，但 §4.3 让载荷系数在周期末到位，而 γ̇ 积分的是平均载荷系数。第一个周期只得到约 60% 的 Δn，相当于延迟一个周期。影响小，暂不改。
13. **教程还是旧执行器。** `docs/two_tier/tutorial/index.html` 和它的测试数据脚本 `scripts/two_tier_tutorial/tests/make_vectors.py`、`test_ports.js` 按旧的横向律（停止转弯率、转弯率上限）、旧的纵向律和旧参数写成；`make_vectors.py` 现在导入就失败（它引用已删除的 `stopping_rate_deg_s`）。这些不在 `run_all_tests.sh` 里。待办：按本文重写教程的执行器章节（审查 S2，2026-10-12，记为待办）。

## 17. 词表需要的改动（D7、D8）

本节是对词表文档（`vocabulary.md`）的改动请求。词表文档还没有改。改动写进词表文档、得到编号之后才生效（Q3）。

### 17.1 依据

现在的标注器在新一段的第一行说出角度词。新一段只在飞机偏离旧的直线超过拟合容差之后才开始。实测：说出平飞→下降的角度词时，观测飞机已经下沉约 16 米（中位数），推下大约在词之前 6 到 8 秒开始（§7.8）。执行器不能在听到词之前行动（X1），所以没有提前量时，执行器总是落后，修正器要用修正词补。这些修正词补的是标注的时间，不是模型的意图。

### 17.2 改动

| 编号 | 改动 | 原因 |
|---|---|---|
| C1 | 角度词：第 r 行取第 r + L_γ 秒时生效的那一段的角度类别。与生效类别不同时，说出新词。接近句末时，取最后一行的类别 | 与航向词的读法相同（第 r 行读第 r + L 秒的航迹，词表 §3.3） |
| C2 | 开始一段爬升或下降的高度词，与它的角度词在同一行说出（也提前 L_γ） | 执行器由 T 和当前高度决定方向（R5.4）。如果角度词先到、T 还是当前高度，停止边界马上起作用，执行器会保持高度。语法规则 3 也要求两者在同一行一致 |
| C3 | 管子从到达时刻 r + L_γ 开始，起点高度取那一时刻的高度 | 词描述的是 r + L_γ 之后的路径 |
| C4 | 修正词的规则不变。它的含义与其他角度词相同（R5.3），所以修正在 L_γ 之后才完全生效 | 一个词只有一个含义。航向修正词也有提前量 L |
| C5 | 第 0 行照常说出每一列。角度词取第 L_γ 秒时的类别 | 与航向词第 0 行的做法相同 |
| C6 | 词仍在最近的 Δ 行说出（D42、D45 不变） | Δ = 8 秒时，L_γ 可能不到一行。这与航向词是同一个已知局限 |
| C7 | 规格加一个值：`angle_lead_s` = L_γ | 单一定义 |
| C8 | 速度词（含"unspecified"）：第 r 行说出第 r + L_v 秒时生效的速度词。实现：速度列的每个词提前 L_v 行，落到第 0 行之前的合并到第 0 行，同列最后一个保留。速度词的包络从到达时刻开始。规格加 `speed_lead_s` = L_v | 与 C1 相同的读法（D8） |

### 17.3 复飞时的规定（实现时补充，审查后定）

| 编号 | 规定 | 原因 |
|---|---|---|
| C9 | "go-around"跑道词与爬升词同一行说出，也提前 L_γ。进近的分界仍在爬升被读出的行 | 进近的分界、捕获行和速度词不随 L_γ 变，三列的提前量才能分开测量（V12） |
| C10 | 结束复飞的跑道词：在爬升之后第一个平飞段开始的行（读出的行）；最晚与下一个"no level-off"同一行（说出的行） | 语法规则 5：G 为真时不能说"no level-off"。所以在没有平飞段的情况下，结束复飞的跑道词随最后下降一起提前 L_γ |

### 17.4 不变的部分

- 改平：下降到达一个高度时，标注器不说词（词表 §4.4）。改平由执行器的停止边界完成（§7.3），不需要提前量。
- "平飞"角度词：实测只在第 0 行出现。它不受提前量影响。
- 角度类别、名义角、高度网格、ε、H、H_final 都不变。

### 17.5 代价

改动 C1 到 C7 改变标注的结果。指令产物、闭环句子、执行器规格要重新生成，先验要重新训练。L_γ 要先由 V12 测出，再由用户选定。
