**读法（决定性的一读）。**

- **不用码的执行器建立最高**：0.699 / 0.703，高于所有带码协议——先验给码的 A（指令词表 0.594 / 0.608，K32 0.422 / 0.481）和真值码的 C（指令词表 0.677 / 0.697，K32 0.634 / 0.619）；
  雷达层 0.326 / 0.324 对 C 的 0.235 / 0.310 与 0.145 / 0.097。
- **真值码买到的是跟踪、不是穿越**：协议 C 的雷达 ADE 1742–1910 对无 token 的 2362–2481（−450…−650 m，逐轮 e_track r2 812 对 988）——码里的确有"接下来 60 s 往哪转"的信息（它读未来），
  但穿越份额反而低。**先验给的码一无所得**：A 的雷达 ADE 与无 token 持平（指令词表 2363 / 2342）或更差（K32 2531 / 2637），建立更低。
- **门 E 的进展线被无 token 执行器自己过了**：雷达 ADE 2362 / 2481 ≤ 2919 / 2949，建立 0.699 / 0.703 ≥ 0.690 / 0.699，两种子都过（目标线只差建立 ≥ 0.94）。

  这就是计划 §0 的论点"让 L1 短、单峰"，只是它不需要意图码来实现。

**结论（状态表一行）。** 60 s 段的闭环最好数字来自**不用码**的执行器（建立 0.70，雷达 ADE 2362 / 2481，过门 E 进展线）；真值码只换来跟踪精度（−500 m 雷达 ADE，读未来），
先验码什么都没换来。指令词表臂好于 K32 只因它的执行器几乎不看码。判"意图码的价值"的门应当是**相对无 token 的同协议读数**（计划 §6.3 第 16–17 条，用户定）。
