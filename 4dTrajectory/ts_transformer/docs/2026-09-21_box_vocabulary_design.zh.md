## 1 这份词表说什么

一句话是一串**事件**。每个事件说"从此刻起、持续 T 秒，这架飞机待在这几个区间里"，六个词：
**航向、高度、速度、跑道、时长、结束**。

判据是**包含**：航迹的每一行都必须落在当时生效的那几个区间内。这替换掉旧读法的"取中位数、snap
到最近格心"。三个后果：

- 量化误差这个量消失，定词表的目标换成互相牵制的一对：**句子长度**与**包围盒的宽度**；
- 容差就是词本身，**进 sha**；
- 旧规格那条"容差 < 最窄间隔的一半"反过来：盒子**必须铺满**。按旧容差量过，观测行落在任何盒子外
  的比例是速度 15.2 %、航向 13.5 % —— 那套取值读不出包围盒。

## 2 词表

### 2.1 语义

1. 一个词 = 一个区间，"这段时间里这个量待在这个区间内"，**每一时刻成立**；它约束状态，不约束路径。
2. 盒子**铺满、不留空洞、两端有界**。没有射线：射线装得下任何值，坏行会变成一个合法的词。
3. **量程外拒绝**，不夹到边档、不装进"大于 X"。但**拒绝只留给物理上不可能的值，不用来处理少见的
   值**：一条 4,900 m 进场、或高空 200 m/s 地速的航迹是正常的，量程必须盖住它；一行 11,000 m/s 的
   地速是坏行。量程按"不可能"定，不按分布的分位数定。
4. 容差即盒子，**进 sha**。

**一条规则三处用**：±5 %，加一个绝对地板给百分比会归零的那一端（航向的 ±1°、高度楔形的末端地板）。

### 2.2 航向

相对最后进近航道的地面航迹角，−180…180。半宽 `max(1°, 5 % × 值)`：航道处 2° 宽，±30° 处 3°，
90° 处 9°，反航向 180° 处 18°。**65 个词。**

分辨率自动落在决定成败的地方：旧 §8.4 量过均匀 2° 格把落地率带到 99.3 %，代价是每架 56 个航向词；
这里航道附近同样是 2°，每架 19–20 个。

### 2.3 速度

地速，半宽 5 % 的值，铺满比值 1.1053，量程 **30…250 m/s**、**22 个词**。

边界的依据是不可能而不是罕见：30 m/s 在任何客机的失速速度之下，250 m/s（486 kt 地速）超过任何
进近；之间的都给词。按 35–180 读时被拒的 55 架里，只有 46 架真的是坏行（最高 11,000 m/s），
9 架是强顺风下的正常高空地速。

### 2.4 高度：目标 + 后向可达楔形

**一个高度词是一个目标高度 T**，取自**有符号**的梯子：入口以上 `h0·(r^k − 1)`、入口以下取它的
镜像（h0 = 50 m、r = 1.1053），跨度 **−150…6,000 m**。梯子的间距就是各目标的 ±5 % 盒，恰好铺满。

**下界必须过 0**：一条在入口高程以下掠过的航迹是正常的，而它正是按 `[0, 3630]` 读时最常见的拒绝
原因（65 架里多数最高点只有 1,320 m，撞的是下界不是上界）。

它在一段上的包围盒是 **T 自己的后向可达集**：设这一行到段末还剩 `r` 米航迹，

```
T − r·tan(γ_up) − f(T)   ≤   h   ≤   T + r·tan(γ_down) + f(T)
f(T) = 0.05 · (T + h0)          ← 末端就收到目标自己的 ±5 % 盒
```

取 **γ_down = 1.5°、γ_up = 1.0°**。五条性质都是这个形式自带的：

- 盒子**自己随剩余距离收**，段末收到目标的 ±5 % 盒——和航向、速度同一条规则；
- **不对称**（下降侧宽、爬升侧窄），对应"低是危险侧"；
- 它**就是链条条件**（§3.4）：相邻两段只要 `T_k` 落在第 k+1 段的包络里就自动接得上；
- **读法不会失败**：梯子铺满那些 ±5 % 盒，所以单行段必然有一个目标可用；
- 末端精度和词数**解耦**——这是它相对平板的全部价值（§4.1）。

两条必须写死的读法细节：

- **`r` 是剩余航迹长度（地速积分），不是沿航道投影。**投影在雷达引导的下风边是增大的，剩余距离
  会算成负数，把雷达引导那一批（36 %）读成上百个词。
- **段不必终止在它的目标上**——真实指令可以在到达前被下一条取代。

**垂直词是高度不是航迹倾角**：角度盒约束的是高度变化率，界定不了"降到哪"；反向链一层，可达集就
按 `V·T·Δtan` 张开一次。

### 2.5 跑道、时长、结束

- **跑道**：`机场:跑道号`。它不是包围盒的一维，是包围盒的**坐标系**——决定其余三个量相对谁量。
  类别绑队列（五机场 22 类），不进 sha。
- **时长**：2 秒一格，**写在它描述的那一行**（"这个盒子保持 T 秒"）。链条条件要在发出盒子的同时
  就有 T；解码时也不能等下一个事件才知道当前这条保持多久。因此不需要旧词表那个额外的"落地事件"
  ——最后一个盒子自带它的时长。
- **结束**：继续 / 落地 / 复飞，标在最后一个盒子上，由**终点盒子被进入**导出。

### 2.6 sha 里有什么

冗余 0.05、航向地板 1°、高度的 γ_down / γ_up / 末端地板与目标梯子、三套盒子的构造规则与量程、
时长的格宽与位置、读法规则名。跑道类别集合在 sha 外，否则一份词表不能通用于五个机场。

## 3 读法

### 3.1 三类怎么切

- **航向、速度**：盒子铺满且不重叠，每一行只落在一个盒子里，所以读法就是分箱信号的**游程编码**，
  没有选择。
- **高度**：贪心**最长延伸**——从一端出发，尽量延到楔形还装得下为止，段内取梯子上任一可行目标。
  这一类有选择，所以读的方向有意义。

事件 = 三类变化时刻的并集。

### 3.2 从末端反着读

高度楔形锚在段的**末端**（目标在那里），所以反向是它的自然方向：从最后一行往前延，段的 `r` 是固定
的，可行性检验可以 O(1) 增量做。产物里写的是反向读法；正向读法的段数同时记进 `summary.json`
（`altitude_words_forward_*`）作对照。

### 3.3 终点盒子

句子结束时落在哪，数据自己已经选出来了（v1 读数）：航向落在航道那档 **99.5 %**，高度落在最低两档
**97.2 %**，速度落在相邻三档 **93.1 %**。所以终点盒子不需要拟合，写下来即可；要拍的只是它的边界取
公布的决断高（逐跑道 61.0–129.1 m）还是取数据读出来的这几档。

### 3.4 链条条件

"航迹在自己的盒子里"不够，**相邻两个盒子要接得上**：第 k 个盒子整个落在"能在 T 秒内飞进第 k+1 个
盒子"的集合里。链条成立时，"这句话能落地"是构造出来的，回放门从一次实测变成一次检查。

高度这一维已经自动满足（楔形就是后向可达集）。速度和高度的词**只跳隔壁**（v1 实测 100 %），航向
83.4 % 只跳隔壁——要检查的就是航向那 16.6 % 的大跳。

## 4 读数

### 4.1 楔形对平板：同样的末端精度要多少词（KRDU 6,851 架）

**同一把梯子下楔形的盒子只会比平板宽**（平板盒 + 楔形张开），所以"盒子更小"不是它的卖点。它的
价值是**末端精度与词数解耦**：平板的盒子处处一样宽，要末端紧就得整把梯子都细；楔形只在段末收紧。

| 末端精度 | 目标数 | 平板 词/架 | 楔形 γ 1.5° | 楔形 γ 2.5° |
|---|---|---|---|---|
| ±5 % | 44 | 29.0 | 24.0 | **8.0** |
| ±2.5 % | 86 | 53.0 | 42.0 | **14.0** |
| ±1.25 % | 171 | 88.0 | 67.0 | **24.0** |

γ_down 是这一维唯一的旋钮，代价写在中段盒高上（±5 % 梯子、γ_up 1.0°）：

| γ_down | 词/架 | 中段盒高 p50 / p95 |
|---|---|---|
| 1.0° | 27.0 | 126 m / 544 m |
| 1.5° | 24.0 | 148 m / 920 m |
| 2.0° | 16.0 | 197 m / 1,709 m |
| 2.5° | 8.7 | 288 m / 2,891 m |

**覆盖率与盒子宽度必须成对引用**：γ 越大句子越短、包围盒越宽，取到极限就是"一个词覆盖整条进近、
什么也没说"。**可用区间在机群自己的下降角以下。**机群下降段的中位是 2.98°，包络张开的速率一旦追上它，一个词
就盖住整条进近：实测 γ 3.0° 每架只剩 2 个高度词，而包围盒中位 740 m、p95 3,840 m——覆盖率拉满、
指令什么也没说。取 **1.5°**。

### 4.1b 冗余在句子里实际起了什么作用（KRDU 6,834 架）

航向和速度是**铺满**的盒子，所以冗余就是盒宽，没有第二个参数（高度有两个：梯子的 p 和张开率 γ）。

| | 速度 | 航向 |
|---|---|---|
| 生效中的盒宽 p50 | 9.50 m/s（p5 6.4、p95 14.2） | 2.00°（p95 14.8） |
| 航迹占了盒子多少 p50 / 贴边(>0.9) | 50.3 % / 10.1 % | 33.1 % / 10.7 % |
| 词/架 | 8.0 | 20.0 |

**速度的冗余在花到达时刻。**它允许的到达时刻散布是 **p50 28.2 秒、p90 55.9 秒**（整条进近上按
`∫ dD·δ/v²` 积出来，全宽）。3 NM 的雷达间隔在 83 m/s 上约 **69 秒**——也就是说速度盒一家就吃掉了
将近一半的间隔预算。这是 ±5 % 最该被权衡的地方，不是词数。

**航向的冗余有一大半时候不是百分比，是那个 1° 地板。**56.3 % 的行落在离航道 ±10° 以内，盒宽就是
2°；只有 38.4 % 的行在 |ψ| > 45°，百分比才真正把盒子放宽（p95 14.8°）。

**而且百分比并不省词**：这套 20.0 词/架，均匀 5° 格 21.0，同样 65 类的均匀格（5.5°）19.0。它买的
不是更短的句子，是**分辨率的位置**——航道附近 2°（旧 §8.4 量过那一段的分辨率决定落不落得下来），
而不是到处 5.5°。

## 5 未定项

### 5.1 水平方向没有绝对界

高度楔形是绝对的位置界。航向盒和速度盒只给**位移**界，随时间张开（v1 实测：航向盒每秒张开横向
走廊 p50 1.72 m/s、p95 18.0 m/s，一段 40 秒就是横向半宽 69–720 m）。所以水平包围盒是一个被起点和
跑道两头捏住的漏斗，不是盒子；单靠后向漏斗，25 km 外半宽约 14 km。

要水平也绝对，需要一个**位置维度**（离中线多远的盒子，或"在哪条 leg 上"）。旧词表里唯一那个绝对
的水平界是"保持中线"，它只是一个二值状态、只在最后加入航道那一段出现——它本该是一个维度上最里面
的那一格。

**为什么横向不能照抄垂直的楔形。**收拢的包络只对**慢**状态有意义 —— 它的宽度就是"每米航迹能纠正
多少"：

| | 每米航迹的张开率 |
|---|---|
| 高度（γ 1.5°） | tan 1.5° = **0.026** |
| 横向（30° 切入角） | sin 30° = **0.5**，快 19 倍 |
| 航向 | ω/V：25° 坡度下张满整圈只要 48–82 秒 |

照楔形的办法给**航向**做漏斗，实测（400 架 KRDU）每架只剩 **1 个**航向词，而 **87.6 % 的行包络张满
360°** —— 一个词允许飞机朝任何方向，不是收拢，是什么都没说。

所以三类盒子各司其职，不是"每一维都收拢"：

| | 盒子的形状 | 状态 |
|---|---|---|
| **慢状态**：高度 | 收拢的楔形（后向可达集） | 已做 |
| **快状态**：航向、速度 | 平盒子 | 已做 |
| **位置**：离中线的距离 | **固定走廊**（RNP / established 的 500 m），不是可达集 —— 横向的可达漏斗在 25 km 外半宽约 14 km，太宽 | **未做** |

这也说明现在的词表在横向上把**控制量**（航向）当成了词、而没有**状态**（横向位置）的词 —— 垂直方向
以前犯的是同一个错（旧词表说航迹倾角），盒子版把它换成高度就是这个动作，横向还欠一次。

### 5.2 最短保持

盒子铺满且不重叠，信号在边界上抖一下就生成一个新词再换回来。v1 五机场实测：保持时长中位 **4 秒**，
**36.3 % 的盒子保持不到 4 秒**。三条路，都没选：盒子留一点重叠（迟滞）、加最短保持并接受它破坏
严格包含、或放粗格子。

### 5.3 优先级

1. **给 `course_frame` 加一条地速上限**。现在只检查下限，一行 10,984 m/s 的坏数据要等到读词表才被
   发现；坏行应当在更上游被拒。
2. **算链条条件**（§3.4），产出"接不上的比例"和一张非法转移表；航向的大跳是唯一可能咬的地方。
3. **定最短保持**（§5.2）。
4. **决定位置维度**（§5.1）。
5. **回放门**。先量"给它完美的词时这套限幅能到多少"，任何在限幅下读出的落地率上限是那个数。
6. 五机场以外的读数都还没有（所有设计读数在 KRDU 上量）。
