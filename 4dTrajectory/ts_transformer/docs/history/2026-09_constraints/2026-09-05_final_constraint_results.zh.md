# 五边约束实验报告：有界输出、罚项与投影（2026-09-04/05）

承接 `2026-09-04_procedure_constraints_design.zh.md`（约束的定义与前置测量）和 `2026-09-04_constraint_methods_survey.zh.md`（方法综述与 P0–P3 顺序）。本报告回答两个问题：**把"五边走廊 + 下滑道窗口"放进学习模型，用哪种方式有效；有效的那种值多少。**

所有数字来自验证集（KRDU 2,104 架、KSJC 1,666 架），与 2026-09-03 机场帧消融的 A 臂同一分割、同一名册，逐航班配对；测试集未动，数据源未改；每机场各自训练（机场均衡采样器未被用到，按机场分别报数）。B 臂、C_dual 臂和 on-final 投影臂两个种子（1337、2024），C_fixed 和 FAF 投影臂各一个种子（1337）；配对读数都对同一种子的 A 臂。训练臂带正式实验清单（`--campaign-id / --experiment-id`，代码提交 5b54fae、99ad2d3），仅预测的投影臂沿用 A 臂检查点的元数据。产物：`4dTrajectory/outputs/{KRDU,KSJC}/experiments/final_constraint_20260904/`，每个目录下 `readout.json` / `readout.txt` 是完整读数（`docs/compare_constraint_arms.py`）。

## 结论

1. **有界输出（B 臂，`state_position_reference="corridor-bounded"`）采纳为候选默认。** 四次运行（两机场 × 两种子）汇总 FDE 全部改善（−91 / −66 / −51 / −63 m），汇总 ADE 全部改善（−46 / −8 / −18 / −71 m）；注意检查点就是按共网格 ADE 选的，所以 ADE 的改善有一部分是选择效应，没有参与选择的证据是 FDE、违反率和入口横向 p95；直线进近 FDE 改善 −95 / −96 / −38 / −18 m；真值已建立行上的走廊违反率 KRDU 77 → 48 %、KSJC 34 → 21 %，下滑窗口违反率 62 → 43 %、38–46 → 21–23 %；入口横向 p95 KRDU 492 → 305 m、KSJC 237 → 171 m。否决条件（雷达引导层两个种子都退化）没有触发：KRDU 一正一负（−7 / +49 m ADE），KSJC 两个种子都改善（−28 / −204 m）。它不需要标定权重，约束在成员锥内由构造保证。
2. **罚项否决，原因已定位。** 原始对偶（C_dual）四次运行四次发散：容许违反率 ε = 0.05 不可达（A 臂本身 0.77，B 臂也只到 0.48），对偶变量只涨不落，74 轮里 λ 涨 50 倍，罚项从第 1 轮起就与位置项同量级，第 20 轮起压过它（0.191 对 0.630），共网格 ADE 停在 2420 / 2749 m（KRDU）和 2258 / 2195 m（KSJC），A 臂是 1383 / 1361 / 870 / 865 m。固定在标定平价值 λ = 1e-3 的 C_fixed 不发散，但也不赚：KRDU 汇总 ADE 1383 → 1386、FDE 1163 → 1152，KSJC 870 → 912、776 → 785；它换来的违反率降幅（KSJC 34 → 22 %）和 B 臂一样，却是用精度换的。同一个约束，罚项要用精度换，有界输出不用换，这是本次实验最干净的一组对照。
3. **推理期投影：逐行自门控投影在 KRDU 事后收回了 B 臂的大部分终点收益，但收不回违反率和入口横向尾部。** 对 A 臂的预测逐行套同一个 on-final 门再硬夹（不训练）：KRDU 汇总 FDE 1163 → 1090 m（B 臂 1072），直线进近 FDE 643 → 545 m（B 548），汇总 ADE 1383 → 1344（B 1337）；但走廊违反率只降到 56 %（B 48 %），入口横向 p95 480 m 不动（B 305 m），雷达引导层 ADE 不动、FDE 小幅改善（−35 m，B −84 m）。KSJC 的投影收益小于 B（雷达引导 FDE −73 m 对 B 的 −104 m）（汇总 FDE 748 对 725；种子 2024 ADE 855 对 794）。所以 B 臂在终点误差上与"事后逐行硬夹"接近，多出来的是违反率、尾部和 KSJC，以及没有折角（可飞性未测）。FAF 门控投影是直线进近的上限（KRDU FDE 455、KSJC 399），代价是雷达引导层被毁（ADE 2599 → 4665、2536 → 5281：FAF 距离内的三边/四边行全部被压进走廊，KSJC 30L 的 FAF 在 15.1 km 外）。
4. **有界输出没有解决起点问题，也没有消除西北拉力。** 第一步偏移 KRDU 390 → 377 / 368 → 389 m 未变；已建立航班的终点横向中位数从 +206 / +149 m 变成 +54 / +54 m，正好等于走廊边缘 k·hw(0) = 53 m：偏拉仍在，只是被边界压住。这与设计判断一致——约束只在成员锥内起作用，起点先验仍要另一项（state-v3 连续性项），两者正交。

|---|---|---|---|

几何与门控（`final_approach_geometry.py`）：跑道轴坐标 d（沿航道离入口，上游为正）、xt（航道右侧为正），走廊 hw(d) = cw·(d + d_GARP)/d_GARP 与优化器共用一份定义（`flight_scenarios/fas_geometry.py`，测试逐点对照 `approach_constraints`）；下滑道 u_GP(d) = d·tan GPA。成员（"输出自己说在五边上"）= |xt| ≤ max(hw(d), 500 m) 且预测路径方向与航道夹角 ≤ 30°；方向取预测位置的中央差分，不用速度通道（速度通道从未被监督，网络可以把它们挪去关掉门）。500 m 下限的来由：走廊在入口的半宽只有 107 m，而 A 臂有 250–350 m 的西北平移；KRDU 平行跑道中线相距 1066 m，下限不能再宽。真值门 = 观测航迹留在 k = 0.5 锥内直到入口的尾段（离入口 > 300 m），与前置测量的定义相同；所有"违反率"都在这些行上算，预测行按同一时刻配对，预测提前截断的行计作"未覆盖"（覆盖率 87–99 %）。

## 2. 观测底线

真值门控行上，观测航迹的走廊违反率按定义为 0；下滑窗口违反率 KRDU 6.1 %（直线进近 2.6 %，雷达引导 11.4 %），KSJC 1.7 %（0.9 % / 5.7 %）。任何臂的违反率都应对着这个底线读，不是对着 0。

- **否决条件未触发**：雷达引导层 ADE 在 KRDU 一正一负（−7 / +49 m；A 臂自己两个种子在该层相差 25 m），KSJC 两个种子都改善（−28 / −204 m）；四个种子的雷达引导 FDE 都改善（−84 / −19 / −104 / −233 m）。
- **对照投影**：终点误差上 B 与对 A 事后逐行硬夹接近（KRDU 直线进近 FDE 548 / 526 对投影的 545 / 531，汇总 FDE 1072 / 1058 对 1090 / 1051；KSJC 725 / 692 对 748 / 729），B 多出来的是违反率（48 对 56 %）、入口横向 p95（305 对 480 m）和 KSJC 种子 2024 的 ADE（794 对 855）；对 FAF 上限（直线进近 455 / 399），B 在 KRDU 收回约一半、在 KSJC 约四分之三，且不付雷达引导层的代价（B 2592 / 2623 对上限臂的 4665 m）。
- **违反率降到 48 % / 20 % 而不是 0**：成员锥内的行被硬约束（tanh 饱和），成员锥外的行（预测离中线 > 500 m 或 > hw(d)）不受约束，这是设计选择，把"预测在哪"留给位置项；剩下的违反行约六成来自雷达引导航班在真值已建立、预测还没转上五边的时段（KRDU 分层违反率：直线进近 32 %，雷达引导 72 %）。

## 6. 决定与后续

- `state_position_reference="corridor-bounded"`（`corridor_gate="on-final"`）作为候选默认；是否真的换默认，与 state-v3 连续性项一起判断（后者管起点，前者管终点，二者正交，应该合在一个配方里再决定）。
- `procedure_loss_*` 保留为可选项，权重默认 0，对偶步长默认 0；不再单独跑罚项臂。
- `predict --project-final` 保留：`on-final` 是部署兜底，`faf` 只作读数上限。
- 未做：PatchTST（通道独立的主干能否穿过有界映射）、控制输出路径（同一 hinge 套在 rollout 状态上）、KSJC 12L/12R 的样本（验证集里只有 3 / 86 架，30L 1,444、30R 133）；机场均衡采样器在本次按机场训练的设计下未被用到。
