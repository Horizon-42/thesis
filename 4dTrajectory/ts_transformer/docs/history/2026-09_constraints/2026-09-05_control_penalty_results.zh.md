# control 输出上的五边罚项：实验报告（2026-09-05）

承接 `2026-09-05_final_constraint_results.zh.md`（同一个罚项在 state 输出上：对偶发散、固定权重用精度换违反率，被否决）和 `2026-09-05_control_constraint_design.zh.md`（control 上的其他方案）。问题：**把跑道尺度的走廊 / 下滑道 hinge 罚项接到 control 路径的 rollout 状态上，约束经动力学传回控制量，会怎样？**

数据：验证集，openap-direct 机队子集（KRDU 1,404 架、KSJC 1,083 架；state 那次 campaign 是全机队 2,104 / 1,666 架，两者的任何数字都不在同一批航班上，观测底线也因此不同），`simple-v3` 配方，一个种子（1337），每机场各自训练，与本 campaign 内的基线逐航班配对；KSJC 的雷达引导层只有 204 架（199 架有门控行）。测试集未动，数据源未改。基线是新训的（此前所有 control 检查点都早于 v5 名册）。产物：`4dTrajectory/outputs/{KRDU,KSJC}/experiments/control_procedure_20260905/`，读数 `readout.json` / `readout.txt`（`docs/compare_constraint_arms.py`），control 指标 `docs/score_control_arms.py`。代码提交 9d9e66e（接线）、臂声明 `docs/experiments/control_procedure_arms.json`。

## 结论

1. **罚项在 control 上的作用与 state 上不同：它改善终点、恶化路径中段、几乎不动违反率。** λ = 1e-3：KRDU 汇总 FDE 1650 → 1549（配对 57 % 改善，中位 −67 m）、直线进近 FDE 938 → 888、入口横向 p95 2769 → 2203 m；但汇总 ADE 1333 → 1537，雷达引导层 ADE 2858 → 3439（配对只有 23 % 改善，中位 +658 m）。KSJC 方向相同但收益只在直线进近：汇总 FDE 996 → 957、直线进近 FDE 684 → 626，雷达引导 ADE 2066 → 2311、FDE 2340 → 2383，入口横向 p95 反而 1634 → 1651（雷达引导 4881 → 5203）。入口尾部的收益是 KRDU 独有的。走廊违反率 KRDU 55 → 45 %、KSJC 27 → 25 %，下滑窗口违反率不动。
2. **加大剂量只买到更紧的入口尾部，代价是精度和调度。** λ = 5e-3 给出两机场最紧的入口横向 p95（1999、1340 m）和 KSJC 最低的下滑窗口违反率（23.1 %），但 KRDU 汇总 ADE 1333 → 1917、FDE 1650 → 1904，下滑窗口违反率 46.6 → 53.1 %，坡度调度坍缩成共享形状（共享分量 3.8 → 13.7 %，坡度技能 0.728 → 0.280，接近 KRDU 的随机下限 0.170）；KSJC 温和些（ADE +44、FDE +23，坡度技能 0.678 → 0.642，但共享分量在 1e-3 时已从 5.9 % 升到 7.6 %）。走廊违反率两档一样（KRDU 45–47 %，KSJC 25 %）：剩下的违反行多数在雷达引导航班（KRDU 60 %、KSJC 52 %），其余 40–48 % 仍在直线进近航班上（该层违反率 28 % / 14 %），再加力只会毁掉调度。
3. **"平价"标定在 control 上不成立。** 同一 λ = 1e-3：训练第 1 轮罚项相对各自位置项的比例，control 是 4.4（KRDU 14.8 / 3.4），state 是 0.78（0.77 / 0.99），差 5.6 倍（加权罚项的绝对值差 19 倍，是平方量，折成米约 4.4 倍）；训练结束时（最后一轮）罚项是 state 项的 1.3–1.5 倍（KRDU 0.099 / 0.064，KSJC 0.024 / 0.018；在被选中的最佳轮是 1.2–1.4 倍），而 state 路径上同一权重收敛到 0.53–0.55 倍，即 control 上重 2.4–2.9 倍；5e-3 时 3.6–4.1 倍。所以 λ = 1e-3 在 control 上不是平价，而是"前几十轮压过目标、收敛后仍高于目标"。
4. **决定：罚项不采纳，保留为可选项。** 它证明了一件有用的事：约束经动力学传回控制量，能把终点拉进走廊而不破坏可飞性（第一步偏移始终 ≈ 0，坡度符号翻转为 0）。收益和代价的分离（终点好、中段差）指向"作用点该在哪"的问题，即设计文档里的两个 P1 方案：屏障过滤器只在要越界时改命令，名义律 + 残差在门控段持续拉向中线。两者仍在同一个 rollout 里，梯度同样传回更早的段，所以"不推离中段"是预期而不是保证，要靠读数确认；另外屏障过滤器对已在走廊外的行不作为，而剩余违反行的大半正是这种行。

## 3. 读法

- **为什么终点好、中段差。** 罚项只在真值已建立的行上算（KRDU 是最后 10–18 km，KSJC 建立得更早），但 rollout 是顺序积分，末段的状态是锚点以来每一段控制量的函数，所以罚项的梯度传回全部更早的段——把末段拉进走廊最省力的办法就是提前转向，雷达引导航班的三边、四边段因此被推离。state 路径每行独立输出，没有这个耦合，所以那里罚项只改了违反率。
- **为什么违反率有底。** 剩余的 45 %（KRDU）/ 25 %（KSJC）违反行，多数在雷达引导航班（按分层违反率折算：KRDU 60 %、KSJC 52 %，真值已转上五边而 rollout 还在几公里外），其余 40–48 % 在直线进近航班（该层违反率仍有 28 % / 14 %）。对前者，罚项要求整条路径提前转向，与位置项冲突，加大 λ 只会把调度压平（5e-3）。这也是 state 路径 B 臂剩 48 % 的同一类行；设计文档里的屏障过滤器对这些已在走廊外的行同样不作为。
- **与 state 路径的三个方式对照。** state：罚项否决、有界输出采纳、投影作上限。control：罚项终点有收益但中段付费，"有界输出"没有直接对应物（输出是控制量），对应的是设计文档里作用在命令上的两个方案。本实验的收益（终点误差两机场、入口尾部只在 KRDU、无折角）说明"约束经动力学传回"这条路是对的，问题在作用点太粗。两次 campaign 的机队不同（openap-direct 子集对全机队），跨报告的数字只能比方向。
- **标定教训。** 同一权重在 control 上相对位置项重 2.4–2.9 倍（训练结束时），训练第 1 轮重 5.6 倍。若再用罚项，λ 应按 control 自己的收敛点标定，并考虑随训练进度爬升（warm-up），而不是从第 1 轮起全额。
- **一个种子。** 两机场同形给了方向上的信心，但每个格子的幅度没有种子噪声估计；state 路径的经验是 A 臂两种子汇总 ADE 相差 5–22 m。KSJC 1e-3 的 FDE −39 m 和直线进近 ADE −21 m 在这个量级之上，KRDU 1e-3 的雷达引导 +581 m 远在之上。

## 4. 决定与后续

- `procedure_loss_*` 在 control 上保留为可选项，默认 0；不进 `simple-v3` 配方。
- 下一步按 `2026-09-05_control_constraint_design.zh.md` 的 P1：屏障过滤器与名义律 + 残差，两者都只在门控生效的步上改命令，预期保留本实验的终点收益而不付中段的代价；读数加"走廊外回收率"。
- 若再跑罚项，改为：按 control 收敛点标定 λ、warm-up、只算横向（下滑窗口违反率 1e-3 时两机场都没动，5e-3 时 KRDU 变差、KSJC 略好，不值得为它付出）。
