# 指令词表

把一次进近说成一串管制指令,让第二层说出这串指令,由执行器去飞。单位:米、米/秒、度、秒。

---

## 1 词表

一句话是一串**事件**。每个事件是"在此刻,这几项目标变成了什么",只出现在真的有东西变了的时刻。
每个事件带六个词:

| 词 | 取值 | 冗余 |
|---|---|---|
| **跑道** | 队列里出现过的跑道,类名为 `机场:跑道号`(清单 23 条:KRDU 4 / KSJC 4 / KSTL 8 / KSMF 3 / KMSY 4;pooled 队列 22 条,无 KSTL 06) | —— |
| **航向** | 相对最后进近航道,5° 一格,整圈 72 类;超过 150° 的转弯读的时候拆成两句(§2.4) | —— |
| **垂直** | 航迹倾角六档:上升 3.0 / 平飞 0 / 下降 1.4 / 2.4 / 3.1 / 4.4 度 | 平飞档 ±0.1°;其余 ±7 %(1.4° 上 ±0.10°,4.4° 上 ±0.31°) |
| **速度** | 地速 16 档:44 / 56 / 63 / 68 / 74 / 79 / 86 / 93 / 99 / 107 / 114 / 121 / 129 / 138 / 147 / 157 | ±3 %(74 上 ±2.2,129 上 ±3.9) |
| **时长** | 距上一条事件多久,2 秒一格,0–300 秒,151 类 | —— |
| **结束** | 继续 / 落地 / 复飞 | —— |

跑道词的类别按机场绑定,不进词表规格、不进 sha——否则一份词表不能通用于五个机场。其余各类与机场
无关。冗余是解码与读数的参数,同样不进 sha。

**类名必须带机场前缀**:跑道号跨机场重名(KSJC 与 KSTL 都有 12L/12R/30L/30R,KSTL 与 KMSY 都有
11/29),光用号码,六个词会盖住十二条航道朝向完全不同的跑道,同一个嵌入说不清指的是哪一条。写成
`KSJC:12L`,pooled 队列从 16 类变成 22 类(类别集合是队列的,不是机场的)。

**训练用五个机场合训**,按机场均匀采样。每类词的样本量由此决定,所以它和档位是同一个决定的两面。

### 1.1 每一类词的依据

**跑道。** 其余各类都是相对某条跑道量出来的角度,没有跑道词的句子说不出"去哪条跑道";而在真实管制里
跑道就是管制员说出口的一句话。它是每个位置一列,所以句子能表达中途改跑道。

**航向。** 相对最后进近航道,所以第 0 档的含义是"对着航道"——进近里 38.2 % 的航向指令落在这一档,
它对应"转上最后进近航道"这一条实际指令。5° 一格:每类中位 497 条样本,五机场合训下宽裕。

**垂直是航迹倾角。** 进近里飞机只做两件事——平飞,或按大约 3 度下降,而这个角度从两万英尺到跑道入口
基本不变(下降段 p50 2.98°,四分位 2.37–3.21°,平飞段占 12.4 %)。所以垂直方向该说的是"这一段怎么飞",
不是"最后停在哪"。下降的四个档心按数据拟出再圆到一位小数:圆整不增加误差(36.3 → 35.7 米),而规格里
不出现拟合噪声。

**上升 3.0 度这一档是给复飞用的,但它在训练数据里并非不出现。** 读出来五个机场的 cohort 上它被用到了
——要落进这一档,爬升得超过 1.5°,那不是噪声,是到达切片里真实的爬升段(阶梯爬升或高度修正)。真正
0 次的是"结束"词的复飞值:切片只含最后那次成功的进近,所以句子说不出"这次不落地"。放进词表是因为词表必须在实验开始前定死——复飞要在后训练阶段构造,
那时再加一档就得重训。约定:**下降为正,上升为负**,所以这一档的值是 −3.0。
**待补的一个数**:公布的复飞最小爬升梯度还没有从程序数据里抽出来,所以"3 度够不够"目前只是一个设计
取值(3° ≈ 5.2 % 梯度),不是对着规章核过的。

**速度是地速。** 数据里只有 ADS-B 地速,没有空速;管制给的是表速,风把两者之间的整数结构打散,所以
地速上没有"整节"可对齐,档位只能按误差本身拟。16 档圆到 1 米/秒,圆整同样不增加误差(1.76 → 1.77)。
131,483 条指令,分到这 16 档每类有数千条。

**时长。** 事件流必须说"距上一条多久"。做成词而不是一个回归数,因为生成时要取前 K 个候选、要采样,
回归输出给不了。2 秒是数据本身的分辨率。

**结束。** 一句话在哪结束由它自己的词回答,不由一个外挂的二值输出。这样自由生成就是"一直说到模型
自己说落地";而且"落地"每架恰好一个、占 17 % 的事件,是个学得到的类。**复飞这个值在训练数据里出现
0 次**——词表在 25 公里到达切片上读,切片只含最后那次成功的进近。它在词表里是因为词表必须在实验开始
前定死,否则构造复飞场景的后训练阶段要重训。

### 1.2 词表里没有的

**没有"保持"。** 什么都没变的时刻不是事件,不占位置。

**没有"切入"。** 切入角是管制员给的航向的后果,不是他说出口的目标;在事件流里它从不产生自己的事件
(每一条都与某条航向词同时刻),而且 78 % 可从航向词直接推出。解码时要用的切入角从航向的连续目标值
直接算。

**没有绝对高度。** 见 §1.3 的代价说明。

### 1.3 两条必须记住的性质

**下降角是速率,它的误差随飞行距离累积。** 五档在最优分段上的终点高度误差是中位 34.7 米、p95
194.6 米,最坏约 840 米;加档位对最坏值无效。绝对目标没有这个性质(飞机低了两百米,"下到三千"仍然
收在三千),但绝对高度在这份数据上没有可用的结构,而且它每架只产生一条不带垂直信息的指令。本设计
接受这个代价,不加绝对锚。

**两类冗余积到不同维度。** 下降角的冗余积到**高度**上(δ × 飞行距离);速度的冗余积到**到达时间**上
(≈ D·δ/v²,现行取值下中位 8.3 秒、p95 11.2 秒)。到达时间是这个项目的第四维,所以速度冗余不是免费
的自由度。

## 2 从航迹反算词序列

输入是一架航班的 ADS-B 航迹(25 公里到达切片,每行 `时刻 / 经度 / 纬度 / 高度`,另有逐行的地速),
输出是这架航班的事件序列。六步。

### 2.1 第一步:换到跑道坐标系

用这架航班被指派的跑道,把每一行换算成五个量:

| 量 | 定义 |
|---|---|
| `到入口的沿航迹距离` | 入口之前为正 |
| `横向偏离` | 航道右侧为正 |
| `相对航向` | 地面航迹与最后进近航道的夹角,**沿行展开**(不折回 ±180°,否则平滑和找平台会在边界断开) |
| `入口以上高度` | 用该跑道的入口高程;ADS-B 是椭球高,在这一步之前已经转成海压高 |
| `地速` | ADS-B 报的地速 |

跑道的入口点取公布的着陆入口(有 LPV 的跑道用程序的着陆入口点),不是道面端点。

### 2.2 第二步:平滑

航向用 6 秒窗,高度与地速用 10 秒窗。目的是压掉逐行抖动,不是去掉机动——窗口远小于一次机动的时长。

### 2.3 第三步:分段。两类量用两种办法

**航向和速度用"平台"。** 一段信号在容差内(航向 ±4°、地速 ±2.5 米/秒)保持 ≥ 20 秒,**并且**这 20 秒
的拟合斜率把它带走的量不超过半个容差,就是一个平台。第二个条件是必需的:没有它,缓慢下降、缓慢减速、
下降途中的小停顿都会被当成"稳住了"。

**垂直用分段线性拟合。** 平台那套办法对速率量不成立:速率描述的是整条曲线的形状,分段必须铺满航迹,
而平台分段会把"正在变化"的过渡段留在外面,那些段里的高度变化没有任何指令负责。做法:坐标取
**高度对累计水平距离**(倾角就是这条曲线的斜率),用动态规划在给定段数下求最优断点,段与段共用断点、
首尾相接,每架 5 段。

### 2.4 第四步:从段落到指令

**平台类(航向、速度)**:

1. **第一个平台的值就是 t = 0 的那条指令** —— 记录开始时飞机要么已经在这个目标上,要么正在往它飞。
2. **之后每个平台是一条新指令,它的发出时刻不是这个平台的开始,而是信号离开"紧挨它前面那个平台"的
   那一行。** 这一条是关键:管制员先说话,飞机才动,所以指令的时刻应该是动作开始的时刻,不是动作
   完成的时刻。
3. **三种情况不算新指令**(记进 `absorbed`,并计数,不丢弃):
   - 到达的还是当前生效的那个词;
   - 变化量小于最小变化量(航向半档、地速一档)——**除非**飞机把它守住了 ≥ 40 秒**且**变化量超过一个
     容差,那它就是一条真指令,不管多小;
   - 尾巴太短:信号离开最后一个平台之后不到 20 秒记录就结束了,读不出它要去哪。
4. **整条航迹一个平台都没有**:那就是一次从头到尾的机动,目标取最后一行的值。

**垂直**:每一段的斜率就是那一段的倾角,取最近的档;**发出时刻 = 该段的起点**(断点本身就是斜率改变
的时刻)。段数是**上限不是配额**:比真实相位少的剖面会把多余的段花在几秒钟的过渡上,所以从最短的那段
开始自底向上并进角度更接近的邻段,并到不动点为止;两段读成同一个词时合成一条指令,角度按**合并后的
跨度**重算(保留第一段的角度会让这条指令宣称一个与它自己后半段差 0.9° 的倾角)。上限的代价不许是
静默的:每架航班记一个**拟合残差**(词自己画出的剖面对航迹的 RMS 高度误差),摘要里报 p50/p95。

**超过半圈的转弯要拆。** 航向词是一个绝对目标方向,而"转到 X"这句话**不含左右**;真实管制说的是
"turn LEFT heading 270"。飞机到底往哪边转,读的时候是知道的——航向是**未展开**读的,+178° 和 −182°
在那里是两个不同的数——但绝对目标词把它丢了,任何飞这句话的东西只能走短边,而半圈时短边是掷硬币。
实测五机场训练集:28,221 次航向变化里 13.4 % 超过 150°、**9.9 % 正好是半圈**,17.1 % 的航班至少有
一次;猜错一次整条航迹镜像出去,最多 18 km。做法:超过 `转弯拆分角`(150°)的转弯拆成若干段等分的
中间目标,**中间那句在转弯开始时发出**(不先把飞机支过去就没人转),飞机真的转到中间航向时再交给
下一句。这不新增词类,花的是读的时候本来就有的那点知识。

**跑道**:在 t = 0 说一次,之后不变。句子的结构允许中途改跑道(它是每个位置一列),但这份数据分辨不出
中途改——晚改只有 1/44622,早改看不出来。

### 2.5 第五步:拼成事件序列

把所有类的指令按 `(发出时刻, 类的固定顺序)` 排序,然后**每一个"有东西变了"的时刻生成一个事件**。
一个事件带六个词:该时刻各类**当前生效**的值,加上距上一条事件的时长。

- **第一个事件在 t = 0**,把各类一次说全;
- 之后的事件只出现在真的有变化的时刻,**绝不允许出现与前一个事件完全相同的行**;
- **落地本身是一个事件**,它的六个词沿用当时生效的值,"结束"词置为落地,时长词是距上一次变化多久;
  其余事件的结束词为继续。这一条是被实测逼出来的:把落地词写在最后一次**变化**上时,它平均落在记录
  结束前 136 秒(p95 240 秒,约 11 km),而时长词只表示"距上一个事件多久",所以**最后一段有多长在任何
  词里都没有**,一句生成出来的话说不出自己什么时候落地。加上这一行,时长词之和等于整条航迹的时长。

### 2.6 第六步:拒绝,而不是凑合

下面几种情况直接报错,不做近似:航迹里有静止的行(滑跑或损坏的行,没有航向可读);某一类在某个事件上
没有词;出现重复事件;某个目标超出该类的量程(超出会被夹到边档并**计数**,计数不为零就要在读数里写明)。

**一条自检**:对垂直,用每段的**真实斜率**(不取档)还原整条剖面,终点高度误差必须为 0。任何"把分段
聚合成每架航班"的读数都要先过这一条。

### 2.7 这套算法的已知代价

**分段是离线最优的** —— 断点是在看过整条剖面之后取的。标注时这样做是合法的(标注本来就是回看),
但生成时模型要自己产生这些断点,那是时长词的活,代价没有量过。

**"偏出半个容差才算离开"是一个定义,不是一个测量。** 它让我们标出的时刻系统性地晚于真实电台发话的
时刻;读和执行两边同用这个定义,所以自洽,而我们从不与真实电台记录比较。


## 3 两层怎么训

### 3.1 先验

一个样本 = 一架飞机的整句话。

| | 内容 |
|---|---|
| 事件 k 的输入 | 六个词各一个嵌入相加;该时刻的状态(位置相对机场基准点、地速、航向的 cos/sin);事件序号 |
| 上下文 | 机型 |
| 目标 | 事件 k+1 的六个词 |
| 损失 | 每类词一个交叉熵,只在有下一个事件的位置上算 |

先验不预测轨迹——每个事件时刻的真实状态直接喂给它,它只说下一句。

**部署时有两重落差。** 语言模型生成时只有自己的词回灌;这里先验说词、执行器去飞,先验下一步看到的
状态是执行器飞出来的。词的回灌那一重一样;**上下文里有一个会漂的外部系统**,这一重没有对应物——执行器
逐轮误差线性涨、每轮约 110 米。§3.3 的后训练冲的就是这一重。

### 3.2 跑道要从输入里拿走

跑道现在是三重给定的:状态原点是那条跑道的入口、跑道航道是显式上下文、跑道词本身也在输入里。三样
都在时让模型预测跑道不是预测,是抄。三处一起改:状态原点换成**机场基准点**;去掉跑道航道这个上下文
(状态里的航向是绝对的,航道方向必须由跑道词提供);跑道词进输入也进输出。代价:其余各类要自己从
跑道词还原出相对入口的位置与航道方向。

### 3.3 后训练

**执行器闭环再训。** 在训练集上用预训练执行器闭环飞,每段开若干分支(真值指令及其相邻档),只留段末
离真值最近的那支继续;飞出来的历史切成训练窗口,标签 = 同一绝对时刻真值的下一段。引导是必须的——
不加引导的微调比不微调还差(0.6361 对 0.7581),引导着才有用(0.7616)。

**先验闭环再训。** 同样的引导式做法,挑的是指令:每个位置在先验前 K 个候选里挑一个交给执行器飞,留
落点离真值最近的那个继续,飞出来的状态配同一绝对时刻的真值下一指令作标签。

**目标导向解码。** 每个位置取 K 个候选各飞一段;先按程序与可飞性屏蔽,剩下的按先验概率、向跑道入口
的推进、对航道的对准打分,选最高分的飞。打分只用部署时拿得到的量。上限读法:同一套候选改用真值打分。

**强化学习本阶段不做。** 引导式闭环再训之后再做强化学习只多 +0.0001;只有奖励里有"离真值远近"表达
不了的东西(间隔、指定到达时刻)时才值得。

## 4 怎么判它成不成

**第零条:一句话必须能飞到跑道。** 在拿任何句子去训练之前,把产物里写的句子逐条飞一遍
(`run_ts.py instruction_replay`,飞的是**文件里写的**句子,不是重读航迹),要求它越过入口**且在最后
进近上**。这一条不是锦上添花:它一次抓出了三个读数根本看不见的问题——航向词说不出往哪边转、说不出
保持中线、以及句子从不说自己什么时候落地。KRDU 验证集 1,404 条上,修之前 36.7 %,修之后 **99.6 %**
(直入 100 %,雷达引导 99.2 %)。

注意这条门量的是**词表的表达能力**,不是模型:飞它的是一个理想化的运动学预览(等速段、定坡度转弯、
无风、不分机型,坡度与加速度按机群实测取 14°、0.5 m/s²)。所以它和原始航迹之间剩下的距离
(gap p95 中位 1,085 m)**不该当成词表分辨率不够**:把速度词换成未量化的平台值只降 18 %,换成逐秒
实测地速降 55 %。


**门一 · 真值指令的上限。** 真值读出的指令按执行器所在位置喂给执行器,闭环飞完整个进近。若这样都不比
无指令好,指令这条路本身不成立。判据:两项 established 不差,任一项两个种子都超过无指令的线,
fully flyable ≥ 0.95。

**门二 · 先验自己说的话站不站得住**(不需要执行器)。自由生成到模型自己说"落地"为止,检查:

- 最后一个事件的航向词对着航道、垂直词是最后一段下降或平飞、结束词是落地;
- 复飞词只在入口以上高度 ≥ 该跑道公布的决断高时出现——有垂直引导的进近,复飞点就在决断高上;逐跑道
  的决断高在跑道配置里(25 条跑道有,入口以上 61.0–129.1 米);
- 要压过两个什么都不做的对手:永远重复上一条指令的模型,和只看上一个词猜下一个的模型。

这道门读真实高度,不读词——决断高全部落在一个高度词的跨度之内。

**门三 · 两层接上飞出来。** 先验说话、执行器飞,读 established 与雷达引导组的误差,相对无指令基线。

**读数协议**(三门共用):闭环从固定位置起飞完整个进近,开发 cohort 1,404 架,每配置两个种子,按进近
类型分三组读。

---

## 5 与程序、与多机

**程序不进损失,只进解码时的掩码。** 坐标系本身就是程序的,所以同一词表在任何跑道上读出同样的句子。
违反程序的候选在打分前屏蔽:切入角过大、低于该处障碍物间隔面的高度目标、航道外侧的走向。掩码换来的
是可解率而不是精度(去掉掩码,可解率从 0.865 掉到 0.527)。规则制导只作基线与诊断,不作模型的修法。

**多机在本阶段之后。** 前机的指令序列就是管制员对前机说的话,后机的先验读它作上下文;间隔规则作用在
候选指令上——后机某条指令飞出来的那一段若对前机已提交的段违反间隔,该候选在打分前屏蔽。先量上限:
不建图,把前机的真值指令序列作为上下文喂给单机先验,差大于种子线才值得建层。切分按运行日,不按航班。

---

## 6 步骤

1. **读词表** —— 在五机场 cohort 上读出全部句子,写出词表产物(带 sha)与人工核样本。
2. **门一** —— 真值指令喂执行器,两个种子。不过就停。
3. **训先验** —— 先读困惑度、top-1、翻转率、前 K 覆盖;每一版训完立刻读门二,不等另一版。
4. **消融** —— 中间状态每个位置都给 vs 只在第 0 个位置给。两版都训,谁先完谁先读,齐了再对照。
5. **后训练** —— 执行器闭环再训 → 先验闭环再训 → 目标导向解码,每步过门三再进下一步。

## 7 风险

| 风险 | 怎么看出来 | 后备 |
|---|---|---|
| 词表太粗,真值指令都飞不到 | 门一不过 | 细化档位;仍不过则这条路不成立 |
| 下降角误差在长进近上失控 | 门三的终点高度散布 | 引入一个绝对高度词作锚(多一类词,sha 变) |
| 先验只会重复最常见的指令 | 翻转率低、自由生成早停 | 与"永远重复上一条"比;不过则加目标导向解码 |
| 闭环再训把执行器带坏 | 直线组 established 掉 | 降低飞出窗口的份额 |
| 打分偷用真值 | 审查项:打分函数只收执行器状态、程序几何、先验概率 | —— |
| 5° 航向档让罕见航向学不到 | 前 K 覆盖在罕见档上掉 | 合并罕见档 |
| 多机层数据切分泄漏 | 按航班切分会让邻机的未来进入训练 | 按运行日切分 |

## 8 没有证据的地方

设计已定;下面四条是**已知缺证据**的,读结果时要记得。

**5° 航向档对"转上航道"以外的词的代价没有量过。** 每类样本从 1,077 条降到 497 条,罕见航向可能更难
学,数据撑得住但代价未测。

**最坏那一架(约 840 米)的成因不明。** 补档位对它无效,说明它与最坏 1 % 的整体机制不同。

**"结束"词的复飞值在训练数据里出现 0 次**,先验不会学到它,要到后训练阶段构造复飞场景时才被用到。
垂直的上升档则不然——读出来它确实被用到。**上升 3.0 度这个取值本身没有对着规章核过**:公布的复飞最小
爬升梯度还没有从程序数据里抽出来。
