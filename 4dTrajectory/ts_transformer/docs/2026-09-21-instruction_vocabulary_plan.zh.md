# 指令词表

把一次进近说成一串管制指令,让第二层说出这串指令,由执行器去飞。

**单位:米、米/秒、度、秒。** 量测方法与依据在 `2026-09-21_vertical_word_method.zh.md`;
被取代的旧计划在 `2026-09-18_two_tier_plan_v3_B.zh.md`。

---

## 1 词表

一句话是一串**事件**,每个事件是"在此刻,这几项目标变成了什么"。只在真的有东西变了的时刻出现一个
事件;没有"保持"这个词。每个事件带六个词:

| 词 | 取值 | 冗余 |
|---|---|---|
| **跑道** | 该机场到达清单里出现过的跑道(KRDU 4 / KSJC 4 / KSTL 8 / KSMF 3 / KMSY 4) | —— |
| **航向** | 相对最后进近航道,10° 一格,整圈 36 类 | —— |
| **垂直** | 下降角五档:**0 / 1.4 / 2.4 / 3.1 / 4.4 度** | 平飞档 **±0.1°**(绝对);下降档 **±7 %**(即 1.4° 上 ±0.10°、4.4° 上 ±0.31°)⚠ 待定 |
| **速度** | 地速 16 档:**44 / 56 / 63 / 68 / 74 / 79 / 86 / 93 / 99 / 107 / 114 / 121 / 129 / 138 / 147 / 157 米/秒** | **±3 %**(即 74 米/秒 上 ±2.2、129 上 ±3.9)⚠ 待定 |
| **时长** | 距上一条事件多久,2 秒一格,0–300 秒,151 类 | —— |
| **结束** | 继续 / 落地 / 复飞 | —— |

跑道词的类别按机场绑定,**不进词表规格、不进 sha**,否则一份词表不能通用于五个机场。其余各类与机场
无关。

**⚠ 标记的两个冗余值是起点,不是定论**——它们的取舍见 §8.1,换一个值不换词表 sha(冗余是读数与解码
的参数,不是词本身)。**没有 ⚠ 的都是已定的。**

### 1.1 每一类为什么是这个形式

**跑道**:其余各类都是相对某条跑道量出来的角度和高度,没有跑道词就说不出"去哪条跑道";而真实管制里
跑道就是管制员说出口的一句话。它是每个位置一列,所以句子能表达中途改跑道。

**航向**:三类有格子的词里唯一还剩结构的。剔掉"对着航道"那一簇(0°,占 38.2 %)之后,10° 档比随机
取整好 11 %(2.23° 对均匀的 2.50°)。那一簇不是退化值——它是"转上最后进近航道",是一条有意义的指令。

**垂直是角度,不是高度**。飞机在整条进近上只做两件事:平飞,或按大约 3 度下降,而这个角度从两万英尺
到入口基本不变。原来的"入口以上高度、304.8 米一格"有两个毛病:在真实平飞层上等同随机取整(71.7 米
对均匀的 76.2 米),而且每架有一条退化指令("下降许可",目标恒为入口穿越高,占高度指令的 56 %,不带
垂直信息)。角度描述的是**这一段怎么飞**,不是"最后停在哪"。

**速度只能按地速定**。原来的"10 节一格"等同随机取整(实测 1.34 / 1.28 / 2.46,均匀解析值
1.286 / 1.286 / 2.44),根因是**量错对象**:词量地速,管制给表速,风把两者之间的整数结构打散了。
而数据里没有空速、地面气象也换不出高空风,所以换不掉。档位只能按误差本身拟。

**时长**:事件流必须说"距上一条多久"。做成词不是做成一个回归数,因为生成时要取前 K 个候选、要采样,
回归输出给不了。2 秒是数据本身的分辨率。

**结束**:一句话在哪结束由它自己的词回答,不由一个外挂的二值输出。这样自由生成就是"一直说到模型自己
说落地";而且"落地"每架恰好一个、占 17 % 的事件,是个学得到的类。

### 1.2 没有的东西

**没有"切入"这一类**。量下来它是航向词的影子:4,897 条切入词全部与某条航向词同时刻发出,78 % 可从
航向词直接推出。而且管制员说的是"左转航向 250,切入航道"——角度是他给的航向的后果,不是他说出口的
目标。解码时要用的切入角从航向的连续目标值直接算。

**没有"保持"**。什么都没变的时刻不是事件,不占位置。

**复飞这个值在这份数据里出现 0 次**。词表是在 25 公里到达切片上读的,切片只含最后那次成功的进近。
它留在词表里是因为**词表必须在实验开始前定死**——否则构造复飞场景的后训练阶段要重训。

### 1.3 两条必须记住的性质

**角度是速率,它的误差随飞行距离累积;绝对目标不会。** 五档角度在最优分段上的终点高度误差是中位
34.7 米、p95 194.6 米,但**最坏约 840 米,且加档位修不了**(六档、七档的最坏值在同一区间来回跳)。
成因见 §2.3。本设计不加绝对高度锚。

**两类冗余积到不同维度**:角度的冗余积到**高度**上(δ × 距离),速度的冗余积到**到达时间**上
(≈ D·δ/v²)。到达时间是这个项目的第四维,所以速度冗余不是免费的自由度。

## 2 怎么从航迹读出这些词

### 2.1 两种分段,按量的性质选

**绝对目标用"平台"**:一个量在容差内(航向 ±4°、地速 ±2.5 米/秒)保持 ≥ 20 秒,且这 20 秒的拟合
斜率把它带走的量不超过半个容差。两个平台之间是机动;目标 = 到达的那个平台的中位数;**发出时刻 =
信号离开紧挨它前面那个平台的那一行**。

**速率量不能用平台**。速率描述的是整条曲线的形状,分段必须**铺满**航迹;平台分段把"正在变化"的过渡
段留在外面,没有指令负责它们。代价量过:在平台分段上,量化只占 10.5 米,而**过渡段没人管占了 56.0 米**。

所以**下降角用分段线性拟合**:坐标取高度对累计水平距离,动态规划在给定段数下求最优断点,段与段共用
断点、首尾相接。每架 5 段(与句子长度对齐)。换成这套分段后误差减半(中位 66.5 → 34.7 米),5 段之后
基本饱和。

**自检**:用每段真实斜率还原,终点误差必须为 0(实测 0.0000 米)。凡是"把分段聚合成每架航班"的读数
都要先过这条。

### 2.2 档位怎么拟

拟 **tan(角度)** 而不是角度(一段降多少 = 水平距离 × tan);按**水平距离的平方**加权(长段的角度偏差
代价远大于短段);平飞单独占一档、固定 0°;其余用带权一维 k-means。

**拟出来要圆整**:圆到一位小数是免费的(36.3 → 35.7 米),圆到 0.5 度要 45.4 米。规格里不该出现拟合
噪声。

**等比(按比例)分档不成立**:7 个等比档不如 5 个均匀整数档。等比只在数据横跨几个数量级时才划算。

**代价**:拟合出来的档心成为数据的一部分,必须和词表 sha 一起冻死;cohort 一变就要重拟、换 sha、
产物全废。

### 2.3 误差最大的那一撮

| | 最坏 1 % | 其余 |
|---|---|---|
| 终点误差 | 387.4 m | 35.6 m |
| 总水平距离 | 64.0 km | 24.3 km |
| 最长一段 | 18.6 km | 11.0 km |
| 单段最大误差 | 211.2 m | 34.3 m |
| 离档心最远 | 1.0° | 0.4° |
| 各段误差同号 | 5 % | 5 % |

**不是误差沿途累积**(同号比例两组都是 5 %)。**是一段很长的航段,梯度正好卡在两个档的中间**——单段
就占终点误差的 56 %。哪里的档间隙最宽就往哪里补一档,中位从 36.3 降到 29.0 米。

### 2.4 冗余为什么按百分比

**角度**:百分比给**长而浅**的段更小的冗余,而误差最大的正是长的浅降段。同样的覆盖率下 p95 区间窄
7–12 %。平飞档必须单独给一个固定值——百分比乘 0 等于没有冗余,而平飞占 12.4 % 的段。

**速度**:时间代价 Δt ≈ D·δ/v² 在**低速时最贵**,而进近后段正是低速;绝对冗余在那里最浪费,百分比让
代价分配均匀。同样约 11 秒的 p95 时间代价,百分比给 81.2 % 覆盖,绝对只给 59.6 %。

## 3 两层怎么训

### 3.1 先验

一个样本 = 一架飞机的整句话。

| | 内容 |
|---|---|
| 事件 k 的输入 | 六个词各一个嵌入相加;该时刻的状态(位置相对**机场基准点**、地速、航向的 cos/sin);事件序号 |
| 上下文 | 机型 |
| 目标 | 事件 k+1 的六个词 |
| 损失 | 每类词一个交叉熵,只在有下一个事件的位置上算 |

**先验不预测轨迹**——每个事件时刻的真实状态直接喂给它,它只说下一句。

**部署时有两重落差**:语言模型生成时只有自己的词回灌;这里先验说词、**执行器去飞**,先验下一步看到的
状态是执行器飞出来的。词的回灌一样;**上下文里有一个会漂的外部系统**,这部分没有对应物——执行器逐轮
误差线性涨、每轮约 110 米。§3.3 的两步后训练冲的就是这个。

### 3.2 跑道要从输入里拿走

现在跑道是三重给定的:状态原点是那条跑道的入口、跑道航道是显式上下文、跑道词本身也在输入里。三样
都在时让模型预测跑道不是预测,是抄。三处一起改:状态原点换成**机场基准点**;**去掉跑道航道这个
上下文**;跑道词进输入也进输出。代价:其余各类要自己从跑道词还原出相对入口的位置与航道方向,可能退。

### 3.3 后训练

**执行器闭环再训**:在训练集上用预训练执行器闭环飞,每段开若干分支(真值指令及其相邻档),只留段末
离真值最近的那支继续;飞出来的历史切成训练窗口,标签 = 同一绝对时刻真值的下一段。**不加引导的微调比
不微调还差**(0.6361 对 0.7581),引导着才有用(0.7616)。

**先验闭环再训**:同样的引导式做法,但挑的是指令——每个位置在先验前 K 个候选里挑一个交给执行器飞,
留落点离真值最近的那个继续。

**目标导向解码**:每个位置取 K 个候选各飞一段;先按程序与可飞性**屏蔽**,剩下的按先验概率、向入口的
推进、对航道的对准打分。打分只用部署时拿得到的量。上限读法:同一套候选改用真值打分。

**强化学习本阶段不做**:引导式闭环再训之后再做强化学习只多 +0.0001;只有奖励里有"离真值远近"表达
不了的东西(间隔、指定到达时刻)时才值得。

## 4 怎么判它成不成

**门一 · 真值指令的上限**。真值读出的指令按执行器所在位置喂给执行器,闭环飞完整个进近。若这样都不比
无指令好,指令这条路本身不成立。判据:两项 established 不差,任一项两个种子都超过无指令的线,
fully flyable ≥ 0.95。

**门二 · 先验自己说的话站不站得住**(不需要执行器)。自由生成到模型自己说"落地"为止,检查:

- 最后一个事件的航向词对着航道、垂直词是平飞或最后一段下降、结束词是落地;
- 复飞词只在**入口以上高度 ≥ 该跑道公布的决断高**时出现——有垂直引导的进近,复飞点就在决断高上。
  逐跑道的决断高已抽出存在跑道配置里(25 条跑道有,入口以上 61.0–129.1 米);
- 要压过两个什么都不做的对手:永远重复上一条指令的模型,和只看上一个词猜下一个的模型。

**这道门必须读真实高度,不能读词**——决断高全部落在一个词的跨度之内。

**门三 · 两层接上飞出来**。先验说话、执行器飞,读 established 与雷达引导组的误差,相对无指令基线。

**读数协议**(三门共用):闭环从固定位置起飞完整个进近,开发 cohort 1,404 架,每配置两个种子,按进近
类型分三组读。

## 5 与程序、与多机

**程序不进损失,只进解码时的掩码**。坐标系本身就是程序的,所以同一词表在任何跑道上读出同样的句子。
违反程序的候选在打分前屏蔽:切入角过大、低于该处障碍物间隔面的高度目标、航道外侧的走向。掩码换来的
是**可解率**而不是精度(去掉掩码可解率从 0.865 掉到 0.527)。规则制导只作基线与诊断,不作模型的修法。

**多机在本阶段之后**。前机的指令序列就是管制员对前机说的话,后机的先验读它作上下文;间隔规则作用在
**候选指令**上。先量上限:不建图,把前机的真值指令序列作为上下文喂给单机先验,差大于种子线才值得
建层。切分按运行日,不按航班。

## 6 步骤

1. **读词表** —— 在开发 cohort 上读出全部句子,写出词表产物(带 sha)与人工核样本。
2. **门一** —— 真值指令喂执行器,两个种子。不过就停。
3. **训先验** —— 先读困惑度、top-1、翻转率、前 K 覆盖,再做门二。
4. **消融** —— 中间状态每个位置都给 vs 只在第 0 个位置给。两版都训、都读。
5. **后训练** —— 执行器闭环再训 → 先验闭环再训 → 目标导向解码,每步过门三再进下一步。

## 7 风险

| 风险 | 怎么看出来 | 后备 |
|---|---|---|
| 词表太粗,真值指令都飞不到 | 门一不过 | 先细化档位;仍不过则这条路不成立 |
| 先验只会重复最常见的指令 | 翻转率低、自由生成早停 | 与"永远重复上一条"比;不过则加目标导向解码 |
| 角度误差在长进近上失控 | 门三的雷达组误差、终点高度散布 | 引入一个绝对高度锚(代价:多一类词) |
| 闭环再训把执行器带坏 | 直线组 established 掉 | 降低飞出窗口的份额 |
| 打分偷用真值 | 审查项:打分函数只收执行器状态、程序几何、先验概率 | —— |
| 数据量不够 | 两种子差大、罕见指令学不到 | 五机场按机场均匀采样合训 |

## 8 没定的

**8.1 冗余取多少。** 角度 ±7 %(覆盖 87.1 %,可达区间中位 176.7 米)还是 ±10 %(94.7 %,251.9 米);
速度 ±3 %(覆盖 81.2 %,到达时刻 p95 11.2 秒)还是 ±5 %(97.6 %,18.6 秒)。这是"指令说得多死"与
"执行器有多少自由"之间的取舍,没有客观最优。

**8.2 航向要不要改 5° 一格。** 5° 档误差减半(剔掉主簇后 1.12° 对 2.23°),72 类、每类仍有 497 条
样本,数据撑得住;但更细的档会让"转上航道"以外的词更难学,值不值得没有量过。不改就是 10°。

**8.3 训一个机场还是五个。** KRDU 单训 13,823 条高度指令 / 五机场 75,534 条。合训把每类样本量提高
一个量级。这一条影响所有档位能分多细。

**8.4 门二读数的时机。** 训完立刻读,还是等 §6 第 4 步的消融两版都训完一起读。两版都要训,先后不影响
总量;一起读有参照,单独读没有。

**8.5 重建产物的许可。** 词表已经变了(垂直从高度改成角度、速度换档),**sha 必变,全部产物要重建**,
现有读数全部作废。重建约三分钟,但它改变每一个下游数据集划分。这一步要明确同意才能做。
