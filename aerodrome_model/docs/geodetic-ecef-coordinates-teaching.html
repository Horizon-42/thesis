1. 缩写和术语先展开

坐标转换文档很容易被缩写淹没。先把常见缩写铺开，后面读公式会轻很多。

缩写或术语 完整展开 在本章中的意思
WGS 84 World Geodetic System 1984，1984 世界大地测量系统 全球大地参考系统。它给出地球椭球、坐标框架和一组标准参数，全球导航卫星系统常用它表示位置。
ECEF Earth-Centered, Earth-Fixed，地心地固 原点在地球质心，坐标轴随地球一起旋转的三维直角坐标系。
GNSS Global Navigation Satellite System，全球导航卫星系统 卫星定位系统的总称，例如 GPS、Galileo、BeiDou、GLONASS。GLONASS 来自俄语 Globalnaya Navigatsionnaya Sputnikovaya Sistema，意思是全球导航卫星系统。
GPS Global Positioning System，全球定位系统 美国建设的全球导航卫星系统，常把定位结果放在 WGS 84 参考框架中使用。
CRS Coordinate Reference System，坐标参考系统 一套完整规则：坐标轴、单位、原点、基准和数学模型。只写 “经纬度” 通常还不够完整。
EPSG European Petroleum Survey Group，欧洲石油调查组织 历史名称。现在常指由 International Association of Oil & Gas Producers 维护的 EPSG Geodetic Parameter Dataset，即大地测量参数数据库。
IOGP International Association of Oil & Gas Producers，国际油气生产者协会 维护 EPSG 数据集并发布坐标转换指导文档的组织。
NOAA National Oceanic and Atmospheric Administration，美国国家海洋和大气管理局 发布测地、海洋、大气相关定义和说明的机构。
NGA National Geospatial-Intelligence Agency，美国国家地理空间情报局 维护 WGS 84 相关规范的重要机构。
DMS Degrees, Minutes, Seconds，度、分、秒 角度写法。例如 53°48′33.820″N 表示北纬 53 度、48 分、33.820 秒；E 表示东经，N 表示北纬。
HTML HyperText Markup Language，超文本标记语言 本教学页的文件格式，浏览器可以直接打开。
m meter，米 本页中 ECEF 坐标、椭球半径和高度的默认长度单位。
UTM Universal Transverse Mercator，通用横轴墨卡托 一种把地球表面分带投影到平面的坐标系统。本页只偶尔提到它，不展开 UTM 公式。

2. 两个坐标系到底差在哪里

大地坐标和 ECEF 坐标可以表示同一个物理点，但它们的“语言”完全不同。前者更适合人看地图，后者更适合计算三维向量。

大地坐标：φ、λ、h

大地坐标写成 (φ, λ, h)。φ 是 geodetic latitude，即大地纬度；λ 是 geodetic longitude，即大地经度；h 是 ellipsoidal height，即椭球高。

φ：phi，大地纬度。它由椭球法线决定，不是从地心连线决定。
λ：lambda，大地经度。通常以格林尼治子午面为零经度。
h：椭球高。沿椭球表面法线向外量出的距离。
datum/frame：基准或参考框架。这里默认都在 WGS 84 内部，不做基准变换。

ECEF 坐标：X、Y、Z

ECEF 坐标写成 (X, Y, Z)，单位通常是米。它是右手直角坐标系：X 轴穿过赤道和格林尼治子午线交点，Y 轴穿过赤道和 90°E 经线交点，Z 轴沿地球自转轴指向北极。这里 E 是 East，表示东经方向。

X：沿格林尼治赤道方向的地心直角坐标。
Y：沿 90°E 赤道方向的地心直角坐标，E 是 East，表示东。
Z：沿地球自转轴向北的地心直角坐标。
O：Earth center，地球中心或更准确说地球质心。

3. 读公式前需要的数学最小包

这一章真正用到的高等数学不多，但每一项都很关键。下面是够用版解释，并给出继续学习入口。

三角函数和弧度

sin、cos、tan 分别描述直角三角形中的边长比例。π 读作 pi，是圆周率。计算机函数通常要求角度用 radians，即弧度，而不是 degrees，即度。

radians = degrees × π / 180 degrees = radians × 180 / π

学习入口：三角函数、单位圆、弧度制。

勾股定理和投影

ECEF 中 X、Y 是赤道平面内的两个直角方向，所以点到 Z 轴的水平距离 p 来自勾股定理。sqrt 是 square root，意思是平方根。

p = sqrt(X² + Y²)

学习入口：向量、正交投影、三维直角坐标系。

atan2 而不是 atan

atan 是 arctangent，即反正切，只知道比例 Y/X。atan2(Y, X) 同时看 X 和 Y 的符号，能判断角落在哪个象限。

λ = atan2(Y, X)

学习入口：反三角函数、象限、极坐标。

隐函数求导

椭圆方程不是 z = 某个 p 的简单形式，而是 p 和 z 同时出现在一个等式里。对等式两边求导，可以得到切线斜率。

p²/a² + z²/b² = 1 2p/a² + (2z/b²)(dz/dp) = 0

学习入口：导数、隐函数求导、切线斜率。

法线和负倒数

曲线某点的切线表示“贴着表面走”的方向，法线表示“垂直表面出去”的方向。在平面中，两条互相垂直的直线斜率相乘为 -1。

slope_normal = -1 / slope_tangent

学习入口：解析几何、斜率、垂直关系。

非线性方程和迭代

ECEF 反算大地纬度时，φ 出现在 tan、sin 和平方根里，不能像一次方程那样一移项就解出。迭代就是先猜一个 φ，再反复修正。

φ₀ → φ₁ → φ₂ → ... → stable φ

学习入口：非线性方程、固定点迭代、收敛。

4. 椭球几何：为什么会出现 ν

WGS 84 把地球近似为旋转椭球。赤道半径较长，极半径较短。把三维椭球沿某个经线剖开，就得到一个二维椭圆；许多公式都从这个剖面来。

WGS 84 椭球参数

符号 含义 WGS 84 常用值
a semi-major axis，半长轴，也就是赤道半径 6,378,137.0 m
b semi-minor axis，半短轴，也就是极半径 约 6,356,752.314245 m
f flattening，扁率，描述两极被压扁的程度 1 / 298.257223563
e² first eccentricity squared，第一偏心率平方 约 0.00669437999014
ν prime vertical radius of curvature，卯酉圈曲率半径 随纬度 φ 改变
b、f、e² 的关系：b = a(1 - f)，e² = f(2 - f)。这些量描述的是同一个椭球形状，只是角度不同。

椭球方程到剖面方程

三维椭球方程是：

x²/a² + y²/a² + z²/b² = 1 等价写法：(x² + y²)/a² + z²/b² = 1

令 p = sqrt(X² + Y²)，也就是点到 Z 轴的水平距离。因为椭球绕 Z 轴旋转对称，三维问题可以先在 (p, z) 剖面中处理：

p²/a² + z²/b² = 1

从切线斜率推到表面点公式

假设椭球表面点在剖面中是 S(p₀, z₀)。椭圆方程为 p²/a² + z²/b² = 1。对它做隐函数求导：

2p/a² + (2z/b²)(dz/dp) = 0 dz/dp = -(b² p₀)/(a² z₀)

这是切线斜率。法线与切线垂直，所以法线斜率是负倒数：

slope_normal = (a² z₀)/(b² p₀)

大地纬度 φ 就是法线相对赤道平面的角度，因此 tan φ 等于法线斜率：

tan φ = (a² z₀)/(b² p₀) 因为 b²/a² = 1 - e² tan φ = z₀ / ((1 - e²)p₀)

把这个关系和椭圆方程联立，就得到标准表面点：

ν = a / sqrt(1 - e² sin²φ) p₀ = ν cos φ z₀ = ν(1 - e²) sin φ
核心直觉：ν 不是凭空冒出来的常数，它来自“沿椭球法线定义纬度”这件事。只要用大地纬度而不是地心纬度，ν 就会自然出现在公式中。

5. 坐标变换一：大地坐标 (φ, λ, h) 到 ECEF (X, Y, Z)

正算最容易建立空间直觉：先在椭球表面找到法线脚点 S，再沿法线走 h 到点 P，然后把 P 的三维位置分解到 X、Y、Z 轴。

正算公式

先算卯酉圈曲率半径 ν：

ν = a / sqrt(1 - e² sin²φ)

再得到 ECEF 坐标：

X = (ν + h) cos φ cos λ Y = (ν + h) cos φ sin λ Z = ((1 - e²)ν + h) sin φ

公式里的每一项在做什么

  • (ν + h) 表示法线方向上的水平尺度，h 把点从椭球面推到椭球外或椭球内。
  • cos φ 把位置压到赤道平面，得到水平投影。
  • cos λ、sin λ 把赤道平面的投影分解到 X 轴和 Y 轴。
  • ((1 - e²)ν + h) sin φ 是竖直方向的 Z 分量，里面的 (1 - e²) 来自椭球被压扁。
把角度转成弧度。 如果输入是度、分、秒，先转成十进制度，再乘以 π/180。绝大多数编程语言的 sin、cos、tan 都吃弧度。
确认高度 h 是椭球高。 如果 h 来自地形图或机场标高，它很可能是相对平均海平面的高度，不能直接塞进这个公式。
使用同一个椭球参数。 φ、λ、h、a、e² 必须属于同一个参考系统。这里默认使用 WGS 84。

数值例子

原文章节使用了 EPSG/IOGP 示例点。DMS 写法先转成十进制度：

φ = 53°48′33.820″N ≈ 53.809394444° λ = 2°07′46.380″E ≈ 2.129550000° h = 73.0 m

带入 WGS 84 椭球后，得到：

X ≈ 3,771,793.968 m Y ≈ 140,253.342 m Z ≈ 5,124,304.349 m

6. 坐标变换二：ECEF (X, Y, Z) 到大地坐标 (φ, λ, h)

反算比正算难，因为经度 λ 可以直接从 X、Y 得到，但纬度 φ 藏在 ν 里，而 ν 又依赖 sin²φ。这就是非线性。

先求简单部分

经度来自赤道平面内的方位角，水平距离来自勾股定理：

λ = atan2(Y, X) p = sqrt(X² + Y²)

atan2 的好处是能区分东北、西北、西南、东南四个象限。如果只用 atan(Y/X)，X 为负或接近 0 时容易出错。

为什么 φ 难求

正算公式暗含：

p = (ν + h) cos φ Z = ((1 - e²)ν + h) sin φ

由第一式得到 h = p/cos φ - ν，代入第二式：

Z = p tan φ - e²ν sin φ ν = a / sqrt(1 - e² sin²φ)

φ 同时出现在 tan、sin 和 ν 的平方根里，所以这是非线性方程。

方法 A：迭代反算，概念最直观

先给一个初始纬度 φ₀，然后每轮用当前纬度计算 ν，再更新纬度。常用初值是：

φ₀ = atan2(Z, p(1 - e²))

迭代式：

νₙ = a / sqrt(1 - e² sin²φₙ) φₙ₊₁ = atan2(Z + e²νₙ sin φₙ, p)

当相邻两次 φ 的差很小，就停止。然后恢复高度：

h = p / cos φ - ν
直觉：每轮都在问“如果当前纬度是真的，法线半径 ν 应该是多少”，然后用这个 ν 反过来修正纬度。普通地表或近地空间点通常很快收敛。

方法 B：Bowring 风格闭式近似，工程上常用

EPSG/IOGP 指导文档中给出一种很准确的非迭代写法。先定义辅助角 q 和第二偏心率平方 ε：

q = atan2(Za, pb) ε = e² / (1 - e²)

然后直接计算纬度：

φ = atan2(Z + εb sin³q, p - e²a cos³q) ν = a / sqrt(1 - e² sin²φ) h = p / cos φ - ν
闭式不等于魔法。 这里的 q 是为了把椭球几何重新参数化，使纬度近似可以一次写出来。想继续学，可以查 Bowring geodetic conversion、auxiliary latitude、ECEF to geodetic closed form。

用同一个例子反算

输入 ECEF：

X ≈ 3,771,793.968 m Y ≈ 140,253.342 m Z ≈ 5,124,304.349 m

反算应恢复：

φ = 53°48′33.820″N λ = 2°07′46.380″E h = 73.0 m

正算和反算能互相回到原值，前提是使用同一个椭球、同一种高度定义和同一套轴方向约定。

7. 高度警告：h 不是“海拔”

原文章节最后提醒的这点非常重要：公式里的 h 是 ellipsoidal height，即椭球高，不是常说的海拔。

椭球高 h

椭球高从 WGS 84 椭球表面沿法线量到点 P。GNSS 接收机内部计算常接近这种高度定义。

P = ellipsoid surface point + h × normal direction

正高或海拔 H

工程、地形图和机场标高常用的高度通常接近相对平均海平面的高度，也叫 orthometric height，中文常译为正高。

H ≈ h - N N = geoid undulation，大地水准面起伏

8. 实操检查清单和继续学习入口

写代码前逐项检查

  • 输入纬度 φ 是大地纬度，不是地心纬度 ψ。
  • 输入经度 λ 的零点是格林尼治子午线，东西方向约定明确。
  • 角度已经转成弧度，再调用 sin、cos、tan、atan2。
  • 高度 h 是椭球高；如果是海拔，先确认是否需要大地水准面模型。
  • 所有参数都来自同一个参考系统，例如 WGS 84。
  • ECEF 坐标单位是米，X、Y、Z 轴方向没有被交换。
  • 反算靠近两极时，小心 p 很小、经度不稳定的问题。

一句话总结： 大地坐标 (φ, λ, h) 是“站在椭球表面按法线、经线、纬线描述位置”；ECEF (X, Y, Z) 是“从地球中心用三条固定直角轴描述位置”。正算是把前者分解到三条轴，反算是从三条轴找回法线脚点。
