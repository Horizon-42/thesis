# Agent Instructions

- For document, Markdown, LaTeX, and formatting fixes, preserve the author's content as the top priority.
- Do not rewrite formulas, explanations, terminology, or meaning just to improve rendering compatibility.
- If a rendering problem may require an external package, renderer setting, or build tool, report that requirement before changing content.
- Limit edits to true syntax or formatting errors unless the user explicitly asks for content rewriting.
