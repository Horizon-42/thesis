## How each value was chosen

These are the rules applied to every row; each row's `notes` names the alternatives it did not take.

1. **Variant.** An ICAO designator often covers several certified models. The value is for the model the
   FAA Aircraft Characteristics Database row names (and whose MTOW it prints), e.g. C560 = Citation
   Ultra (MTOW 16,300 lb), C680 = Sovereign, C750 = S/N 750-0173 on, F2TH = Falcon 2000EX,
   BE40 = Model 400A. Other variants' numbers are in `notes`.
2. **Wing area** is copied as printed. Where the document prints both units, the m2 figure is used and
   the ft2 figure is quoted in `notes`; no area was converted. The A220 figure is the ACP's "ESDU wing
   area (including ailerons, flaps, spoilers and area within the fuselage)", the CRJ700 figure the
   APM's "Total Wing Area", the PC-12 figure "Total Wing Area", all others "Wing Area".
3. **Jet thrust** = static sea-level take-off thrust **with all engines operating**:
   * from the engine data sheet (the preferred source), its ISA sea-level column where it prints both
     an ISA and a break-point-temperature value (AS907 series);
   * the *normal* take-off rating where the data sheet prints both a normal and a maximum / APR rating
     (CF34-3B, CF34-8, AS907-2-1G). The CF34-1/-3 data sheet defines the difference itself: APR is
     "a single engine thrust rating used during One Engine Inoperable (OEI) operating conditions",
     take-off "represents and unlimited twin engine use" [sic]. The maximum / APR figure is in `notes`;
   * **exception:** where the *aircraft* data sheet prints a lower installed take-off limit for that
     airplane than the engine data sheet's rating, the airplane limit is used, because it is the most
     the airplane may use (E545 29.53 vs 33.91 kN, G280 normal 33.03 vs 34.37 kN, and in the extra rows
     E550 31.75 vs 33.91 kN, LJ60 4600 lb vs 2081 daN). Both numbers are in `notes`; switch to the
     engine rating if that is what the substitution model wants;
   * where the aircraft data sheet allows several engine models and does not tie them to the FAA row's
     weight (BCS1, BCS3, B712, E75S), the **highest-rated** option is the value and the others are in
     `notes`.
4. **Turboprop / piston power** = take-off shaft power, same rules. For every turboprop in the 37 the
   engine data sheet's rating equals the airframe's flat rating (PC-12 1200 shp = 895 kW, C208 675 shp
   = 503 kW, B350 1050 shp = 783 kW, BE20 850 shp = 634 kW, C408 1110 shp = 828 kW); in the extra rows
   BE9L (550 shp airframe limit vs PT6A-135A 559 kW engine rating) takes the airframe limit.
5. **Units.** kN and daN are copied (daN / 10 = kN is a prefix change). Pounds-thrust are converted
   once with 1 lbf = 4.4482216 N, horsepower with 1 hp = 0.745699872 kW (shp treated as mechanical hp),
   only where no SI figure is printed (H25B, C560, LJ60, P28A, P28R, BE9L) or the printed SI figure is
   wrong (C25M, see Contradictions). `notes` gives the original value and unit.
6. **Locators.** "PDF pN" is the 1-based page index of the PDF file, which is not always the page number
   printed on the page. Web pages have no pages; their excerpts give line numbers of the visible text.
7. **Tiers** (as the brief defines them): 1 = type-certificate data sheet (EASA or FAA, aircraft or
   engine); 2 = manufacturer document or product page; 3 = ICAO emissions databank; 4 = peer-reviewed
   data set.

**Access notes.** EASA serves each data sheet at `https://www.easa.europa.eu/en/downloads/<id>/en`;
the ids were read from the data sheet's page in the EASA type-certificate library, which was crawled in
full on 2026-09-23 (622 entries, 13 listing pages). FAA DRS answers a plain download with HTTP 403; it
serves a data sheet after `GET https://drs.faa.gov/guest/login` (keep the cookies), then
`GET /api/browse/documents/summaryguiddocview/<docUniqueId>` (the JSON `id` is the file id), then
`GET /api/content/alf/<id>`. DRS document search: `POST /api/drs/search/simpleSearch` with body
`{"searchText":["\"A16SW\""],"sort":[],"fuzzy":false,"offSet":0,"rowCount":"25","filtersAfterSearchApplied":false,
"filtersAfterSearch":{"documentType":[],"status":[],"searchOptions":[],"publishedDate":{"start":"","end":""},
"effectiveDate":{"start":"","end":""}}}` - the body must carry `sort` (the server throws on a missing
sort list), and a data-sheet number or an engine model in quotes is found reliably while a free-text
model name is not. Bombardier's `bombardier.com/en/media/media-library/<model>` pages answered HTTP 403
to a scripted request on 2026-09-23 (the product pages answered 200).
