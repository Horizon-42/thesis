# Hierarchical / two-tier trajectory prediction — reading list for ts_transformer (2026-09-16)

Why this folder exists. `4dTrajectory/ts_transformer` learns 4D arrival trajectories in terminal
airspace (vendored iTransformer + PatchTST) along two output paths: a **`control` path** that
predicts N segments of bounded controls `(δ, φ, n)` and integrates them through a differentiable
point-mass RK4 rollout, and a **`plan` path** that predicts the next radar instruction every 30 s
and flies it with a deterministic guidance layer. The question this folder answers sources for:

> Is a **TWO-TIER** transformer worth building — **tier 1**, a short-horizon model (30–60 s) that
> predicts control parameters and is re-asked repeatedly, conditioned on **tier 2**, a long-horizon
> model that tokenises each time SEGMENT and predicts the long-term flight plan; and later
> **tier 3** (lower priority), a graph network over several aircraft's predicted segments for
> multi-aircraft interaction?

The premise being tested is: *a short-horizon model has lower error, and a hierarchy converts
compounding error into plan error.* §2 (*Patterns*) collects what the literature says for and
against that premise; §3 lists the results that **contradict** it. The assessment itself is not in
this folder — it lives in the report the main agent is writing.

The PDFs are **not tracked in git** (root `.gitignore` has `*.pdf`); `./download.sh` re-fetches all
32 (tested 2026-09-16: three deleted files came back byte-identical). §4 lists what could not be
fetched. Conventions: formulas in backticks are quoted as the source writes them (symbols
transliterated to Unicode); "checked at" says where the claim was read; **(reading)** marks my
inference, not the source's claim. Every number below was read out of the fetched PDF, not the
abstract.

### 1.2 Cluster B — multi-scale / segment-token time-series transformers

| file / id | token | how scales are fused | reported gain (and against what) |

| `Crossformer_Zhang2023…` (ICLR 2023, OpenReview `vSVLM2j9eie`) | **Dimension-Segment-Wise (DSW)**: each variate's series is cut into segments of length `L_seg` and each segment is linearly embedded — `x⁽ˢ⁾_{i,d} = {x_{t,d} : (i−1)·L_seg < t ≤ i·L_seg}`, so the input becomes a 2-D (time × dimension) array of segment tokens | **Hierarchical Encoder-Decoder (HED)**: encoder layer `l > 1` merges every two adjacent segments, `Ẑ^{enc,l}_{i,d} = M[Z^{enc,l−1}_{2i−1,d} · Z^{enc,l−1}_{2i,d}]`, then a Two-Stage Attention layer; **each decoder layer predicts at its own scale and the predictions are summed** | **The horizon-dependence result for time series.** Table 2 (ETTh1, MSE), DSW vs DSW+HED: τ = 24 `0.373 → 0.406` (**worse**), τ = 48 `0.456 → 0.493` (worse), τ = 168 `0.947 → 0.614`, τ = 336 `0.969 → 0.788`, τ = 720 `1.086 → 0.841` (**−23 %**). ### 1.3 Cluster C — compounding error: iterated vs direct multi-step

| file / id | the result, in one formula | assumptions | crossover / empirical horizon |
|---|---|---|---|
| `RossBagnell2010…` (AISTATS 2010, PMLR v9) | **Theorem 2.1**: if `E_{s∼d_π*}[e_π̂(s)] ≤ ε` then `J(π̂) ≤ J(π*) + T²ε` | costs `C ∈ [0,1]`; `J(π) = T·E_{s∼d_π}[C_π(s)]`; error measured under the **expert's** state distribution | **Tight**: there is a system where the cost is exactly `(1 − Tε)J(π*) + T²ε`. Forward Training gives `O(T)`; SMILe with `α = ε/T^{2/3}√log T`, `N = 2T²(ln T)^{3/2}` gives `J(π̃ᴺ) ≤ J(π*) + O(T(Ã₁ + ε̃) + 1)`. |
| `DAgger_Ross2011…` (arXiv 1011.0686, AISTATS 2011) | **Theorem 2.2**: if the expert's cost-to-go advantage is bounded, `Q*_{T−t+1}(s,a) − Q*_{T−t+1}(s,π*) ≤ u` for all `a`, and `ε = E_{s∼d_π}[ℓ(s,π)]` is measured under the **learner's own** distribution, then `J(π) ≤ J(π*) + uTε`. **Theorem 3.2**: for DAgger with `N = Õ(uT)` iterations there exists `π̂ ∈ π̂_{1:N}` achieving that bound. | `u` is the recoverability horizon; **worst case `u = O(T)`, which recovers `T²ε`**. For an α-mixing chain with rate δ, `u = O(1/(1 − e^{−δ}))`. | Kääriäinen's exact sequence-prediction count: `T/2 − (1 − (1 − 2ε)^{T+1})/(4ε) + 1/2`, "bounded by `T²ε` and behaves as `Θ(T²ε)` for small ε". |
| `DaD_Venkatraman2015…` (AAAI 2015, RI-CMU copy) | **Theorem 1**: a learned model with single-step error `‖M̂(x_t) − x_{t+1}‖ ≤ ε` and Lipschitz constant `L` gives `‖M̂(x̂_T) − x_{T+1}‖ ≤ ε·Σ_{t=0}^{T} Lᵗ ∈ O(exp(T log L))` for `L > 1`. **This is the bound that matters for a physics rollout.** | The three regimes are explicit: `L > 1` → exponential; **`L = 1` → O(T)** (same as supervised); `L < 1` → `O(ε)` but the predictions decay to the mean ("boring simulated behaviour"). | **Theorem 3**: with a regularised squared loss on a linear/kernel predictor and `N = Õ(T)` DaD iterations, `J(M̂) ≤ O(T·ε_N)` — **linear in T**. Empirically (normalised RMSE over the rollout): pendulum `6.00 % → 3.32 %` (−44.7 %), cartpole `19.7 % → 8.46 %` (−57.1 %), 21-D LQR helicopter `44.2 % → 25.3 %` (−42.8 %); video textures −2.6 % to −20 %. |
| `BenTaieb2012…` (arXiv 1108.3259, *Expert Systems with Applications*) | Five strategies, unified: **Recursive** (one model iterated, "sensitive to the accumulation of errors… especially if `h` exceeds the embedding dimension `d`"), **Direct** (H independent models, "immune to the accumulation of errors" but imposes **conditional independence** of the H forecasts), **DirRec**, **MIMO** (one model, vector output of all H), **DIRMO** (`H/s` models each emitting a block of `s`) | H = 56 days, NN5 competition (111 daily cash-machine series), lazy-learning function class, 12 preprocessing configurations | **MIMO wins everywhere.** Competition phase, no deseasonalisation / no input selection (SMAPE*): MIMO-LOO **21.92**, DIRMO-WAVG 22.36, DIR 24.48, REC 24.22, **DirRec 44.97** (catastrophic). With deseasonalisation: MIMO-ACFLIN 20.25 vs REC 23.12 vs DIR 23.98 — the gap narrows but the ordering holds. **`s` is exactly the "segment length" knob, and here `s = H` (full MIMO) is optimal.** |
| `MarcellinoStockWatson2006…` (J. Econometrics 135, Princeton draft) | "In theory, iterated forecasts are more efficient if correctly specified, but direct forecasts are more robust to model misspecification. Which approach is better is an empirical matter." | 171 US monthly macro series, 1959–2002, univariate AR + bivariate, simulated out-of-sample, four lag-selection rules | **The strongest contradiction in this folder.** Iterated typically wins, and **direct gets relatively worse as the horizon grows**: at `h = 24` the iterated forecast is preferred for all four lag rules and the 90th percentile of the direct/iterated MSFE ratio **exceeds 1.2**. Direct wins only where the one-step model is short-lagged and misspecified (price/wage/money series, BIC lags: mean ratio **0.86** at `h = 6, 12`) — and **lengthening the lags erases it** (0.87 at p = 4 → **1.00** at p = 12). Conclusion: "the reduction in estimation variance arising from estimating the one-period ahead model outweighs the reduction in bias obtained from the direct multiperiod model." |
| `Chevillon2007…` (J. Economic Surveys 21(4) 746–785; open TU-Wien mirror) | A survey and unifying framework for **DMS** (direct multi-step) vs **IMS** (iterated). The comparison reduces to "the accuracy of the **powered estimate** `Υ̂ʰ` versus the **estimated power** `Υ̂^h`". | VAR(1) `x_t = Υx_{t−1} + ϵ_t`; DMS estimates `Υ_h` by minimising the h-step in-sample error, IMS powers the one-step estimate | **The condition, quoted**: "Among model misspecifications which might sustain DMS, **unnoticed unit roots** stand out; **neglected serial correlation** of the disturbances also provide a rationale **at short horizons**. | `MultiStepMitigates_2025…` (arXiv 2504.01766, Somalwar/Lee/Pappas/Matni) | **Well-specified** (Props III.1–III.2): both errors decay at `1/N`, but the multi-step estimator's asymptotic covariance carries the extra term `tr(Γ_w((M_MS − M_SS + (H−1)d_u I_H) ⊗ I_{d_x})Γ_wᵀ)` — "a multi-step predictor is **less efficient** than a single-step predictor, and **the efficiency gap grows linearly with the prediction horizon H**". **Misspecified** (Props IV.1–IV.2): the multi-step bias equals `min_M tr((Φ + MC)Σ_x̂(Φ + MC)ᵀ) + tr(MD_eD_eᵀMᵀ)`, so it "**never exceeds** that of its single-step counterpart". | Linear dynamical systems; misspecification = an incorrect Markov assumption under partial observability | Closed loop, scalar `a = 0.9`, MPC horizon 20: in the **well-specified** case the single-step rollout has lower infinite-horizon LQR cost in the **low-data regime** (N ≈ 200–900); in the **misspecified** case the single-step rollout's closed-loop spectral radius **exceeds 1** (unstable, infinite LQR cost) while the multi-step stays below 1. | `StatEfficiency_2026…` (arXiv 2603.23465, same authors, extended) | Adds the **intermediate** predictor — *a single-step model trained with a multi-step loss*, which is what our `control` path's RK4 rollout loss is. **Prop II.4** (well-specified): single-step ≻ intermediate ≻ direct multi-step in statistical efficiency, because "the single-step predictor benefits from (i) leveraging the Markovian structure and (ii) avoiding compounding process noise across multiple prediction steps in the training loss"; the intermediate keeps (i) but loses (ii). **Prop III.4** (misspecified): the bias ordering **reverses exactly**, `B(Ĝ^MS) ≤ B(Ĝ^I) ≤ B(Ĝ^SS)`. | Same linear-system setting, 3 predictor classes | The gap "does not diminish with `a`" once the system is 2-D with an eigenvalue strictly inside the unit circle (unlike the scalar case). The intermediate predictor sits strictly between the two in **both** regimes — it is never the worst and never the best. |

## 2. Patterns across the four clusters

1. **Every hierarchy that pays measurably pays at a LONG horizon and nowhere else.** QCNet: 3 s
   horizon → `minFDE₆ 0.92 → 0.89` (noise); 6 s horizon → `1.47 → 1.27` (−14 %). Crossformer:
   HED *hurts* at τ = 24/48 and helps 23 % at τ = 720. FlightBERT++: the direct model is *worse*
   than the AR one at 20 s and 55 % better at 5 min. WTFTP+: more wavelet levels are "only
   marginal" at 1–3 steps. There is no paper here where a hierarchy helps a short horizon.

2. **The coarse tier buys mode coverage, not point accuracy.** MTR Table 3 and MTR++ Table 5 both
   show a *flat* latent-query decoder with the **best minADE** (0.6829 / 0.6564) and the worst
   mAP; the intention-point hierarchy trades ~3 % minADE for +5–7 mAP points and a large miss-rate
   drop. C2F-TP's refinement moves FDE by 34–60 % and ADE by 2–19 %. TNT/DenseTNT's gains are
   concentrated in minFDE and miss rate. If the deliverable metric is a point ADE, the hierarchy
   is not where the gain is.

3. **Refinement saturates fast, and more tiers are not better.** QCNet: 3 → 6 recurrent chunks is
   bit-identical (`1.90 / 1.27 / 0.16` both). MTR++: decoder layers 6 → 9 *reverses* (0.6490 →
   0.6512). Crossformer's segment length wants 24 (the daily period) and gets worse at 48. The
   useful number of tiers in every paper here is **two**.

4. **The segment length is a real, tunable, task-dependent knob — and there is no universal
   value.** Ben Taieb's DIRMO `s`, Stratify's `σ`, QCNet's recurrent chunk, Crossformer's `L_seg`
   and Pathformer's patch pool are the same parameter. Ben Taieb finds `s = H` best on NN5;
   Stratify finds *no* strategy dominates and that searching (strategy, σ) beats every fixed
   strategy in 84 % of 1080 runs; Pathformer makes the choice **per input** with a router and that
   routing is its single biggest ablation. **The evidence supports making the segmentation a
   searched hyper-parameter, not a design commitment.**

5. **The theory says the direction of the effect depends on one thing: misspecification.**
   Well-specified → single-step rollout is more statistically efficient and the gap grows
   **linearly in H** (2504.01766 Prop III.1/III.2). Misspecified (wrong Markov assumption, partial
   observability) → the direct multi-step bias **never exceeds** the single-step bias (Prop IV.1),
   and in closed loop the single-step model can go unstable while the multi-step does not.
   2603.23465 adds the third class and orders all three: **single-step ≻ intermediate ≻ multi-step
   when well-specified, and exactly the reverse when misspecified.** Chevillon names the specific
   misspecifications that sustain DMS (unit roots, structural breaks, omitted negative residual
   autocorrelation) and says gains in stationary processes "fade rapidly as the horizon
   increases". The question "does a hierarchy help?" is therefore the question "**is the
   short-horizon model misspecified for this data?**", not a question about architecture.

6. **The compounding bound is about the Lipschitz constant, not about being autoregressive.**
   DaD Theorem 1 is explicit: `L > 1` → `O(exp(T log L))`; `L = 1` → `O(T)`; `L < 1` → `O(ε)`.
   Behaviour-cloning's `T²ε` (Ross & Bagnell Thm 2.1) is the `u = O(T)` corner of DAgger's `uTε`
   (Thm 2.2) — i.e. quadratic growth is what you get when the system cannot recover, and the
   `uTε` form says an **easily recoverable** system compounds only linearly. Both papers'
   *remedy* is to train under the rolled-out state distribution (DAgger/DaD), not to replace the
   iterated model with a direct one: DaD's own numbers are −43 % to −57 % rollout RMSE from that
   alone, with **no architectural change at all**.

7. **Conditioning on an intent that the history does not contain is worth far more than any
   architecture in these papers.** SIA-FTP's instruction input: −25 % MDE at 3 min, and its
   ablation shows the gain survives deleting the whole elaborate training schedule.
   Trajectron++'s robot-future conditioning: −28 % FDE @4 s. The Neurocomputing 2024 paper (§4)
   retrieves the intent from a repository of historical trajectories filtered by landing time and
   landing direction and reports it as a model-agnostic conditioning input. Against these,
   AgentFormer's joint latent is 4–15 % and Scene Transformer's joint loss is 15–19 % on joint
   metrics only.

8. **The strongest single result in favour of a flat model is Wayformer**, which beat every
   goal-based hierarchy of its generation on every WOMD metric with k learned queries, one forward
   pass and a post-hoc k-means, by spending its complexity budget on input fusion instead.
   MultiPath++ independently found that **learned** anchors beat a priori k-means anchors
   (`minADE 1.22 → 0.978`), explicitly contradicting the earlier claim that anchor-free models
   collapse.

## 3. Results that contradict the premise

The brief's premise is *"a short-horizon model has lower error, and a hierarchy converts
compounding into plan error."* These are the places the sources say otherwise, with the numbers.

| contradiction | evidence |
|---|---|
| **Iterated beats direct on real data, and gets *relatively better* with horizon** — the opposite of the compounding story | MSW 2006, 171 US macro series: at `h = 24` the iterated forecast is preferred under **all four** lag rules and the 90th percentile of the direct/iterated MSFE ratio **> 1.2**. Direct wins only for short-lag misspecified models, and lengthening the lags takes the ratio from 0.87 to **1.00**. |
| **A short-horizon (single-step) model is *more* statistically efficient, and the multi-step model's disadvantage grows linearly in H** | arXiv 2504.01766, Prop III.1/III.2: extra covariance term `(M_MS − M_SS + (H−1)d_u I_H)`; "the efficiency gap grows linearly with the prediction horizon H". Well-specified low-data closed loop: single-step rollout has the **lower** LQR cost. |
| **A short-horizon model does NOT have lower error per se — the direct model is worse at the shortest horizon** | FlightBERT++ Table I: at h = 1 (20 s) AR Transformer `0.65` vs direct Transformer-Seq2Seq `0.67`; AR LSTM `0.91` vs direct LSTM+Attention `1.09`. The direct/segment model pays a price at short horizon and only earns it back by h ≈ 3. |
| **The hierarchy can make point accuracy WORSE** | MTR Table 3: static intention query (hierarchy) `minADE 0.7036` vs flat latent embeddings `0.6829`. MTR++ Table 5: flat latent embedding is the best minADE (0.6564) of all five decoders. Crossformer Table 2: DSW+HED vs DSW at τ = 24, MSE `0.373 → 0.406`. |
| **Coarse-to-fine refinement has its own compounding failure mode** | Scaleformer §3.3: "Iterative refinement at different scales can cause significant distribution shifts between intermediate forecasts which can lead to runaway error propagation"; normalising by look-back *or* by previous-forecast statistics "result in an accumulation of errors across steps". The cross-scale normalisation exists solely to stop this. |
| **A flat one-shot decoder was the state of the art** | Wayformer (WOMD, 8 s) `minFDE 1.126 / minADE 0.545 / mAP 0.419` beating DenseTNT `1.551 / 1.039 / 0.328` and SceneTransformer. Pyraformer's *own* better decoder is "a single fully connected layer", not its attention decoder. |
| **The "multi-scale transformer" line has been overtaken by flat patch models** | Pathformer's Table 1: Pyraformer ETTh1-720 MSE `0.963` and Scaleformer `0.494` vs PatchTST `0.495` — and Pathformer beats PatchTST by only 8.1 %. Both Crossformer and Scaleformer predate PatchTST/iTransformer and **neither is compared against them by its own authors.** |
| **Adding a tier is not what fixed the AR model in the one aviation case with a same-corpus comparison** | WTFTP+ vs FlightBERT++ (same dataset, both direct): `0.12 / 0.23 / 0.60 / 1.06` vs `0.17 / 0.30 / 0.70 / 1.06` — identical at 5 min. The published "−40 %" is against its own **autoregressive** predecessor. |
| **No strategy dominates** | Stratify, 1080 experiments: existing strategies (recursive, direct, DirRec, MIMO, DirMO) are **not significantly different from one another** under a Nemenyi test at 95 %; "the best strategy remains highly dependent on the dataset and task". |

Also worth recording as *not* a contradiction but a caution: the one directly relevant formal
result for **our** `control` path is arXiv 2603.23465's **intermediate** predictor — a single-step
model trained with a multi-step loss, which is exactly a segment-control head trained through an
RK4 rollout. Prop II.4 and Prop III.4 put it strictly *between* single-step and direct multi-step
in **both** regimes. It is never the best and never the worst.
