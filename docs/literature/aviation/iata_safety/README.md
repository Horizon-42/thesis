# IATA 安全报告：飞行路径管理、手动操纵、SOP 不遵守

日期：2026-10-17
问题：哪份 IATA 文件支持“飞行路径管理、手动操纵和 SOP 不遵守是事故的反复出现的致因”？

## 文件

| 文件 | 来源 | 页数 |
|---|---|---|
| `papers/IATA_Safety_Report_2025_Executive_Summary.pdf` | IATA Annual Safety Report 2025，执行摘要与安全概览（新闻稿日期 2026-03-09） | 72 |
| `papers/IATA_Safety_Report_2024_Executive_Summary.pdf` | IATA Annual Safety Report 2024，同上 | 45 |
| `papers/IATA_White_Paper_Flight_Path_Management_2026.pdf` | IATA 白皮书《Flight Path Management Recommendations》，第一版 2026 | 92 |

## 我核对过的数字（PDF 页序号）

按事故占比，一起事故可有多个致因，百分比之和可超过 100%。分类来自威胁与差错管理（TEM）框架。

| 致因 | 2025（p.9） | 2024（p.8，部分到 p.8 以外未核对） |
|---|---|---|
| Aeroplane Flight Path Management, Manual Control | 29% | 37% |
| Manual Handling and (Primary) Flight Control Errors | 24% | 39% |
| Non-compliance with SOP | 20% | 35% |

白皮书（p.10）：过去 20 年里，有效飞行路径管理的缺陷被认定为事故的主要致因之一；2005–2025 年 IATA 安全报告共有 270 起致命事故，其中 63 起由手动操纵或主飞行控制差错造成。

## 限制

- 这些百分比对象是**所有**事故，不是只看进近阶段。
- 2024 年的 3 个数字我只在 p.8 核对了其中的飞行路径管理一项（37%）；39% 和 35% 来自 2024 年文本的同一小节，未单独核对页码。
