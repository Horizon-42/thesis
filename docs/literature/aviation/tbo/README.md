## 各文件讲了什么

### 1. FAA TBO 外部资料单页（最新的一份，但无日期）

- **定义：** TBO 是一种空中交通管理方法，计划并管理飞机在 NAS 中的飞行。它要求飞机更精确地遵守轨迹，并**用时间而不是距离**来调节交通流。
- **状态：** TBO "已从规划转入实施和整合"，逐步实施，已有收益。
- **三个组成部分：**
  - 基于时间的管理（TBM）：在约束点对飞机排程和调节，以此管理轨迹。
  - 基于性能的导航（PBN）：让飞机沿轨迹精确导航。
  - 企业使能项（Enterprise Enablers）：扩大并自动化飞机轨迹信息的共享。
- **预期收益：** 吞吐量增加；可预测性提高；飞行效率提高（延误再分配、离场等待缩短、更好的航路管理、平滑下降剖面）；运营人更灵活。
- **实施里程碑**按区域列出：西北山区（DEN）、西南（LAS、LAX）、东北走廊（PHL、EWR）、中大西洋（ATL）。条目包括延伸调节（Extended Metering）、离场排程、到达调节、集成离到场能力（IDAC）、终端排序与间隔（TSAS）、终端飞行数据管理器（TFDM）。
- **培训：** 即将发布 TBFM 基础简报和 7210.3 的变更；重新着手制定交通管理协调员和管制员培训的国家标准。

### 2. 2021 年 TBO 行业日邀请信

- **定义：** TBO 是一种 ATM 概念，加强对飞机流的战略规划，以减少 NAS 中容量与需求的不平衡，并向交通管理人员和管制员提供工具，帮助飞机在起降机场之间更快运行。
- **要点：** 改善战略规划，减少被动决策和静态的"英里间隔"（miles-in-trail）限制。
- **基础：** TBO 建立在 FAA 对时间管理工具的投资、以及 FAA 和运营人对先进导航能力的投资之上。
- 议程重点是飞行计划流程、FAA 对运营人所提供数据的使用、名义 TBM 运行。

### 3. 2018 年 REDAC 简报（讲清楚历史和路线）

- **定义：** TBO 是一种 ATM 方法，通过 TBM、空地信息交换、以及飞机在时间和空间中飞精确路径的能力，对整个运行过程中的飞行做战略规划、管理和优化。
- **在 NextGen 中的位置：** TBO 一直是 NextGen 的目标：它出现在最初的 NextGen 构想中，是 2016 年《NAS 的未来》的主要运行构想，其国际构想包含在 ICAO Doc 9854 中。
- **《基于轨迹运行愿景》的地位**（简报第 5 页）：
  - 是应业界要求写的。
  - 提供一个框架，供 FAA 和用户界共同确定 TBO 具体实施计划的优先级。
  - 给出比《NAS 的未来》更低一层的构想描述。
  - **不包含任何新的运行构想或技术方案。**
- **三阶段演进：**
  - 初始 TBO（2016–2020）：各域分别部署，整合留给人工。
  - 完整 TBO（2021–2025）：所有域交付，时间管理的数据和工具实现自动整合。
  - 动态 TBO（2026–2030）：用先进的机载和地面自动化，实现针对单架飞机的、基于时间的改航和排序方案，以及基于飞机的成对轨迹方案。
- **这是 2018 年的计划，不是现状。** 单页资料说 TBO 已进入实施；我没有找到 2026–2030 年"动态 TBO"的进展材料。

### 4. 2025 年《NextGen 最终报告》

- NextGen 官方收尾总结，称 NextGen 的工作覆盖 21 年。
- TBO 在报告中被放在"面向未来的举措"里，和先进空中交通（AAM）并列，由 NextGen 的基础设施承接。
- 与 TBO 直接相关的几处：
  - ERAM Enhancements 2（EE2）在 2025 年增加了轨迹管理和管制员协作能力。
  - 通用支持服务—气象（CSS-Wx）的功能域之一就是"基于轨迹的运行"，报告说天气信息对 TBO 的精确性和可预测性很重要。
  - 数据通信已在所有 ARTCC 提供，用于轨迹协商。
- **报告没有给出 TBO 的新定义**，只做整体评价；全文我只搜索了 "trajectory" 相关段落，没有逐页通读。

## 对论文的用法

- **引用定义：** 国际定义用 ICAO Doc 9854；美国定义用 2018 年简报的第一页（定义完整），或单页资料的"用时间而不是距离"（简短）。
- **别写成 FAA 的 TBO ConOps：** 本文件夹里没有这种文件。
- **写现状时注意日期：** 单页资料没有日期，不能当作某个年份的现状。
