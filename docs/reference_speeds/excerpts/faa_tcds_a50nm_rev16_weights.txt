Notes
  * The minimum flight weight is CG-dependent: 23,075 lb at 14% CG down to 20,100 lb at 32.5% CG for the
    Falcon 2000; 23,444 lb / 21,149 lb for the Falcon 2000EX. The lowest printed figure for the designator
    is 20,100 lb (= 9,117 kg by x 0.45359237; the TCDS prints pounds only), Falcon 2000, at 32.5% CG.
  * ICAO Doc 8643 (aircraft/icao_doc8643.json) lists F2TH only as "DASSAULT Falcon 2000"; the 2000EX
    figure is recorded for completeness and is higher, so it does not change the minimum.
  * EASA TCDS EASA.A.008 Issue 13 (15 Sept 2026), item 2.5.11 page 16 of 64, prints the line
    "- Minimum flight" three times WITH NO VALUE (checked on the rendered page image); EASA gives no
    number for this designator, and its 2000EX/DX/LX/S/LXS sections print maximum weights only.
