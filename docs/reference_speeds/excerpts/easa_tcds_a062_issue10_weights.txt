Notes
  * FA50: Minimum flight weight 8,600 kg (18,959 lb) in every Falcon 50 weight column.
  * F900: Minimum flight weight 9,390 kg (20,700 lb) for the Mystere-Falcon 900 and for the Falcon 900EX/DX.
  * The MF900 "with M1196" column prints "Maximum flight ... 9,390 kg (20,700 lbs)" where every other
    column prints "Minimum flight"; a 9,390 kg maximum is impossible next to a 21,092 kg MTOW, so it is
    read as the same minimum flight weight mislabelled. The figure taken does not depend on it: the
    "without M1196" column prints "Minimum flight 9 390 kg (20 700 lbs)" unambiguously.
  * FAA TCDS A46EU Rev 23 prints the same two figures (excerpt faa_tcds_a46eu_rev23_weights.txt).
