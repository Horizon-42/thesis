13 Figures for the thesis

The page shows 23 figures in the sections where they belong. Each one has a PNG file (300 dpi) and a PDF file (vector, with embedded fonts). All text in the images is English. Each image has no title and no caption. The suggested caption is under the figure on this page, and you can copy and change it. The panel letters (a), (b) and so on are part of the images.

The files are in docs/two_tier/tutorial/figures/png/ and figures/pdf/. scripts/two_tier_tutorial/make_figures.py makes all of them again.
