14 Glossary

Term中文Meaning in this design
Row, step行，步One line of a sentence, Δ seconds long, on UTC multiples of Δ
Word词，指令词The value of one column in one row; “unchanged” says nothing new
Sentence句子The rows of one flight
Word in force生效词The last word that a column said
Runway in force (R)生效跑道The candidate runway that the runway column said last
Go-around state (G)复飞状态True after “go-around”, false after a runway word
Candidate runway候选跑道A runway end with a published vertical path; no flight decides a candidate
Capture row截获行First row from which the track stays in the capture corridor to the end of the approach
First predicted step第一个预测步The row 16 s after row 0
Open-loop reading开环读取The words read from the observed track alone
Closed-loop reading闭环读取The words with correction words, from the flight of the executor
Matched point匹配点The point of the observed path nearest to the flown position, searched forward
Correction word修正词A word added when the flown path leaves the observed path by more than a tolerance
Envelope包络The tube or span in which a word must hold, with its width stated
Executor执行器The autopilot that flies the words
Judge裁判The code that classifies the flown flight
Decision altitude (DA)决断高度The published height at which a missed approach must start
FAF最终进近定位点Final approach fix
FAS cone最终进近段锥形区The lateral containment of an LPV final
Prior, speaker先验模型，说话者The language model of the controller and its decoder
Mask掩码A set of words that a speaker must not say in a column
Teacher forcing教师强制Training in which each head reads the true words of the earlier columns
RoPE旋转位置编码Rotary position embedding, here on the time in seconds
Post-training后训练Training of the prior in a closed loop with a reward
Advantage优势The reward of a sentence minus the mean reward of its group
Branch training分支训练Credit assignment that copies the state at branch points and gives the advantage to the words after them
Approach clock进近时钟The distance along the final, used to order and compare aircraft
Operating day运行日The landing day of a flight (UTC − 9 h); the unit of the data split
Conformance check一致性检查A check that code gives the same results on fixed inputs, run each time the code is used
