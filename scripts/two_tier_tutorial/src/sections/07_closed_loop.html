7 The closed-loop reading

The open-loop reading gives the observed words. These words say directions and angles. They do not say positions. Real flights stay on their paths because of the guidance of the aircraft (LOC, LPV) and the radar of the controller. Their corrections are smaller than half a grid step, so the open-loop reading shows none: in the smoke artefact, the last heading word is class 0 in every sentence.

If the executor flies these words alone, the errors of the directions add up over 10–25 km. In a smoke test with an exact model of the words, 47 % of the vectored flights ended more than 106.7 m from the centreline. A finer grid does not help, because the real corrections are smaller than any grid step.

The closed-loop reading puts the missing corrections into words. The labeller flies its own sentence with the executor. When the flown path leaves the observed path by more than a tolerance, it adds a correction word. When the flown path is back, it says the observed word again (D32). A model that trains on these sentences reads the flown states. So it learns “an offset gives a correction word” from states that its own closed loop also gives.

7.1 The matched point: said where, not when

The labeller compares the flown state with the observed path at the matched point: the point of the observed path that is nearest to the flown position. The search goes forward from the matched point of the row before, so a path that crosses itself does not make a jump. There:

  • the lateral error e_y is the signed distance from the observed path, positive to the right;
  • the vertical error e_h is the flown height minus the observed height.

The reference is the matched point and not the observed point at the same time. A difference along the path is a difference of time. The comparison does not correct it. The observed words are said where the observed aircraft heard them (D42): at the Δ row nearest to the place where the matched point reaches the word. The controller gives a turn at a place, not at a time. An aircraft that is d ahead along the path before a turn of 90° is d to the side after it.

7.2 The correction rules

Starts whenThe wordEnds when
Heading|e_y| > Y = 30 m, and the row says no new observed heading wordThe class one step (5°) from the observed word, toward the path|e_y| < Y/2, or e_y changes sign, or a new observed heading word arrives
Angle|e_h| > H = 15 m (H_final = 10 m while “no level-off” is in force), and a descent class is in forceThe next steeper class (too high) or shallower class (too low)|e_h| < H/2, or e_h changes sign, or a new observed altitude or angle word arrives

An overshoot (D53) is a change of sign while the error is still larger than the tolerance. The labeller then says the opposite correction in the same row. Waiting one row would add a lag that comes from the reading and not from Δ.

No correction is possible in some rows: a row that says a new observed word, a level hold, a climb, and the rows past the end of the observed path (D44). A correction is one class and needs time to work. A 100 m offset takes about 20 s to fix with one 5° class. So the flown path can stay outside the tolerance for some rows (D50).

The sketch shows the mechanism. During the turn, a new observed word arrives in every row, so no correction can start. The error grows while the executor turns in a different way from the pilot. After the turn, the correction starts. With corrections on, the error returns under the tolerance. With corrections off, it stays.
