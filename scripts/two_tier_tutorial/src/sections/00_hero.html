The two-tier model: a tutorial

A language model says what a controller would say. An autopilot flies only those words. This page explains the design and the code step by step. It uses real flights, and it has parts that you can change.

How to use this page.

  • Read the text from the top. Each section builds on the one before it.
  • Look for the boxes marked Try it. They run in your browser. Move a slider and watch what changes.
  • Look for the figures marked Paper figure. Each one has a PNG file and a PDF file. The captions are only on this page. They are not in the image files, so you can write your own.
  • A D12 tag gives the number of a design decision. The numbers are the same as in the design documents.
  • The button 中文注解 shows or hides the Chinese notes. Hover over a dotted term to see its Chinese note again.

Language. The text follows the writing rules of ASD-STE100: short sentences, active voice, and one meaning for each word. Nobody checked the words one by one against the STE dictionary. The design documents make the same statement. Units are SI only (m, m/s, deg, s).

State of the design. This page follows the three design documents of 2026-10-05 and the code behind them. Stage A (the vocabulary, the labeller, the executor and the judge) is built and merged. Stage B (the prior) is built and tested, but its formal training campaign has not run. Stage C (the post-training) is partly built. This page gives no result of a trained prior, because there is none yet. Where it shows numbers, they come from the stage A artefact, and they are the train split only.
